# 경험치 기준

「경험치에 관한 세부 회칙」2026년 5월 21일 개정본을 기준으로 정리한 내용이다. 아래 수치와 지급 대상을 현행 API 설계의 기준으로 사용하며 레거시 구현의 수치로 대체하지 않는다.

## 목적·누적

- 경험치는 동아리 활동 정도를 객관화하는 참고 기준이며 활동 정도와 반드시 비례하지는 않는다.
- 단위는 exp다.
- 회원 자격을 상실하기 전까지 초기화하지 않고 누적한다.

## 등급

| 등급 | 범위 |
| :-- | :-- |
| 하급 | 500 exp 미만 |
| 초급 | 500 exp 이상 2000 exp 미만 |
| 중급 | 2000 exp 이상 3500 exp 미만 |
| 고급 | 3500 exp 이상 5000 exp 미만 |
| 특급 | 5000 exp 이상 |

- 등록 시 지급되는 경험치보다 현저히 낮은 경험치를 가진 하급 회원은 연구지원시스템을 이용할 수 없다. 현저히 낮음의 구체적인 수치는 제공된 회칙에 없다.
- 특급 회원은 회비를 납부하지 않을 수 있다.
- 하급 회원은 운영진이 될 수 없다.
- 하급 회원은 그룹 역할 중 운영진이 정한 범위의 역할을 가질 수 없다. 이 문서에서 그 범위를 임의로 정하지 않는다.

## 적용 원칙

- 사용자 확정에 따라 보고서 제출·취소에도 세미나 발표 등록·취소와 동일한 ±150 exp를 적용한다.
- 사용자 확정에 따라 운영진이 세미나 세션을 강제로 제거할 때에도 멤버 전체에게 -150 exp를 적용한다. 기존 -20 기준은 사용하지 않는다.
- 이 문서는 과거 경험치를 일괄 재계산하거나 소급 지급·회수하라는 지시가 아니다.
