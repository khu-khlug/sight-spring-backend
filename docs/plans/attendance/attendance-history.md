# 출석 내역 조회

특정 연도에 출석코드가 발급됐던 일정 목록을 조회합니다. 운영진(`MANAGER`)만 호출할 수 있습니다.

## API

```
GET /attendance-history
```

### 쿼리 파라미터

| 이름   | 타입 | 필수 | 설명                          |
| :----- | :--: | :--: | :---------------------------- |
| `year` | 정수 |  N   | 조회할 연도 (예: `2026`), 기본값은 현재 연도 |

### 요청 바디

(해당 없음)

### 응답 코드 및 응답 바디

```
200 OK
```

| 이름                    |   타입    | 설명                    |
| :---------------------- | :-------: | :---------------------- |
| `count`                 |   숫자    | 반환된 항목 수          |
| `schedules`             | 객체 배열 | 일정 목록               |
| `schedules.id`          |   숫자    | 일정 ID                 |
| `schedules.title`       |  문자열   | 일정 제목               |
| `schedules.category`    |  문자열   | 카테고리 enum 값        |
| `schedules.scheduledAt` |  문자열   | 시작 일시 (ISO 8601)    |
| `schedules.endAt`       |  문자열   | 종료 일시 (ISO 8601)    |

### 판단 기준

- `scheduledAt`이 `year`년 1월 1일 00:00 이상, 다음 해 1월 1일 00:00 미만
- `checkCode`가 `null`이 아닌 일정만 (출석코드가 발급된 적 있는 일정)
- soft-delete된 일정은 제외
- `checkCode` 자체는 응답에 포함하지 않는다 (조회 목적이 출석코드 확인이 아니라 이력 열람이므로)

### 정렬

`scheduledAt` **내림차순**(최신 일정이 먼저).

### 테스트 케이스

1. 정상 조회 → 200, 해당 연도의 checkCode 발급 일정만 포함
2. `year` 파라미터 누락 → 이번 연도의 checkCode 발급 일정만 포함
3. `checkCode`가 `null`인 일정은 결과에서 제외된다
4. 다른 연도의 일정은 결과에서 제외된다
5. 결과가 없으면 `count=0`, `schedules=[]`
6. 응답이 `scheduledAt` 내림차순으로 정렬되어 있다
7. soft-delete된 일정은 제외된다
8. 권한 없음(비운영진) → 403
