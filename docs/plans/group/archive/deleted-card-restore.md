# 삭제된 카드 복구

삭제된 카드를 지정한 리스트로 복구합니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
POST /groups/:groupId/deleted-cards/:cardId/restore
```

## 권한

USER and 그룹원

## 조건

- 그룹이 종료(`SUCCESS`·`FAIL`) 상태가 아니어야 함
- 대상 카드가 이 그룹의 삭제된 카드여야 함
- `targetListId`가 이 그룹의 리스트여야 함

## 부수 효과

### 카드 복구와 집계

- 카드의 삭제 표시를 해제하고 소속 리스트를 `targetListId`로, 위치를 해당 리스트의 맨 끝으로 설정한다.
- 그룹의 카드 수와 복구 대상 리스트의 카드 수를 각각 1 늘린다.
- 그룹의 기록 수에 복구한 카드의 `recordCount`를 더한다. 이 값은 카드 안의 삭제되지 않은 기록 수이며, 개별 삭제된 기록은 복구하거나 집계에 더하지 않는다. 카드 자체의 `recordCount`는 유지한다.
- 카드 상태·소속·위치 변경과 카운트 갱신, 경험치·로그·최근 활동 일시·중단 해제는 같은 트랜잭션에서 처리한다. 같은 카드의 동시 복구도 한 번만 반영한다.

### 그룹 상태

실제 변경이 발생하면 중단 상태를 진행 중으로 자동 전환한다. [그룹 공통 사항](../global.md#활동에-따른-중단-상태-해제)을 따른다.


### 경험치 변동

| 대상   | 변동 |
| :----- | :--: |
| 요청자 |  +1  |

- 개정 회칙에 따라 카드 작성자가 아니라 카드를 복구한 요청자에게 지급함

(해당 없음)

### 그룹 활동 로그

그룹 활동 로그에 카드 복구를 기록하고 최근 활동 일시를 갱신함

## 쿼리스트링

(해당 없음)

## 요청 바디

| 이름           |  타입  | 설명                                         |
| :------------- | :----: | :------------------------------------------- |
| `targetListId` | 10진 문자열 | 복구할 리스트 아이디. 카드는 리스트 맨 끝에 들어감 |

## 성공 응답

```
204 No Content
```

(해당 없음)

## 실패 응답

| 상황                                   | 응답 코드 |
| :------------------------------------- | :-------: |
| 종료된 그룹임 | 400 |
| `targetListId`가 이 그룹의 리스트가 아님 |    400    |
| 대상 카드가 없거나 이 그룹의 삭제된 카드가 아님 |    404    |

삭제된 카드만 대상으로 하는 경로이므로 삭제되지 않은 카드는 [소프트 삭제된 카드·기록](../global.md#소프트-삭제된-카드기록)에 따라 404다.

## 테스트 케이스

1. 그룹원은 삭제된 카드를 복구할 수 있다
   - `targetListId`를 보내면 204 응답과 함께 그 리스트의 맨 끝으로 카드를 복구한다
   - 삭제 표시가 해제되고 그룹·대상 리스트의 카드 수가 각각 1 늘어난다. 그룹의 기록 수에는 카드의 삭제되지 않은 기록 수를 더한다
   - 카드 복구 로그를 남기고 최근 활동 일시를 갱신한다
2. 복구한 요청자에게 경험치를 준다
   - 카드 생성자가 아닌 요청자에게 +1 exp를 지급한다
3. 복구할 리스트는 이 그룹에 있어야 한다
   - `targetListId`가 없거나 타입이 잘못되거나, 없는 리스트이거나 다른 그룹 리스트면 400 에러를 반환한다
4. 삭제되지 않은 카드는 이 경로의 대상이 아니다
   - 이미 복구됐거나 삭제되지 않은 카드면 404 에러를 반환하며 카운트·경험치·로그를 다시 반영하지 않는다
5. 종료된 그룹에서는 카드를 복구할 수 없다
   - 그룹이 `SUCCESS`·`FAIL` 상태면 400 에러를 반환한다
6. 중단된 그룹에서 카드를 복구하면 그룹이 다시 진행 중이 된다
   - 그룹 상태가 `PROGRESS`로 전환된다
7. 그룹원만 카드를 복구할 수 있다
   - 그룹원이 아니면 403, 인증되지 않으면 401 에러를 반환한다
8. 경로의 그룹·카드가 있어야 한다
   - 그룹이 없거나, 카드가 없거나 다른 그룹의 카드면 404 에러를 반환한다
9. 거부된 요청은 아무것도 바꾸지 않는다
   - 400·401·403·404 응답에서는 카드 상태·소속·위치, 카운트와 경험치·알림·로그·최근 활동 일시·그룹 상태를 바꾸지 않는다
10. 카드 안에서 개별 삭제된 기록은 복구하지 않는다
    - 삭제되지 않은 기록 3개와 개별 삭제된 기록 2개가 있는 카드를 복구하면 그룹 기록 수는 3만 늘어나고 카드의 `recordCount`는 3으로 유지된다. 개별 삭제된 2개 기록은 삭제 상태를 유지한다
    - 기록이 없는 카드는 카드 수만 늘어나고 그룹 기록 수는 바뀌지 않는다
11. 실패하거나 동시에 복구해도 카운트가 어긋나지 않는다
    - 트랜잭션이 실패하면 카드 상태·소속·위치, 그룹·리스트 카운트와 경험치·로그·최근 활동 일시·그룹 상태를 함께 되돌린다
    - 같은 카드의 동시 복구는 한 요청만 성공하고 나머지는 404다. 그룹·대상 리스트의 카드 수 증가, 그룹 기록 수 복원과 경험치·로그는 한 번만 반영된다
