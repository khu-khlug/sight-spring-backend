# 삭제된 카드 목록 조회

그룹에서 삭제한 카드 목록을 최근에 삭제한 것부터 조회합니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
GET /groups/:groupId/deleted-cards
```

## 권한

USER and 그룹원

## 조건

(해당 없음)

## 제한

- 한 번에 받는 카드 수는 최대 20개이며, 더 필요하면 `page`를 1 늘려 다시 요청해야 함

## 부수 효과

(해당 없음)

## 쿼리스트링

| 이름   |    타입    | 기본값 | 설명                                          |
| :----- | :--------: | :----: | :-------------------------------------------- |
| `page` | 숫자(uint) | 0 | 0부터 시작하는 페이지 번호. 페이지당 20개 |

페이지 크기는 20개로 고정하며, `page * 20`개를 건너뛴 위치부터 최대 20개를 반환한다. 첫 페이지는 `page=0`, 다음 페이지는 `page + 1`이다. `offset`과 `limit` 옵션은 받지 않는다.

## 요청 바디

(해당 없음)

## 성공 응답

```
200 OK
```

| 이름                |    타입    | 설명                                          |
| :------------------ | :--------: | :-------------------------------------------- |
| `page` | 숫자(uint) | 조회한 페이지 번호 (요청의 `page`와 같음) |
| `totalCount`        | 숫자(uint) | 삭제된 카드 총 수 |
| `receivedCount`     | 숫자(uint) | 받은 카드 수 (`cards` 길이)                   |
| `cards`             | 객체 배열  | 카드 목록. 삭제 일시 내림차순                 |
| `cards.id`          |   10진 문자열   | 카드 아이디                                   |
| `cards.title`       |   문자열   | 카드명                                        |
| `cards.authorName`  |   문자열   | 카드 생성자 실명                              |
| `cards.recordCount` | 숫자(uint) | 카드의 기록 수                                |
| `cards.createdAt`   |   문자열   | 카드 생성 일시 (ISO 8601 UTC, `Z` 접미사)     |
| `cards.deletedAt`   |   문자열   | 카드 삭제 일시 (ISO 8601 UTC, `Z` 접미사)     |

### 페이지네이션

다음 페이지는 `(page + 1) * 20 < totalCount`인 경우에만 남아 있다. 조회할 페이지의 시작 위치가 전체 개수 이상이면 빈 배열과 `receivedCount: 0`을 반환하고, `page`는 요청 값을 유지한다.

## 정렬 동률 처리

삭제 일시가 같으면 카드 아이디 내림차순이다. 페이지 연속성은 조회 사이 데이터 변경이 없는 경우를 기준으로 한다.

## 테스트 케이스

1. 그룹원은 삭제된 카드 목록을 조회할 수 있다
   - 200 응답과 함께 이 그룹의 삭제된 카드만 삭제 일시 내림차순으로 최대 20개 반환한다
   - 카드 아이디·제목·생성자 실명·기록 수·생성 일시·삭제 일시를 반환한다. 시각은 UTC ISO 8601 `Z` 형식이다
2. 삭제 일시가 같으면 아이디 순으로 정렬한다
   - 카드 아이디 내림차순이며, 페이지 경계에서도 누락·중복이 없다
3. `page`로 범위를 나눠 조회한다
   - 21개가 있으면 첫 응답은 20개, `page=1`이면 1개를 반환한다. `page * 20 >= totalCount`이면 빈 배열이다
   - 응답 `page`는 요청한 페이지 번호, `receivedCount`는 반환한 개수, `totalCount`는 이 그룹의 삭제된 카드 수다
   - 음수·소수·숫자가 아닌 `page`는 400 에러를 반환한다
4. 그룹 상태와 관계없이 조회할 수 있다
   - 중단·종료 그룹에서도 그룹원이면 200 응답을 반환한다
5. 그룹원만 조회할 수 있다
   - 공개 그룹이라도 그룹원이 아니면 403, 인증되지 않으면 401, 그룹이 없으면 404 에러를 반환한다
