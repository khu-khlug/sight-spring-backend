# 보관한 기록 목록 조회

보관한 기록 목록을 조회합니다. 요청자가 이 그룹에서 개인 보관함에 저장한 기록만 최근에 보관한 것부터 반환합니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
GET /groups/:groupId/saved-records
```

## 권한

USER and 그룹원

## 조건

(해당 없음)

## 제한

- 한 번에 받는 기록 수는 최대 10개이며, 더 필요하면 `skip`을 늘려 다시 요청해야 함
  - 10개인 이유: 기록 본문 전체를 담아 항목 하나가 무거우므로, 카드창의 기록 목록 조회와 같은 크기로 맞춤

## 부수 효과

(해당 없음)

## 쿼리스트링

| 이름   |    타입    | 기본값 | 설명                                         |
| :----- | :--------: | :----: | :------------------------------------------- |
| `skip` | 숫자(uint) |   0    | 최근 보관한 기록부터 n개를 건너뛰고 반환     |

## 요청 바디

(해당 없음)

## 성공 응답

```
200 OK
```

| 이름                 |    타입    | 설명                                                  |
| :------------------- | :--------: | :---------------------------------------------------- |
| `skip`               | 숫자(uint) | 건너뛴 개수 (요청의 `skip`과 같음)                    |
| `totalCount`         | 숫자(uint) | 보관한 기록 총 수 |
| `receivedCount`      | 숫자(uint) | 받은 기록 수 (`records` 길이)                         |
| `records`            | 객체 배열  | 기록 목록. 보관 일시 내림차순                         |
| `records.recordId`   |   문자열   | 기록 아이디                                           |
| `records.type`       |    enum    | 본문 형식. `TIPTAP` \| `LEGACY`                       |
| `records.content`    |   문자열   | 기록 본문                                             |
| `records.cardId`     |   문자열   | 기록이 속한 카드 아이디                               |
| `records.cardTitle`  |   문자열   | 기록이 속한 카드명                                    |
| `records.authorName` |   문자열   | 기록 작성자 실명                                      |
| `records.createdAt`  |   문자열   | 기록 작성 일시 (ISO 8601 UTC, `Z` 접미사)             |
| `records.savedAt`    |   문자열   | 보관 일시 (ISO 8601 UTC, `Z` 접미사)                  |
| `records.files`      | 객체 배열  | 기록에 연결된 첨부 파일과 읽기 링크. 형식은 [기록 첨부 파일의 조회 응답 파일 매핑](../global.md#조회-응답의-파일-매핑)을 따름 |

### 본문 반환 규칙

- `TIPTAP`·`LEGACY` 본문 모두 저장된 값을 그대로 반환한다. 서버는 본문을 파싱하거나 정제하지 않는다.
