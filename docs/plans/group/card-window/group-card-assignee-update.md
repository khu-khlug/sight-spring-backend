# 카드 담당자 변경

카드의 담당자를 지정하거나 해제합니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
PUT /groups/:groupId/cards/:cardId/assignee
```

## 권한

USER and 그룹원

## 조건

- 그룹이 종료(`SUCCESS`·`FAIL`) 상태가 아니어야 함
- 카드가 삭제되지 않아야 함
- 신규 담당자(`assigneeUserId`)를 지정하면 현재 그룹원이어야 함

## 부수 효과

### 그룹 상태

실제 변경이 발생하면 중단 상태를 진행 중으로 자동 전환한다. [그룹 공통 사항](../global.md#활동에-따른-중단-상태-해제)을 따른다.

### 경험치 변동

(해당 없음)

### 알림

- 담당자가 바뀌면 변경 전 담당자에게 담당 해제 알림. 담당자를 해제(`assigneeUserId: null`)한 경우도 포함하며, 변경 전 담당자가 없었으면 보내지 않음
- 담당자가 새로 지정될 때마다 지정된 담당자에게 담당 지정 알림. 과거에 같은 회원에게 지정 알림을 보낸 적이 있어도 다시 보냄 (예: A 지정 → 해제 → A 지정이면 A에게 지정 알림을 두 번 보내게 됨)
- 현재 담당자와 같은 회원으로 요청하면 변경 없이 성공하며 알림을 보내지 않음. [같은 값의 재요청](../global.md#같은-값의-재요청)을 따름

### 그룹 활동 로그

그룹 활동 로그에 담당자 변경을 기록하고 최근 활동 일시를 갱신함

## 쿼리스트링

(해당 없음)

## 요청 바디

| 이름 | 타입 | 설명 |
| :-- | :--: | :-- |
| `assigneeUserId` | 숫자(Long) 또는 null | 필수. 담당 회원 아이디. null이면 해제 |

## 성공 응답

```
204 No Content
```

(해당 없음)

## 실패 응답

| :-- | :--: |
| 종료된 그룹임 | 400 |

| 삭제된 카드임 | 404 |
