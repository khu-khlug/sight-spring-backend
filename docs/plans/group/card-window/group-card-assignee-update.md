# 카드 담당자 변경

카드의 담당자를 지정하거나 해제합니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
PUT /groups/:groupId/cards/:cardId/assignee
```

## 권한

USER and 그룹원

## 조건

- 그룹이 종료(`SUCCESS`·`FAIL`) 상태가 아니어야 함
- 카드가 삭제되지 않은 활성 상태여야 함. [카드 활성 상태별 동작](group-card-disabled-update.md#비활성-상태의-동작)을 따름
- 신규 담당자(`assigneeUserId`)를 지정하면 현재 그룹원이어야 함

## 부수 효과

### 그룹 상태

실제 변경이 발생하면 중단 상태를 진행 중으로 자동 전환한다. [그룹 공통 사항](../global.md#활동에-따른-중단-상태-해제)을 따른다.

### 경험치 변동

(해당 없음)

### 알림

- 담당자가 바뀌면 변경 전 담당자에게 담당 해제 알림. 담당자를 해제(`assigneeUserId: null`)한 경우도 포함하며, 변경 전 담당자가 없었으면 보내지 않음
- 담당자가 새로 지정될 때마다 지정된 담당자에게 담당 지정 알림. 과거에 같은 회원에게 지정 알림을 보낸 적이 있어도 다시 보냄 (예: A 지정 → 해제 → A 지정이면 A에게 지정 알림을 두 번 보내게 됨)
- 현재 담당자와 같은 회원으로 요청하면 변경 없이 성공하며 알림을 보내지 않음. [같은 값의 재요청](../global.md#같은-값의-재요청)을 따름

### 그룹 활동 로그

그룹 활동 로그에 담당자 변경을 기록하고 최근 활동 일시를 갱신함

## 쿼리스트링

(해당 없음)

## 요청 바디

| 이름 | 타입 | 설명 |
| :-- | :--: | :-- |
| `assigneeUserId` | 숫자(Long) 또는 null | 필수. 담당 회원 아이디. null이면 해제 |

## 성공 응답

```
204 No Content
```

(해당 없음)

## 실패 응답

[그룹 공통 실패 응답](../global.md#공통-실패-응답)을 함께 적용한다.

| 상황 | 응답 코드 |
| :-- | :--: |
| 종료된 그룹임 | 400 |
| 담당자가 현재 그룹원이 아님 | 400 |
| 비활성 카드임 | 400 |
| 삭제된 카드임 | 400 |

## 테스트 케이스

1. 그룹원은 카드 담당자를 지정할 수 있다
   - 현재 그룹원의 아이디를 보내면 204 응답과 함께 담당자가 바뀌고, 담당자 변경 로그를 남기고 최근 활동 일시를 갱신한다
   - 기존 담당자에게 해제 알림, 새 담당자에게 지정 알림을 보낸다. 기존 담당자가 없으면 해제 알림은 없다
2. 담당자를 해제할 수 있다
   - `assigneeUserId`가 null이면 204 응답과 함께 담당자가 해제되고, 기존 담당자에게 해제 알림을 보낸다
3. 담당자가 새로 지정될 때마다 지정 알림을 보낸다
   - A 지정 → 해제 → A 지정 순서로 요청하면 A에게 지정 알림이 두 번 간다
4. 현재와 같은 담당자로 요청하면 아무것도 바뀌지 않는다
   - 현재 담당자와 같은 아이디, 또는 담당자가 없을 때 null을 보내면 204 응답을 반환하고 알림·로그를 남기지 않는다
5. 담당자는 현재 그룹원이어야 한다
   - `assigneeUserId`가 없거나 타입이 잘못되면 400 에러를 반환한다
   - 그룹원이 아닌 회원을 지정하면 400 에러를 반환한다
6. 종료된 그룹에서는 담당자를 바꿀 수 없다
   - 그룹이 `SUCCESS`·`FAIL` 상태면 400 에러를 반환한다
7. 중단된 그룹에서 담당자를 바꾸면 그룹이 다시 진행 중이 된다
   - 실제로 담당자가 바뀌면 그룹 상태가 `PROGRESS`로 전환된다
8. 비활성·삭제된 카드의 담당자는 바꿀 수 없다
   - 비활성 카드나 삭제된 카드면 400 에러를 반환한다
9. 그룹원만 담당자를 바꿀 수 있다
   - 그룹원이 아니면 403, 인증되지 않으면 401 에러를 반환한다
10. 경로의 그룹·카드가 있어야 한다
    - 그룹이 없거나, 카드가 없거나 다른 그룹의 카드면 404 에러를 반환한다
11. 거부된 요청은 아무것도 바꾸지 않는다
    - 400·401·403·404 응답에서는 데이터와 경험치·알림·로그·최근 활동 일시·그룹 상태를 바꾸지 않는다
