# 카드 커버 이미지 제거

카드의 커버 이미지를 제거합니다. 커버 지정은 [카드 커버 이미지 지정](group-card-cover-image-update.md)을 따릅니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
DELETE /groups/:groupId/cards/:cardId/cover-image
```

## 권한

USER and 그룹원

## 조건

- 그룹이 종료(`SUCCESS`·`FAIL`) 상태가 아니어야 함
- 카드가 삭제되지 않은 활성 상태여야 함. [카드 활성 상태별 동작](group-card-disabled-update.md#비활성-상태의-동작)을 따름
- 커버가 없는 카드면 변경 없이 성공함

## 저장 처리

커버가 업로드한 파일이면 커버 해제와 업로드 기록의 삭제 표시를 한 트랜잭션에서 처리하고, 커밋 후 [파일 삭제 흐름](../global.md#삭제-흐름)으로 R2 파일을 지운다. 외부 URL 커버는 주소만 지운다.

## 부수 효과

## 테스트 케이스

1. 그룹원은 카드 커버를 제거할 수 있다
   - 외부 URL 커버는 주소만 지우고 204 응답을 반환한다. 외부 서버에는 삭제 요청을 보내지 않는다
   - 실제로 제거되면 커버 제거 로그를 남기고 최근 활동 일시를 갱신한다
2. 업로드한 커버 파일은 커버 제거와 함께 삭제한다
   - 커버 해제와 업로드 기록의 삭제 표시를 한 트랜잭션에서 처리하고, 커밋 후 R2 파일을 지운다
   - R2 삭제에 실패해도 204 응답을 유지하고 삭제 표시를 남겨 청소에서 다시 지운다. `NoSuchKey`는 삭제 성공으로 본다
3. 커버가 없으면 아무것도 바뀌지 않는다
   - 커버가 없는 카드에 요청하면 204 응답을 반환하고 로그를 남기지 않는다
4. 종료된 그룹에서는 커버를 제거할 수 없다
   - 그룹이 `SUCCESS`·`FAIL` 상태면 400 에러를 반환한다
5. 중단된 그룹에서 커버를 제거하면 그룹이 다시 진행 중이 된다
   - 실제로 커버가 제거되면 그룹 상태가 `PROGRESS`로 전환된다
6. 비활성·삭제된 카드의 커버는 제거할 수 없다
   - 비활성 카드나 삭제된 카드면 400 에러를 반환한다
7. 그룹원만 커버를 제거할 수 있다
   - 그룹원이 아니면 403, 인증되지 않으면 401 에러를 반환한다
8. 경로의 그룹·카드가 있어야 한다
   - 그룹이 없거나, 카드가 없거나 다른 그룹의 카드면 404 에러를 반환한다
9. DB 처리가 실패하면 모두 되돌린다
   - 트랜잭션 도중 실패하면 커버·업로드 기록·로그를 함께 되돌리고, R2 객체는 지우지 않는다
10. 거부된 요청은 아무것도 바꾸지 않는다
    - 400·401·403·404 응답에서는 데이터와 경험치·알림·로그·최근 활동 일시·그룹 상태를 바꾸지 않는다
