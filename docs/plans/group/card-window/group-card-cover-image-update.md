# 카드 커버 이미지 지정

업로드한 파일을 카드 커버로 지정합니다. 커버는 항상 사이트에 업로드한 이미지만 사용합니다. 기존 커버가 있으면 교체합니다. 커버 제거는 [카드 커버 이미지 제거](group-card-cover-image-delete.md)를 따릅니다. 지정 후 카드 조회의 `coverImageUrl`은 [그룹 파일 조회](../group-file-get.md)의 영구 주소이며, 업로드 PUT URL이나 Presigned GET URL을 커버 주소로 저장하지 않습니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
POST /groups/:groupId/cards/:cardId/cover-image
```

## 권한

USER and 그룹원

## 조건

- 그룹이 종료(`SUCCESS`·`FAIL`) 상태가 아니어야 함
- 카드가 삭제되지 않은 활성 상태여야 함. [카드 활성 상태별 동작](group-card-disabled-update.md#비활성-상태의-동작)을 따름
- `fileUploadId`가 아래 파일 검증 흐름을 통과해야 함

### 파일 검증 흐름 (`fileUploadId`)

1. `file_upload`에서 `id = fileUploadId` row 조회 — 없으면 400
2. `api_path != "/groups/:groupId/cards/:cardId/cover-image/upload-link"` — 400
3. 발급 대상 카드가 경로의 카드와 다름 — 400
4. `memberId != 요청자` — 400
5. `isUploaded == true` (이미 사용된 key) — 400
6. 이미 삭제 처리된 파일 (삭제 대기 중이라 R2에는 아직 남아 있을 수 있음) — 400
7. R2에 해당 key 파일 미존재 — row 삭제 후 400
8. 모두 통과 → `isUploaded = true` 설정 후 진행. 기존 커버가 있으면 같은 트랜잭션에서 삭제 표시하고 커밋 후 [파일 삭제 흐름](../global.md#삭제-흐름)으로 지움

## 테스트 케이스

1. 그룹원은 업로드한 파일을 카드 커버로 지정할 수 있다
   - 본인이 이 카드의 커버 업로드 링크로 발급받아 R2에 올린 `fileUploadId`를 보내면 204 응답과 함께 커버로 지정하고 업로드 완료 표시를 남긴다
   - 커버 지정 로그를 남기고 최근 활동 일시를 갱신한다
2. `fileUploadId`가 있어야 한다
   - `fileUploadId`가 없거나 문자열이 아니면 400 에러를 반환한다
3. 커버 파일은 파일 검증 흐름을 통과해야 한다
   - 업로드 기록이 없거나, 발급 용도·대상 카드·발급자가 다르거나, 이미 사용됐거나, 삭제 표시가 있으면 400 에러를 반환한다
   - R2에 객체가 없으면 업로드 기록을 지우고 400 에러를 반환한다. 기존 커버는 유지한다
4. 커버를 교체하면 기존 파일을 삭제한다
   - 기존 커버 파일의 삭제 표시를 새 커버 저장과 같은 트랜잭션에서 처리하고, 커밋 후 R2 파일을 지운다
   - R2 삭제에 실패해도 204 응답을 유지하고 삭제 표시를 남겨 청소에서 다시 지운다
5. 종료된 그룹에서는 커버를 바꿀 수 없다
   - 그룹이 `SUCCESS`·`FAIL` 상태면 400 에러를 반환한다
6. 중단된 그룹에서 커버를 바꾸면 그룹이 다시 진행 중이 된다
   - 그룹 상태가 `PROGRESS`로 전환된다
7. 비활성·삭제된 카드의 커버는 바꿀 수 없다
   - 비활성 카드나 삭제된 카드면 400 에러를 반환한다
8. 그룹원만 커버를 바꿀 수 있다
   - 그룹원이 아니면 403, 인증되지 않으면 401 에러를 반환한다
9. 경로의 그룹·카드가 있어야 한다
   - 그룹이 없거나, 카드가 없거나 다른 그룹의 카드면 404 에러를 반환한다
10. DB 처리가 실패하면 모두 되돌린다
    - 트랜잭션 도중 실패하면 커버·업로드 기록·로그를 함께 되돌리고, 기존 R2 객체는 지우지 않는다
11. 거부된 요청은 아무것도 바꾸지 않는다
    - 400·401·403·404 응답에서는 데이터와 경험치·알림·로그·최근 활동 일시·그룹 상태를 바꾸지 않는다
