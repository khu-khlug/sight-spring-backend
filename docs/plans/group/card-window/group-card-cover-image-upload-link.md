# 카드 커버 이미지 업로드 링크 발급

카드 커버로 사용할 이미지의 업로드 링크를 발급합니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
POST /groups/:groupId/cards/:cardId/cover-image/upload-link
```

## 권한

USER and 그룹원

## 조건

- 그룹이 종료(`SUCCESS`·`FAIL`) 상태가 아니어야 함. 중단 상태에서는 발급하며 그룹 상태는 바꾸지 않음. [업로드 링크 발급의 중단 상태 예외](../global.md#중단-상태에서의-동작-제한)를 따름
- 카드가 삭제되지 않은 활성 상태여야 함. [카드 활성 상태별 동작](group-card-disabled-update.md#비활성-상태의-동작)을 따름

## 허용 형식

- `contentType`은 `image/jpeg`, `image/png`, `image/webp`, `image/gif`, `image/avif` 중 하나여야 한다.
- SVG(스크립트를 포함할 수 있음), HEIC(대부분 브라우저가 표시하지 못함), BMP·TIFF(크고 브라우저 지원이 약함)는 허용하지 않는다.
- 최대 크기와 링크 유효 시간은 [업로드 링크 기준](../global.md#업로드-링크-기준)을 따른다.

## 업로드 계약

- 발급만으로 커버가 변경되지는 않는다. 반환된 `url`로 PUT 업로드한 뒤 [커버 이미지 지정](group-card-cover-image-update.md)에 `fileUploadId`를 제출한다.
- 업로드된 파일은 [커버 이미지 지정의 파일 검증 흐름](group-card-cover-image-update.md#파일-검증-흐름-fileuploadid)으로 검증한다.

## 저장 처리

업로드 용도·발급자·대상 카드와 연결된 미사용 업로드 정보를 생성한다.

## 요청 바디

| 이름 | 타입 | 설명 |
| :-- | :--: | :-- |
| `fileName` | 문자열 | 필수. 원본 파일명 |
| `contentType` | 문자열 | 필수. 이미지 MIME 타입 |

## 성공 응답

```
200 OK
```

| 이름 | 타입 | 설명 |
| :-- | :--: | :-- |
| `url` | 문자열 | 파일을 PUT 업로드할 임시 주소 |
| `fileUploadId` | 문자열 | 커버 변경 시 제출할 업로드 아이디 |

## 실패 응답

[그룹 공통 실패 응답](../global.md#공통-실패-응답)을 함께 적용한다.

| 상황 | 응답 코드 |
| :-- | :--: |
| 종료된 그룹임 | 400 |
| 비활성 카드임 | 400 |
| 파일명 또는 MIME 타입이 없거나 허용 형식이 아님 | 400 |
| 삭제된 카드임 | 404 |
