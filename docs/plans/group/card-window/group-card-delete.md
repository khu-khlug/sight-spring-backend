# 그룹 카드 삭제

카드를 소프트 삭제하여 일반 목록에서 제외합니다. 복구는 [삭제된 카드 복구](../archive/deleted-card-restore.md)를 따릅니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
DELETE /groups/:groupId/cards/:cardId
```

## 권한

USER and 그룹원

## 조건

- 그룹이 종료(`SUCCESS`·`FAIL`) 상태가 아니어야 함
- 삭제되지 않은 카드여야 함. 비활성 카드도 삭제할 수 있음

## 저장 처리

- 복구를 위해 소속 기록과 첨부 파일을 삭제하지 않고 보존한다.
- 삭제한 카드는 소속 리스트에서 빠진다. 복구할 때는 지정한 리스트의 맨 끝으로 다시 들어간다.
- 그룹·리스트의 카드 수와 그룹의 조회 대상 기록 수를 함께 반영한다.

## 부수 효과

### 그룹 상태

실제 변경이 발생하면 중단 상태를 진행 중으로 자동 전환한다. [그룹 공통 사항](../global.md#활동에-따른-중단-상태-해제)을 따른다.

### 경험치 변동

| 대상 | 변동 |
| :-- | :--: |
| 카드 생성자 | -1 |

요청자와 생성자가 달라도 생성자에게 차감함

### 알림

(해당 없음)

### 그룹 활동 로그

그룹 활동 로그에 카드 삭제를 기록하고 최근 활동 일시를 갱신함
