# 그룹 카드 삭제

카드를 소프트 삭제하여 일반 목록에서 제외합니다. 복구는 [삭제된 카드 복구](../archive/deleted-card-restore.md)를 따릅니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
DELETE /groups/:groupId/cards/:cardId
```

## 권한

USER and 그룹원

## 조건

- 그룹이 종료(`SUCCESS`·`FAIL`) 상태가 아니어야 함
- 삭제되지 않은 카드여야 함. 비활성 카드도 삭제할 수 있음

## 저장 처리

- 복구를 위해 소속 기록과 첨부 파일을 삭제하지 않고 보존한다.
- 삭제한 카드는 소속 리스트에서 빠진다. 복구할 때는 지정한 리스트의 맨 끝으로 다시 들어간다.
- 그룹·리스트의 카드 수와 그룹의 조회 대상 기록 수를 함께 반영한다.

## 부수 효과

### 그룹 상태

실제 변경이 발생하면 중단 상태를 진행 중으로 자동 전환한다. [그룹 공통 사항](../global.md#활동에-따른-중단-상태-해제)을 따른다.

### 경험치 변동

| 대상 | 변동 |
| :-- | :--: |
| 카드 생성자 | -1 |

요청자와 생성자가 달라도 생성자에게 차감함

| :-- | :--: |
| 종료된 그룹임 | 400 |
| 이미 삭제된 카드임 | 400 |

## 테스트 케이스

1. 그룹원은 카드를 삭제할 수 있다
   - 204 응답과 함께 카드를 소프트 삭제하고 소속 리스트에서 뺀다
   - 그룹·리스트의 카드 수와 그룹의 조회 대상 기록 수를 반영한다. 카드의 기록과 첨부 파일은 복구를 위해 보존한다
   - 카드 삭제 로그를 남기고 최근 활동 일시를 갱신한다
2. 카드 생성자의 경험치를 차감한다
   - 요청자와 생성자가 달라도 카드 생성자에게 -1 exp를 적용한다
3. 비활성 카드도 삭제할 수 있다
   - 비활성 카드에 요청해도 204 응답과 함께 삭제한다
4. 이미 삭제된 카드는 다시 삭제할 수 없다
   - 400 에러를 반환하며 경험치·카운트를 다시 차감하지 않는다
5. 종료된 그룹에서는 카드를 삭제할 수 없다
   - 그룹이 `SUCCESS`·`FAIL` 상태면 400 에러를 반환한다
6. 중단된 그룹에서 카드를 삭제하면 그룹이 다시 진행 중이 된다
   - 실제로 삭제되면 그룹 상태가 `PROGRESS`로 전환된다
7. 그룹원만 카드를 삭제할 수 있다
   - 그룹원이 아니면 403, 인증되지 않으면 401 에러를 반환한다
8. 경로의 그룹·카드가 있어야 한다
   - 그룹이 없거나, 카드가 없거나 다른 그룹의 카드면 404 에러를 반환한다
9. 거부된 요청은 아무것도 바꾸지 않는다
   - 400·401·403·404 응답에서는 데이터와 경험치·알림·로그·최근 활동 일시·그룹 상태를 바꾸지 않는다
