# 카드 활성 상태 변경

카드를 비활성화하거나 다시 활성화합니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
PUT /groups/:groupId/cards/:cardId/disabled
```

## 권한

USER and 그룹원

## 조건

- 그룹이 종료(`SUCCESS`·`FAIL`) 상태가 아니어야 함
- 카드가 삭제되지 않아야 함

## 비활성 상태의 동작

- 비활성화는 삭제와 다르다. 카드와 기록을 보존하고 목록에 `isDisabled` 상태를 반환한다.
- 비활성 카드는 카드 목록·단건 조회에 포함하며 기존 기록도 조회할 수 있다.
- 비활성 카드의 이름·설명·커버·레이블·담당자·포트폴리오 포함 변경과 기록 작성·수정·삭제·복구·이동·포트폴리오 포함 변경은 거부한다. 재활성화·카드 삭제·카드 위치 변경은 허용한다.

## 부수 효과

### 그룹 상태

실제 변경이 발생하면 중단 상태를 진행 중으로 자동 전환한다. [그룹 공통 사항](../global.md#활동에-따른-중단-상태-해제)을 따른다.

### 경험치 변동

(해당 없음)

### 알림

실제 상태가 변경되면 그룹원 전체에게 활성화·비활성화 알림

### 그룹 활동 로그

실제 변경 시 그룹 활동 로그에 카드 상태 변경을 기록하고 최근 활동 일시를 갱신함

## 쿼리스트링

(해당 없음)

## 요청 바디

| 이름 | 타입 | 설명 |
| :-- | :--: | :-- |
| `isDisabled` | 불리언 | 필수. true이면 비활성화, false이면 재활성화 |

## 성공 응답

```
204 No Content
```

(해당 없음)

## 실패 응답

[그룹 공통 실패 응답](../global.md#공통-실패-응답)을 함께 적용한다.

| 상황 | 응답 코드 |
| :-- | :--: |
| 종료된 그룹임 | 400 |
| `isDisabled`가 없거나 불리언이 아님 | 400 |
| 삭제된 카드임 | 400 |

## 테스트 케이스

1. 그룹원은 카드를 비활성화하거나 다시 활성화할 수 있다
   - `isDisabled: true`면 비활성화, false면 재활성화하고 204 응답을 반환한다. 카드·기록·첨부 파일은 보존한다
   - 실제로 바뀌면 그룹원 전체에게 활성화·비활성화 알림을 보내고, 상태 변경 로그를 남기고 최근 활동 일시를 갱신한다
2. 비활성 카드는 내용을 바꿀 수 없다
   - 목록·단건 조회와 기존 기록 조회는 할 수 있다
   - 이름·설명·커버·레이블·담당자·포트폴리오 포함 변경과 기록 작성·수정·삭제·복구·이동·포트폴리오 포함 변경은 400 에러를 반환한다
   - 재활성화·카드 삭제·카드 위치 변경은 할 수 있다
3. 현재와 같은 상태로 요청하면 아무것도 바뀌지 않는다
   - 204 응답을 반환하고 알림·로그를 남기지 않는다
4. `isDisabled`는 불리언이어야 한다
   - 없거나 null이거나 불리언이 아니면 400 에러를 반환한다
5. 종료된 그룹에서는 활성 상태를 바꿀 수 없다
   - 그룹이 `SUCCESS`·`FAIL` 상태면 400 에러를 반환한다
6. 중단된 그룹에서 활성 상태를 바꾸면 그룹이 다시 진행 중이 된다
   - 실제로 바뀌면 그룹 상태가 `PROGRESS`로 전환된다
7. 삭제된 카드의 활성 상태는 바꿀 수 없다
   - 삭제된 카드면 400 에러를 반환한다
8. 그룹원만 활성 상태를 바꿀 수 있다
   - 그룹원이 아니면 403, 인증되지 않으면 401 에러를 반환한다
9. 경로의 그룹·카드가 있어야 한다
   - 그룹이 없거나, 카드가 없거나 다른 그룹의 카드면 404 에러를 반환한다
10. 거부된 요청은 아무것도 바꾸지 않는다
    - 400·401·403·404 응답에서는 데이터와 경험치·알림·로그·최근 활동 일시·그룹 상태를 바꾸지 않는다
