# 카드 활성 상태 변경

카드를 비활성화하거나 다시 활성화합니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
PUT /groups/:groupId/cards/:cardId/disabled
```

## 권한

USER and 그룹원

## 조건

- 그룹이 종료(`SUCCESS`·`FAIL`) 상태가 아니어야 함
- 카드가 삭제되지 않아야 함

## 비활성 상태의 동작

- 비활성화는 삭제와 다르다. 카드와 기록을 보존하고 목록에 `isDisabled` 상태를 반환한다.
- 비활성 카드는 카드 목록·단건 조회에 포함하며 기존 기록도 조회할 수 있다.
- 비활성 카드의 이름·설명·커버 수정과 기록 작성·수정·삭제·복구·이동·포트폴리오 포함 변경은 거부한다. 재활성화와 카드 삭제는 허용한다.

## 부수 효과

### 그룹 상태

실제 변경이 발생하면 중단 상태를 진행 중으로 자동 전환한다. [그룹 공통 사항](../global.md#활동에-따른-중단-상태-해제)을 따른다.

### 경험치 변동

(해당 없음)

### 알림

실제 상태가 변경되면 그룹원 전체에게 활성화·비활성화 알림

### 그룹 활동 로그

실제 변경 시 그룹 활동 로그에 카드 상태 변경을 기록하고 최근 활동 일시를 갱신함

## 쿼리스트링

(해당 없음)

## 요청 바디

| 이름 | 타입 | 설명 |
| :-- | :--: | :-- |
| `isDisabled` | 불리언 | 필수. true이면 비활성화, false이면 재활성화 |

## 성공 응답

```
204 No Content
```

(해당 없음)

## 실패 응답

[그룹 공통 실패 응답](../global.md#공통-실패-응답)을 함께 적용한다.

| 상황 | 응답 코드 |
| :-- | :--: |
| 종료된 그룹임 | 400 |
| `isDisabled`가 없거나 불리언이 아님 | 400 |
| 삭제된 카드임 | 404 |
