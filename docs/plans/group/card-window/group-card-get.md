# 카드 단건 조회

카드 요약과 설명, 소속 리스트 정보를 조회합니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
GET /groups/:groupId/cards/:cardId
```

## 권한

USER and 열람권한

## 조건

(해당 없음)

## 부수 효과

(해당 없음)

## 쿼리스트링

(해당 없음)

## 요청 바디

(해당 없음)

## 성공 응답

```
200 OK
```

[카드 요약 필드](../kanban/group-cards-get.md#카드-요약-필드)에 아래 필드를 추가한 객체를 반환한다. 비활성 카드도 조회할 수 있으며 기록 목록은 포함하지 않는다.

| 이름 | 타입 | 설명 |
| :-- | :--: | :-- |
| `listId` | 문자열 | 소속 리스트 아이디 |
| `listTitle` | 문자열 | 소속 리스트 이름 |
| `description` | 문자열 | 카드 설명 Markdown 원문. 없으면 빈 문자열 |
| `recordSort` | 문자열 | 카드에 저장된 기록 정렬 설정. `NEWEST`, `OLDEST`, `RECENTLY_UPDATED` |

### 레거시 카드 설명

- 레거시 카드 설명이 플레인텍스트인지 HTML인지 확인이 필요하다.
- 플레인텍스트이면 저장된 값을 그대로 반환한다.
- HTML이면 저장된 값을 그대로 반환하지 않고, 위 `description` 응답 형식에 맞게 처리한 뒤 반환한다. 구체적인 처리 방식은 레거시 형식을 확인한 후 확정한다.
