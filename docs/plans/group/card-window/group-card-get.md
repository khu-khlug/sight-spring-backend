# 카드 단건 조회

카드 요약과 설명, 소속 리스트 정보를 조회합니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
GET /groups/:groupId/cards/:cardId
```

## 권한

USER and 열람권한

## 조건

(해당 없음)

## 부수 효과

(해당 없음)

## 쿼리스트링

(해당 없음)

## 요청 바디

(해당 없음)

## 성공 응답

```
200 OK
```

[카드 요약 필드](../kanban/group-cards-get.md#카드-요약-필드)에 아래 필드를 추가한 객체를 반환한다. 비활성 카드도 조회할 수 있으며 기록 목록은 포함하지 않는다.

| 이름 | 타입 | 설명 |
| :-- | :--: | :-- |
| `listId` | 문자열 | 소속 리스트 아이디 |
| `listTitle` | 문자열 | 소속 리스트 이름 |
| `description` | 문자열 | 카드 설명 Markdown 원문. 없으면 빈 문자열 |
| `recordSort` | 문자열 | 카드에 저장된 기록 정렬 설정. `NEWEST`, `OLDEST`, `RECENTLY_UPDATED` |

### 레거시 카드 설명

- 레거시 카드 설명이 플레인텍스트인지 HTML인지 확인이 필요하다.
- 플레인텍스트이면 저장된 값을 그대로 반환한다.
- HTML이면 저장된 값을 그대로 반환하지 않고, 위 `description` 응답 형식에 맞게 처리한 뒤 반환한다. 구체적인 처리 방식은 레거시 형식을 확인한 후 확정한다.

## 실패 응답

[그룹 공통 실패 응답](../global.md#공통-실패-응답)을 함께 적용한다.

| 상황 | 응답 코드 |
| :-- | :--: |
| 삭제된 카드임 | 400 |

## 테스트 케이스

1. 열람 권한이 있는 회원은 카드를 조회할 수 있다
   - 200 응답과 함께 카드 요약 필드와 `listId`, `listTitle`, `description`, `recordSort`를 반환한다. 기록 목록은 포함하지 않는다
   - 설명이 없으면 `description`은 빈 문자열이고, 있으면 저장한 Markdown 원문을 그대로 반환한다
2. 비활성 카드도 조회할 수 있다
   - 비활성 카드는 `isDisabled: true`로 반환한다
3. 레거시 카드 설명은 응답 형식에 맞춰 반환한다
   - 플레인텍스트면 저장값을 그대로, HTML이면 원본 HTML을 노출하지 않고 `description` 형식에 맞게 처리해 반환한다
4. 그룹 상태와 관계없이 조회할 수 있다
   - 중단·종료 그룹에서도 열람 권한이 있으면 200 응답을 반환한다
5. 공개 범위에 따라 열람할 수 있는 회원이 정해진다
   - 비공개는 그룹원, 운영진 공개는 운영진, 회원 공개는 교류 회원을 제외한 회원, 완전 공개는 모든 로그인 회원이 조회할 수 있다
   - 범위 밖 회원이면 403, 인증되지 않으면 401 에러를 반환한다
6. 삭제된 카드는 조회할 수 없다
   - 삭제된 카드면 400 에러를 반환한다
7. 경로의 그룹·카드가 있어야 한다
   - 그룹이 없거나, 카드가 없거나 다른 그룹의 카드면 404 에러를 반환한다
