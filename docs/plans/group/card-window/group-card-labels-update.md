# 카드 레이블 변경

카드의 레이블 배열을 변경합니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
PUT /groups/:groupId/cards/:cardId/labels
```

## 권한

USER and 그룹원

## 조건

- 그룹이 종료(`SUCCESS`·`FAIL`) 상태가 아니어야 함
- 중단 상태에서는 실행할 수 없음. [그룹 공통 사항의 중단 상태 동작 제한](../global.md#중단-상태에서의-동작-제한)을 따름
- 카드가 삭제되지 않아야 함

## 새니타이징

- 레이블은 최대 8개이며 중복 값과 허용하지 않는 값은 거부한다.

## 저장 처리

요청한 배열로 레이블 전체를 교체한다. 레거시 저장값 `violet`은 `purple`, `white`는 `lightGray`와 대응한다. 저장소 내부의 비트마스크는 API 입력·응답에 노출하지 않고 배열로 전달한다.

## 요청 바디

| 이름 | 타입 | 설명 |
| :-- | :--: | :-- |
| `labels` | 문자열 배열 | 필수. `red`, `yellow`, `green`, `blue`, `purple`, `lightGray`, `gray`, `black`. 빈 배열이면 모두 해제 |

## 성공 응답


(해당 없음)
