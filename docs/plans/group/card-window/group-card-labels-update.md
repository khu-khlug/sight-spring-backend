# 카드 레이블 변경

카드의 레이블 배열을 변경합니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
PUT /groups/:groupId/cards/:cardId/labels
```

## 권한

USER and 그룹원

## 조건

- 그룹이 종료(`SUCCESS`·`FAIL`) 상태가 아니어야 함
- 중단 상태에서는 실행할 수 없음. [그룹 공통 사항의 중단 상태 동작 제한](../global.md#중단-상태에서의-동작-제한)을 따름
- 카드가 삭제되지 않은 활성 상태여야 함. [카드 활성 상태별 동작](group-card-disabled-update.md#비활성-상태의-동작)을 따름

## 새니타이징

- 레이블은 최대 8개이며 중복 값과 허용하지 않는 값은 거부한다.

## 저장 처리

요청한 배열로 레이블 전체를 교체한다. 레거시 저장값 `violet`은 `purple`, `white`는 `lightGray`와 대응한다. 저장소 내부의 비트마스크는 API 입력·응답에 노출하지 않고 배열로 전달한다.

## 요청 바디

| 이름 | 타입 | 설명 |
| :-- | :--: | :-- |
| `labels` | 문자열 배열 | 필수. `red`, `yellow`, `green`, `blue`, `purple`, `lightGray`, `gray`, `black`. 빈 배열이면 모두 해제 |

## 성공 응답

```
204 No Content
```

(해당 없음)

## 실패 응답

[그룹 공통 실패 응답](../global.md#공통-실패-응답)을 함께 적용한다.

| 상황 | 응답 코드 |
| :-- | :--: |
| 종료되거나 중단된 그룹임 | 400 |
| 중복·미지원 레이블이거나 8개를 초과함 | 400 |
| 비활성 카드임 | 400 |
| 삭제된 카드임 | 400 |

## 테스트 케이스

1. 그룹원은 카드 레이블을 바꿀 수 있다
   - 허용한 레이블 배열을 보내면 204 응답과 함께 기존 배열 전체를 교체한다. 빈 배열이면 모두 해제한다
   - 실제로 바뀌면 레이블 변경 로그를 남긴다. 최근 활동 일시는 갱신하지 않는다
2. 레이블은 정해진 값으로 최대 8개까지 지정할 수 있다
   - 서로 다른 허용 값 8개는 저장한다
   - 9개 이상이거나, 중복 값·허용하지 않는 값이 있거나, `labels`가 없거나 문자열 배열이 아니면 400 에러를 반환한다
3. 레거시 레이블 값은 API 값으로 대응해 반환한다
   - 레거시 `violet`은 `purple`, `white`는 `lightGray`로 다룬다. 저장 비트마스크는 노출하지 않는다
4. 현재와 같은 레이블로 요청하면 아무것도 바뀌지 않는다
   - 204 응답을 반환하고 로그를 남기지 않는다
5. 중단·종료된 그룹에서는 레이블을 바꿀 수 없다
   - 그룹이 `STOP`·`SUCCESS`·`FAIL` 상태면 400 에러를 반환한다
6. 비활성·삭제된 카드의 레이블은 바꿀 수 없다
   - 비활성 카드나 삭제된 카드면 400 에러를 반환한다
7. 그룹원만 레이블을 바꿀 수 있다
   - 그룹원이 아니면 403, 인증되지 않으면 401 에러를 반환한다
8. 경로의 그룹·카드가 있어야 한다
   - 그룹이 없거나, 카드가 없거나 다른 그룹의 카드면 404 에러를 반환한다
9. 거부된 요청은 아무것도 바꾸지 않는다
   - 400·401·403·404 응답에서는 데이터와 경험치·알림·로그·최근 활동 일시·그룹 상태를 바꾸지 않는다
