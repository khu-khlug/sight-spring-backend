# 카드 포트폴리오 포함 변경

카드를 포트폴리오에 포함할지 변경합니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
PUT /groups/:groupId/cards/:cardId/portfolio
```

## 권한

USER and 그룹원

## 조건

- 그룹이 종료(`SUCCESS`·`FAIL`) 상태가 아니어야 함
- 중단 상태에서는 실행할 수 없음. [그룹 공통 사항의 중단 상태 동작 제한](../global.md#중단-상태에서의-동작-제한)을 따름
- 카드가 삭제되지 않은 활성 상태여야 함. [카드 활성 상태별 동작](group-card-disabled-update.md#비활성-상태의-동작)을 따름

## 저장 처리

카드의 포함 여부만 변경하며 그룹 포트폴리오 발행 여부는 변경하지 않는다.

## 실패 응답

[그룹 공통 실패 응답](../global.md#공통-실패-응답)을 함께 적용한다.

| 상황 | 응답 코드 |
| :-- | :--: |
| 종료되거나 중단된 그룹임 | 400 |
| 비활성 카드임 | 400 |
| `isInPortfolio`가 없거나 불리언이 아님 | 400 |
| 삭제된 카드임 | 400 |

## 테스트 케이스

1. 그룹원은 카드의 포트폴리오 포함 여부를 바꿀 수 있다
   - `isInPortfolio`를 보내면 204 응답과 함께 카드의 포함 여부만 바꾼다. 그룹 포트폴리오 발행 여부는 그대로다
   - 실제로 바뀌면 카드 포트폴리오 포함 변경 로그를 남긴다. 최근 활동 일시는 갱신하지 않는다
2. 현재와 같은 값으로 요청하면 아무것도 바뀌지 않는다
   - 204 응답을 반환하고 로그를 남기지 않는다
3. `isInPortfolio`는 불리언이어야 한다
   - 없거나 null이거나 불리언이 아니면 400 에러를 반환한다
4. 중단·종료된 그룹에서는 포함 여부를 바꿀 수 없다
   - 그룹이 `STOP`·`SUCCESS`·`FAIL` 상태면 400 에러를 반환한다
5. 비활성·삭제된 카드의 포함 여부는 바꿀 수 없다
   - 비활성 카드나 삭제된 카드면 400 에러를 반환한다
6. 그룹원만 포함 여부를 바꿀 수 있다
   - 그룹원이 아니면 403, 인증되지 않으면 401 에러를 반환한다
7. 경로의 그룹·카드가 있어야 한다
   - 그룹이 없거나, 카드가 없거나 다른 그룹의 카드면 404 에러를 반환한다
8. 거부된 요청은 아무것도 바꾸지 않는다
   - 400·401·403·404 응답에서는 데이터와 경험치·알림·로그·최근 활동 일시·그룹 상태를 바꾸지 않는다
