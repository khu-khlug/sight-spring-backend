# 카드 포트폴리오 포함 변경

카드를 포트폴리오에 포함할지 변경합니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
PUT /groups/:groupId/cards/:cardId/portfolio
```

## 권한

USER and 그룹원

## 조건

- 그룹이 종료(`SUCCESS`·`FAIL`) 상태가 아니어야 함
- 중단 상태에서는 실행할 수 없음. [그룹 공통 사항의 중단 상태 동작 제한](../global.md#중단-상태에서의-동작-제한)을 따름
- 카드가 삭제되지 않아야 함

## 저장 처리

카드의 포함 여부만 변경하며 그룹 포트폴리오 발행 여부는 변경하지 않는다.

### 그룹 활동 로그

실제 변경 시 그룹 활동 로그에 카드 포트폴리오 포함 변경을 기록함. 최근 활동 일시는 갱신하지 않음
