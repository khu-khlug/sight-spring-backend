# 카드 기록 목록 조회

카드가 소유한 기록 목록을 조회합니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
GET /groups/:groupId/cards/:cardId/records
```

## 권한

USER and 열람권한

## 조건

- 카드가 삭제되지 않아야 함. 비활성 카드의 기존 기록은 조회할 수 있음
- 삭제된 기록 포함(`includeDeleted=true`)은 요청자가 그룹원일 때만 허용함

## 정렬·범위

- `NEWEST`: `createdAt` 내림차순, 같으면 기록 아이디 내림차순
- `OLDEST`: `createdAt` 오름차순, 같으면 기록 아이디 오름차순
- `RECENTLY_UPDATED`: `updatedAt` 내림차순, 같으면 기록 아이디 내림차순
- `totalCount`는 열람권한과 삭제 포함 여부 등 필터링이 적용된 후 조회 가능한 전체 기록 수다.
- 기록 정렬 방향은 카드별 공통 설정으로 영구 저장하며, 기본값은 최신순이다. 회원 개인 설정이 아니다.
- 카드에 저장된 `recordSort`를 적용한다. 정렬 설정은 [카드 정보 변경](group-card-update.md)으로 변경한다.

## 부수 효과

(해당 없음)

## 쿼리스트링

| 이름 | 타입 | 설명 |
| :-- | :--: | :-- |
| `skip` | 숫자(uint) | 기본 0. 건너뛸 개수 |
| `limit` | 숫자(uint) | 기본 10. 1~100 |
| `includeDeleted` | 불리언 | 기본 false. true는 그룹원에게만 허용 |

## 요청 바디

(해당 없음)

## 성공 응답

```
200 OK
```

| 이름 | 타입 | 설명 |
| :-- | :--: | :-- |
| `skip` | 숫자(uint) | 건너뛴 기록 개수 (요청의 `skip`과 같음) |
| `totalCount` | 숫자(uint) | 삭제 포함 여부와 권한을 적용한 전체 기록 수 |
| `receivedCount` | 숫자(uint) | 이번에 반환한 기록 수 |
| `records` | 객체 배열 | 기록 목록. 각 항목은 [기록 필드](../edit-window/group-record-get.md#기록-필드)를 따름 |

다음 시작 위치는 `skip + receivedCount`다. `skip`이 전체 개수 이상이면 빈 배열을 반환한다.

## 실패 응답

[그룹 공통 실패 응답](../global.md#공통-실패-응답)을 함께 적용한다.

| 상황 | 응답 코드 |
| :-- | :--: |
| 페이지네이션·불리언 값이 잘못됨 | 400 |
| 그룹원이 아닌 요청자가 삭제된 기록 포함을 요청함 | 403 |
| 삭제된 카드임 | 404 |
