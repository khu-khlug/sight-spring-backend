# 그룹 카드 수정

카드의 이름, 설명과 기록 정렬 설정을 변경합니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
PATCH /groups/:groupId/cards/:cardId
```

## 권한

USER and 그룹원

## 조건

- 그룹이 종료(`SUCCESS`·`FAIL`) 상태가 아니어야 함
- 카드가 삭제되지 않은 활성 상태여야 함. [카드 활성 상태별 동작](group-card-disabled-update.md#비활성-상태의-동작)을 따름
- 수정할 필드를 하나 이상 포함해야 함. 생략한 필드는 유지하며 null은 허용하지 않음

## 새니타이징

- 이름은 앞뒤 공백을 제거하고, 공백만 있는 값과 255자를 초과한 값은 거부한다.
- 설명 입력은 UTF-8 인코딩 기준 최대 4 KiB(4,096바이트)까지 허용하며, 초과하면 400으로 거부한다. Markdown 문법과 공백·줄바꿈도 바이트 수에 포함한다.
- 설명은 Markdown 원문 그대로 저장한다. 서버는 설명을 파싱하거나 정제하지 않으며, 표시할 때의 정제는 프런트가 한다.
- `recordSort`는 `NEWEST`, `OLDEST`, `RECENTLY_UPDATED`만 허용한다.

## 저장 처리

`recordSort`는 카드별 공통 설정으로 영구 저장한다. 이후 기록 목록 조회는 저장된 설정을 따른다.

## 부수 효과

### 그룹 상태

실제 변경이 발생하면 중단 상태를 진행 중으로 자동 전환한다. [그룹 공통 사항](../global.md#활동에-따른-중단-상태-해제)을 따른다.

## 요청 바디

| 이름 | 타입 | 설명 |
| :-- | :--: | :-- |
| `title` | 문자열 | 선택. 앞뒤 공백 제거 후 비어 있지 않은 이름 |
| `description` | 문자열 | 선택. Markdown 원문. 빈 문자열이면 설명 제거 |
| `recordSort` | 문자열 | 선택. 기록 정렬 설정. `NEWEST`, `OLDEST`, `RECENTLY_UPDATED` |

## 성공 응답

## 실패 응답

[그룹 공통 실패 응답](../global.md#공통-실패-응답)을 함께 적용한다.

| 상황 | 응답 코드 |
| :-- | :--: |
| 종료된 그룹임 | 400 |
| 비활성 카드임 | 400 |
| 이름이나 설명이 길이 제한을 초과함 | 400 |
| 이름·설명 형식이나 `recordSort` 값이 잘못되거나 수정할 필드가 없음 | 400 |
| 삭제된 카드임 | 400 |

## 테스트 케이스

1. 그룹원은 카드 이름·설명·기록 정렬 설정을 바꿀 수 있다
   - 바꿀 필드만 보내면 204 응답과 함께 그 필드만 바뀌고, 생략한 필드는 그대로다
   - 이름·설명이 실제로 바뀌면 카드 수정 로그를 남기고 최근 활동 일시를 갱신한다. 정렬 설정만 바뀌면 로그를 남기지 않는다
2. 이름은 공백이 아닌 255자 이하여야 한다
   - 앞뒤 공백은 제거해 저장한다. 255자는 저장하고, 공백뿐이거나 256자면 400 에러를 반환한다
3. 설명은 UTF-8 4 KiB 이하의 Markdown 원문이다
   - 4,096바이트는 저장하고 4,097바이트는 400 에러를 반환한다. 한글·Markdown 문법·공백·줄바꿈도 바이트 수에 포함한다
   - 서버는 설명을 파싱·정제하지 않고 원문 그대로 저장한다. 빈 문자열이면 설명을 지운다
4. 기록 정렬 설정은 정해진 값이어야 한다
   - `NEWEST`, `OLDEST`, `RECENTLY_UPDATED`는 저장하고 이후 기록 목록 조회에 적용한다. 그 밖의 값은 400 에러를 반환한다
5. 바꿀 필드가 하나 이상 있어야 한다
   - 필드가 하나도 없거나, 필드에 null을 보내거나 타입이 잘못되면 400 에러를 반환한다
6. 현재와 같은 값으로 요청하면 아무것도 바뀌지 않는다
   - 204 응답을 반환하고 로그를 남기지 않는다
7. 종료된 그룹에서는 카드를 수정할 수 없다
   - 그룹이 `SUCCESS`·`FAIL` 상태면 400 에러를 반환한다
8. 중단된 그룹에서 카드를 수정하면 그룹이 다시 진행 중이 된다
   - 실제로 바뀌면 그룹 상태가 `PROGRESS`로 전환된다
9. 비활성·삭제된 카드는 수정할 수 없다
   - 비활성 카드나 삭제된 카드면 400 에러를 반환한다
10. 그룹원만 카드를 수정할 수 있다
    - 그룹원이 아니면 403, 인증되지 않으면 401 에러를 반환한다
11. 경로의 그룹·카드가 있어야 한다
    - 그룹이 없거나, 카드가 없거나 다른 그룹의 카드면 404 에러를 반환한다
12. 거부된 요청은 아무것도 바꾸지 않는다
    - 400·401·403·404 응답에서는 데이터와 경험치·알림·로그·최근 활동 일시·그룹 상태를 바꾸지 않는다
