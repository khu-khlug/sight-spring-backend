# 기록 개인 보관 변경

요청자 본인의 기록 개인 보관 여부를 변경합니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
PUT /groups/:groupId/records/:recordId/archive
```

## 권한

USER and 그룹원

기록 작성자가 아닌 그룹원도 요청할 수 있다.

## 조건

- 기록의 현재 소속 카드는 `recordId`로 조회하며, 해당 카드의 그룹이 `groupId`와 일치해야 함
- 그룹이 중단 상태가 아니어야 함
- `isInUserArchive: true`이면 해당 기록과 그 기록이 현재 속한 카드가 모두 삭제 상태가 아니어야 함
- `isInUserArchive: false`이면 기록·카드의 삭제 여부나 카드 활성 여부는 제한하지 않음

카드 활성 상태와 중단 상태 제한은 [카드 활성 상태별 동작](group-card-disabled-update.md#비활성-상태의-동작)과 [그룹 공통 사항](../global.md#중단-상태에서의-동작-제한)을 따른다.

## 저장 처리

true이면 원본을 복제하지 않고 요청자와 기록의 연결을 저장한다. false이면 해당 연결만 제거하며 기록 자체는 삭제하지 않는다. 다른 회원의 보관 상태는 유지한다. 이미 보관한 기록의 보관 요청과 보관하지 않은 기록의 보관 해제는 변경 없이 성공하며 부수 효과를 반복하지 않는다.

## 요청 바디

| 이름 | 타입 | 설명 |
| :-- | :--: | :-- |
| `isInUserArchive` | 불리언 | 필수. 요청자 본인의 개인 보관 여부. true는 보관, false는 보관 해제 |

## 실패 응답

[그룹 공통 실패 응답](../global.md#공통-실패-응답)을 함께 적용한다.

| 상황 | 응답 코드 |
| :-- | :--: |
| 중단된 그룹임 | 400 |
| `isInUserArchive`가 없거나 불리언이 아님 | 400 |
| 보관 추가 대상이 삭제된 기록이거나 삭제된 카드에 속함 | 404 |
| 기록이 없거나 다른 그룹의 기록임 | 404 |
