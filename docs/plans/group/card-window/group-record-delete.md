# 카드 기록 삭제

기록을 소프트 삭제합니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
DELETE /groups/:groupId/records/:recordId
```

## 권한

USER and 그룹원

## 조건

- 기록의 현재 소속 카드는 `recordId`로 조회하며, 해당 카드의 그룹이 `groupId`와 일치해야 함
- 그룹이 종료(`SUCCESS`·`FAIL`) 상태가 아니어야 함
- 해당 기록이 현재 속한 카드가 삭제되지 않은 활성 상태여야 함. [카드 활성 상태별 동작](group-card-disabled-update.md#비활성-상태의-동작)을 따름
- 삭제된 기록이 아니어야 함

## 저장 처리

본문과 첨부 파일은 보존한다. 카드·그룹의 삭제되지 않은 기록 수를 반영한다.

## 부수 효과

### 그룹 상태

실제 변경이 발생하면 중단 상태를 진행 중으로 자동 전환한다. [그룹 공통 사항](../global.md#활동에-따른-중단-상태-해제)을 따른다.

### 경험치 변동

| 대상 | 변동 |
| :-- | :--: |
| 기록 작성자 | -2 |

작성자가 아닌 다른 그룹원도 삭제할 수 있지만, 삭제 요청자가 아니라 기록 작성자에게 차감함

### 알림

(해당 없음)

### 그룹 활동 로그

그룹 활동 로그에 기록 삭제를 기록하고 최근 활동 일시를 갱신함

## 실패 응답

[그룹 공통 실패 응답](../global.md#공통-실패-응답)을 함께 적용한다.

| 상황 | 응답 코드 |
| :-- | :--: |
| 종료된 그룹임 | 400 |
| 비활성 카드임 | 400 |
| 이미 삭제된 기록임 | 400 |
| 현재 소속 카드가 삭제됨 | 400 |

## 테스트 케이스

1. 그룹원은 기록을 삭제할 수 있다
   - 204 응답과 함께 기록을 소프트 삭제한다. 작성자가 아니어도 된다
   - 카드·그룹의 삭제되지 않은 기록 수를 줄이고, 본문과 첨부 파일은 보존한다
   - 기록 삭제 로그를 남기고 최근 활동 일시를 갱신한다
2. 기록 작성자의 경험치를 차감한다
   - 요청자와 작성자가 달라도 기록 작성자에게 -2 exp를 적용한다
3. 이미 삭제된 기록은 다시 삭제할 수 없다
   - 400 에러를 반환하며 경험치·기록 수를 다시 차감하지 않는다
4. 종료된 그룹에서는 기록을 삭제할 수 없다
   - 그룹이 `SUCCESS`·`FAIL` 상태면 400 에러를 반환한다
5. 중단된 그룹에서 기록을 삭제하면 그룹이 다시 진행 중이 된다
   - 실제로 삭제되면 그룹 상태가 `PROGRESS`로 전환된다
6. 비활성·삭제된 카드의 기록은 삭제할 수 없다
   - 현재 소속 카드가 비활성이거나 삭제됐으면 400 에러를 반환한다
7. 그룹원만 기록을 삭제할 수 있다
   - 그룹원이 아니면 403, 인증되지 않으면 401 에러를 반환한다
8. 경로의 그룹·기록이 있어야 한다
   - 그룹이 없거나, 기록이 없거나 현재 소속 카드의 그룹이 경로 그룹과 다르면 404 에러를 반환한다
9. 거부된 요청은 아무것도 바꾸지 않는다
   - 400·401·403·404 응답에서는 데이터와 경험치·알림·로그·최근 활동 일시·그룹 상태를 바꾸지 않는다
