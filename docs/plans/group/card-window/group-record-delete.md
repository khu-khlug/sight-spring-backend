# 카드 기록 삭제

기록을 소프트 삭제합니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
DELETE /groups/:groupId/records/:recordId
```

## 권한

USER and 그룹원

## 조건

- 기록의 현재 소속 카드는 `recordId`로 조회하며, 해당 카드의 그룹이 `groupId`와 일치해야 함
- 그룹이 종료(`SUCCESS`·`FAIL`) 상태가 아니어야 함
- 해당 기록이 현재 속한 카드가 삭제되지 않은 활성 상태여야 함. [카드 활성 상태별 동작](group-card-disabled-update.md#비활성-상태의-동작)을 따름
- 삭제된 기록이 아니어야 함

## 저장 처리

본문과 첨부 파일은 보존한다. 카드·그룹의 삭제되지 않은 기록 수를 반영한다.

## 부수 효과

### 그룹 상태

실제 변경이 발생하면 중단 상태를 진행 중으로 자동 전환한다. [그룹 공통 사항](../global.md#활동에-따른-중단-상태-해제)을 따른다.

### 경험치 변동

| 대상 | 변동 |
| :-- | :--: |
| 기록 작성자 | -2 |

작성자가 아닌 다른 그룹원도 삭제할 수 있지만, 삭제 요청자가 아니라 기록 작성자에게 차감함

### 알림

(해당 없음)

### 그룹 활동 로그

그룹 활동 로그에 기록 삭제를 기록하고 최근 활동 일시를 갱신함
