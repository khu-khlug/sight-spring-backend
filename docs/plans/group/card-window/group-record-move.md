# 기록 소속 카드 변경

기록을 같은 그룹의 다른 카드로 이동합니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
PUT /groups/:groupId/records/:recordId/position
```

## 권한

USER and 그룹원

## 조건

- 기록의 현재 소속 카드는 `recordId`로 조회하며, 해당 카드의 그룹이 `groupId`와 일치해야 함
- 그룹이 종료(`SUCCESS`·`FAIL`) 상태가 아니어야 함
- 원본·목적지 카드가 모두 같은 그룹의 삭제되지 않은 활성 카드여야 함. [카드 활성 상태별 동작](group-card-disabled-update.md#비활성-상태의-동작)을 따름
- 삭제된 기록이 아니어야 함
- 목적지 카드가 현재 카드와 같으면 변경 없이 성공함

## 저장 처리

- 기록 아이디·작성자·본문·작성 시각·포인트는 유지한다. 개인 보관 기록은 같은 기록을 계속 가리킨다.
- 소속 카드 변경과 양쪽 카드의 기록 수 변경은 하나의 트랜잭션에서 처리한다. 그룹의 전체 기록 수는 바뀌지 않는다.

## 부수 효과

### 그룹 상태

실제 변경이 발생하면 중단 상태를 진행 중으로 자동 전환한다. [그룹 공통 사항](../global.md#활동에-따른-중단-상태-해제)을 따른다.
