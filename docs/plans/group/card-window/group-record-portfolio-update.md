# 기록 포트폴리오 포함 변경

기록의 포트폴리오 포함 여부를 변경합니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
PUT /groups/:groupId/records/:recordId/portfolio
```

## 권한

USER and 그룹원

기록 작성자가 아닌 그룹원도 요청할 수 있다.

## 조건

- 기록의 현재 소속 카드는 `recordId`로 조회하며, 해당 카드의 그룹이 `groupId`와 일치해야 함
- 그룹이 종료·중단 상태가 아니어야 함
- 해당 기록이 현재 속한 카드가 삭제되지 않은 활성 상태여야 함
- 삭제된 기록이 아니어야 함

카드 활성 상태와 중단 상태 제한은 [카드 활성 상태별 동작](group-card-disabled-update.md#비활성-상태의-동작)과 [그룹 공통 사항](../global.md#중단-상태에서의-동작-제한)을 따른다.

## 저장 처리

기록의 포함 여부만 변경한다. 그룹 포트폴리오 발행 여부와 카드의 포함 여부는 유지한다. 현재 값과 같은 요청은 변경 없이 성공하며 부수 효과를 반복하지 않는다.

## 실패 응답

[그룹 공통 실패 응답](../global.md#공통-실패-응답)을 함께 적용한다.

| 상황 | 응답 코드 |
| :-- | :--: |
| 종료·중단된 그룹이거나 현재 소속 카드가 비활성 상태임 | 400 |
| `isInPortfolio`가 없거나 불리언이 아님 | 400 |
| 삭제된 카드·기록임 | 400 |
| 기록이 없거나 다른 그룹의 기록임 | 404 |

## 테스트 케이스

1. 그룹원은 기록의 포트폴리오 포함 여부를 바꿀 수 있다
   - `isInPortfolio`를 보내면 204 응답과 함께 기록의 포함 여부만 바꾼다. 작성자가 아니어도 된다
   - 그룹 포트폴리오 발행 여부와 소속 카드의 포함 여부는 그대로다
   - 실제로 바뀌면 기록 포트폴리오 포함 변경 로그를 남긴다. 최근 활동 일시는 갱신하지 않는다
2. 현재와 같은 값으로 요청하면 아무것도 바뀌지 않는다
   - 204 응답을 반환하고 로그를 남기지 않는다
3. `isInPortfolio`는 불리언이어야 한다
   - 없거나 null이거나 불리언이 아니면 400 에러를 반환한다
4. 중단·종료된 그룹에서는 포함 여부를 바꿀 수 없다
   - 그룹이 `STOP`·`SUCCESS`·`FAIL` 상태면 400 에러를 반환한다
5. 삭제된 기록과 비활성·삭제된 카드의 기록은 바꿀 수 없다
   - 기록이 삭제됐거나 현재 소속 카드가 비활성이거나 삭제됐으면 400 에러를 반환한다
6. 그룹원만 포함 여부를 바꿀 수 있다
   - 그룹원이 아니면 403, 인증되지 않으면 401 에러를 반환한다
7. 경로의 그룹·기록이 있어야 한다
   - 그룹이 없거나, 기록이 없거나 현재 소속 카드의 그룹이 경로 그룹과 다르면 404 에러를 반환한다
8. 거부된 요청은 아무것도 바꾸지 않는다
   - 400·401·403·404 응답에서는 데이터와 경험치·알림·로그·최근 활동 일시·그룹 상태를 바꾸지 않는다
