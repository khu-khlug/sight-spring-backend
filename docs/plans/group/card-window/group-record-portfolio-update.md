# 기록 포트폴리오 포함 변경

기록의 포트폴리오 포함 여부를 변경합니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
PUT /groups/:groupId/records/:recordId/portfolio
```

## 권한

USER and 그룹원

기록 작성자가 아닌 그룹원도 요청할 수 있다.

## 조건

- 기록의 현재 소속 카드는 `recordId`로 조회하며, 해당 카드의 그룹이 `groupId`와 일치해야 함
- 그룹이 종료·중단 상태가 아니어야 함
- 해당 기록이 현재 속한 카드가 삭제되지 않은 활성 상태여야 함
- 삭제된 기록이 아니어야 함

카드 활성 상태와 중단 상태 제한은 [카드 활성 상태별 동작](group-card-disabled-update.md#비활성-상태의-동작)과 [그룹 공통 사항](../global.md#중단-상태에서의-동작-제한)을 따른다.

## 저장 처리

기록의 포함 여부만 변경한다. 그룹 포트폴리오 발행 여부와 카드의 포함 여부는 유지한다. 현재 값과 같은 요청은 변경 없이 성공하며 부수 효과를 반복하지 않는다.

| :-- | :--: |

| 삭제된 카드·기록임 | 404 |
| 기록이 없거나 다른 그룹의 기록임 | 404 |
