# 기록 복구

삭제된 기록을 복구합니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
POST /groups/:groupId/records/:recordId/restore
```

## 권한

USER and 그룹원

기록 작성자가 아닌 그룹원도 요청할 수 있다.

## 조건

- 기록의 현재 소속 카드는 `recordId`로 조회하며, 해당 카드의 그룹이 `groupId`와 일치해야 함
- 그룹이 종료(`SUCCESS`·`FAIL`) 상태가 아니어야 함
- 해당 기록이 현재 속한 카드가 삭제되지 않은 활성 상태여야 함

카드 활성 상태와 중단 상태 제한은 [카드 활성 상태별 동작](group-card-disabled-update.md#비활성-상태의-동작)과 [그룹 공통 사항](../global.md#중단-상태에서의-동작-제한)을 따른다.

## 저장 처리

본문·첨부 파일을 유지하고 카드·그룹의 삭제되지 않은 기록 수를 증가시킨다. 이미 복구된 기록이면 변경 없이 성공하며 부수 효과를 반복하지 않는다.

## 부수 효과

### 그룹 상태

실제 복구 시 중단 상태를 진행 중으로 자동 전환한다.

### 경험치 변동

실제로 기록을 복구한 요청자에게 +2.

### 알림

(해당 없음)

### 그룹 활동 로그

실제 복구 시 기록 복구 로그를 남기고 최근 활동 일시를 갱신한다.

## 쿼리스트링

(해당 없음)

## 요청 바디

(해당 없음)

## 성공 응답

```
204 No Content
```

(해당 없음)

## 실패 응답

[그룹 공통 실패 응답](../global.md#공통-실패-응답)을 함께 적용한다.

| 상황 | 응답 코드 |
| :-- | :--: |
| 종료된 그룹이거나 현재 소속 카드가 비활성 상태임 | 400 |
| 현재 소속 카드가 삭제 상태임 | 400 |
| 기록이 없거나 다른 그룹의 기록임 | 404 |

## 테스트 케이스

1. 그룹원은 삭제된 기록을 복구할 수 있다
   - 204 응답과 함께 삭제 표시를 해제한다. 작성자가 아니어도 된다
   - 본문·첨부 파일은 그대로이고, 카드·그룹의 삭제되지 않은 기록 수를 1씩 늘린다
   - 기록 복구 로그를 남기고 최근 활동 일시를 갱신한다
2. 복구한 요청자에게 경험치를 준다
   - 요청자와 작성자가 달라도 요청자에게 +2 exp를 지급한다
3. 이미 복구된 기록이면 아무것도 바뀌지 않는다
   - 삭제되지 않은 기록에 요청하면 204 응답을 반환하고 경험치·기록 수·로그를 바꾸지 않는다
4. 종료된 그룹에서는 기록을 복구할 수 없다
   - 그룹이 `SUCCESS`·`FAIL` 상태면 400 에러를 반환한다
5. 중단된 그룹에서 기록을 복구하면 그룹이 다시 진행 중이 된다
   - 실제로 복구되면 그룹 상태가 `PROGRESS`로 전환된다
6. 비활성·삭제된 카드의 기록은 복구할 수 없다
   - 현재 소속 카드가 비활성이거나 삭제됐으면 400 에러를 반환한다
7. 그룹원만 기록을 복구할 수 있다
   - 그룹원이 아니면 403, 인증되지 않으면 401 에러를 반환한다
8. 경로의 그룹·기록이 있어야 한다
   - 그룹이 없거나, 기록이 없거나 현재 소속 카드의 그룹이 경로 그룹과 다르면 404 에러를 반환한다
9. 거부된 요청은 아무것도 바꾸지 않는다
   - 400·401·403·404 응답에서는 데이터와 경험치·알림·로그·최근 활동 일시·그룹 상태를 바꾸지 않는다
