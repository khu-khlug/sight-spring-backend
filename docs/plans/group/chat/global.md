# 채팅 API 공통 사항

## Discord 연동

- 채팅 메시지 조회는 백엔드가 Discord 봇 인증으로 수행한다.
- 채팅 메시지 전송은 백엔드가 해당 채널의 Discord 웹훅으로 수행한다. 웹훅 표시 이름에는 요청자의 이름을 사용한다.

## 채팅 내용 캐시

- 채팅 내용의 원본은 Discord에 둔다.
- 백엔드는 조회하거나 전송한 채팅 내용을 DB·Redis·메모리 등에 캐싱하지 않는다. 봇 라이브러리의 메시지 캐시도 사용하지 않는다.
- 백엔드는 조회 요청마다 봇으로 Discord에서 메시지를 가져와 응답한다. 요청 처리 중 응답을 구성하는 임시 데이터는 재사용 가능한 캐시로 보관하지 않는다.
- 채팅 내용의 캐시는 프런트엔드에서만 관리한다.
