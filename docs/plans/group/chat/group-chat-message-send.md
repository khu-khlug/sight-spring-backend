# 그룹 채팅 메시지 전송

그룹 채팅방(디스코드 채널)에 요청자 명의로 메시지를 보냅니다. 본문과 첨부 파일을 함께 보낼 수 있습니다.
디스코드 웹훅을 이용하여 사용자의 이름으로 해당 채팅방에 채팅을 보냅니다.

연동 방식과 채팅 내용의 캐시 정책은 [채팅 API 공통 사항](global.md)을 따릅니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
POST /groups/:groupId/chat-messages
```

## 권한

USER and 그룹원

## 조건

- 중단 상태에서는 실행할 수 없음. [그룹 공통 사항의 중단 상태 동작 제한](../global.md#중단-상태에서의-동작-제한)을 따름
- 그룹에 채팅방이 있어야 함
- `content`가 공백이 아니거나 `files` 파트가 하나 이상 있어야 함

## 제한

- `content` 길이는 최대 2000자. 디스코드 일반 메시지의 본문 길이 제한에 맞춘 값이다.
  - 디스코드는 멘션·이모지 표기 등이 실제 전송 내용에서 길어지거나 글자 수를 다르게 셀 수 있으므로, 2000자 이하라도 웹훅 전송이 길이 초과로 실패할 수 있다.
- 첨부 파일 하나의 실제 크기는 최대 20 MiB(20 × 1024 × 1024 = 20,971,520바이트)
- 첨부 파일의 실제 크기 합계는 최대 25 MiB(25 × 1024 × 1024 = 26,214,400바이트)
- 크기는 각 파일 파트의 실제 바이트 수로 계산한다. 정확히 상한과 같은 크기는 허용한다.
- 서버의 multipart 요청 크기 설정은 첨부 합계 상한(25 MiB)에 본문과 파트 헤더 여유를 더한 값으로 둔다. 설정 상한을 넘는 요청은 본문을 끝까지 읽기 전에 거부한다.
- 첨부 파일 개수는 제한하지 않는다.
- 위 크기 상한은 디스코드 공식 문서의 파일당 기본 한도(20 MiB)와 메시지 요청 최대 크기(25 MiB)에 맞춘 값이다.

## 새니타이징

- 입력받은 첨부 파일 이름에 경로 구분자(`/`, `\`)나 제어 문자가 포함되어 있는지 검사하고 해당 문자를 제거한다.

## Discord 전송 규칙

- 디스코드에는 `multipart/form-data`로 보낸다. 첨부 파일은 받은 순서대로 `files[0]`, `files[1]` … 파트로 넣고, 본문과 첨부 목록(`attachments`의 `id`·`filename`)은 `payload_json` 파트에 담는다. 받은 파일을 다른 형식으로 인코딩하지 않는다.
- 웹훅 표시 이름으로 쓰는 요청자 이름은 디스코드 규칙(1~80자, `discord`·`clyde` 포함 불가)에 맞게 정리한다.
- 서버의 크기 검사를 통과했더라도 디스코드가 요청 크기 초과(HTTP 413)로 전송을 거부하면 413으로 응답한다. 프런트엔드는 413을 받으면 파일 용량이 커서 보낼 수 없다는 알림을 띄운다.

## 요청 바디

`Content-Type: multipart/form-data`로 보낸다.

| 파트 이름 | 타입 | 기본값 | 설명 |
| :-- | :--: | :--: | :-- |
| `content` | 텍스트 파트 | `""` | 메시지 본문. 생략 가능 |
| `files` | 파일 파트, 여러 개 | 없음 | 첨부 파일. 같은 이름으로 파일마다 하나씩 보낸다. 파일 이름은 파트의 `filename`, MIME 타입은 파트의 `Content-Type`을 사용한다 |

## 성공 응답

```
201 Created
```

| 이름                      |      타입      | 설명                                 |
| :------------------------ | :------------: | :----------------------------------- |
| `id`                      |     문자열     | 메시지 아이디                        |
| `authorName`              |     문자열     | 작성자 표시 이름                     |
| `content`                 |     문자열     | 메시지 본문                          |
| `createdAt`               |     문자열     | 작성 일시 (ISO 8601 UTC, `Z` 접미사) |
| `attachments`             |   객체 배열    | 첨부 파일 목록                       |
| `attachments.name`        |     문자열     | 파일 이름                            |
| `attachments.contentType` | 문자열 \| null | MIME 타입                            |
| `attachments.size`        |   숫자(uint)   | 파일 크기 (바이트)                   |
| `attachments.url`         |     문자열     | 파일을 내려받을 수 있는 주소         |

## 실패 응답

| 상황                                         | 응답 코드 |
| :------------------------------------------- | :-------: |
| 그룹에 채팅방이 없음                         |    400    |
| 본문이 비어 있고 첨부 파일도 없음            |    400    |
| 본문 길이 제한을 넘음                        |    400    |
| 첨부 파일 하나가 20 MiB를 초과함             |    400    |
| 첨부 파일의 실제 크기 합계가 25 MiB를 초과함 |    400    |
| 요청 전체가 서버의 multipart 요청 크기 설정을 넘음 |    413    |
| 디스코드가 요청 크기 초과로 전송을 거부함     |    413    |
| 2000자 이하지만 디스코드가 본문 길이 초과로 전송을 거부함 |    400    |
| 그 밖의 이유로 디스코드 전송에 실패함        |    502    |
