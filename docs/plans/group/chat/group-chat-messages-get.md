# 그룹 채팅 메시지 목록 조회

그룹 채팅방(디스코드 채널)의 메시지를 최신 메시지부터 거슬러 올라가며 조회합니다.

Discord 봇으로 조회하며 백엔드에서는 채팅 내용을 캐싱하지 않습니다. 연동 방식과 캐시 정책은 [채팅 API 공통 사항](global.md)을 따릅니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
GET /groups/:groupId/chat-messages
```

## 권한

USER and 그룹원

## 조건

- 그룹에 채팅방이 있어야 함

## 제한

- 한 번에 받는 메시지 수는 최대 50개이며, 이전 메시지가 더 필요하면 `skip`을 늘려 다시 요청해야 함
  - 50개인 이유: 디스코드 메시지 조회 API가 한 번에 최대 100개, 기본 50개를 반환하므로 디스코드 요청 1회로 응답 1회를 채울 수 있음

## 새니타이징

- Discord 응답에서 받은 `attachments.url`이 디스코드 첨부 파일 주소(`https://cdn.discordapp.com/...` 등)인지 검증한다. 검증한 첨부 파일 주소만 반환한다.

## 성공 응답

```
200 OK
```

| 이름                               |      타입      | 설명                                                                    |
| :--------------------------------- | :------------: | :---------------------------------------------------------------------- |
| `skip`                             |   숫자(uint)   | 최신 메시지부터 건너뛴 개수 (요청의 `skip`과 같음)                      |
| `receivedCount`                    |   숫자(uint)   | 받은 메시지 수 (`messages` 길이)                                        |
| `hasMore`                          |     불리언     | 이보다 이전 메시지가 더 있는지                                          |
| `messages`                         |   객체 배열    | 메시지 목록. 오래된 메시지가 앞, 최신 메시지가 뒤                       |
| `messages.id`                      |     문자열     | 메시지 아이디                                                           |
| `messages.authorName`              |     문자열     | 작성자 표시 이름. HTML로 해석하지 않는 일반 텍스트 |
| `messages.content`                 |     문자열     | 메시지 본문. HTML로 해석하지 않는 일반 텍스트 |
| `messages.createdAt`               |     문자열     | 작성 일시 (ISO 8601 UTC, `Z` 접미사)                                    |
| `messages.attachments`             |   객체 배열    | 첨부 파일 목록. 없으면 빈 배열                                          |
| `messages.attachments.name`        |     문자열     | 파일 이름                                                               |
| `messages.attachments.contentType` | 문자열 \| null | MIME 타입                                                               |
| `messages.attachments.size`        |   숫자(uint)   | 파일 크기 (바이트)                                                      |
| `messages.attachments.url`         |     문자열     | 파일을 내려받을 수 있는 주소                                            |

## 실패 응답

| 상황                   | 응답 코드 |
| :--------------------- | :-------: |
| 그룹에 채팅방이 없음   |    400    |

## 외부 실패 처리

Discord의 권한 상실(401/403), 채널 없음(404), 호출 제한(429), 5xx·네트워크 오류·타임아웃은 502로 응답한다. SIGHT의 권한/입력 오류와 구분하며 Discord 오류 본문·토큰을 노출하지 않는다. 여러 페이지를 조회하다 일부가 실패하면 받은 일부만 정상 응답하지 않고 502다.

## 테스트 케이스

1. 그룹원은 채팅방 메시지를 조회할 수 있다
   - 200 응답과 함께 최신 메시지부터 최대 50개를 고르고, 응답 배열은 그 범위를 오래된 순으로 정렬한다
   - 메시지 아이디는 문자열이고, 작성자 이름과 본문은 HTML로 해석하지 않는 일반 텍스트다. 시각은 UTC ISO 8601 `Z` 형식이다
2. 첨부 파일은 검증한 주소만 반환한다
   - 첨부가 없으면 빈 배열, MIME 타입이 없으면 `contentType: null`이다. Discord 첨부 파일 주소로 확인된 URL만 반환한다
3. `skip`으로 이전 메시지를 조회한다
   - 메시지가 51개면 첫 응답은 최신 50개와 `hasMore: true`, `skip=50`이면 가장 오래된 1개와 `hasMore: false`다
   - Discord 한 페이지보다 큰 `skip`도 필요한 이전 페이지를 읽어 정확한 범위를 반환한다
   - 음수·소수·숫자가 아닌 `skip`은 400 에러를 반환한다
4. 메시지는 매번 Discord에서 읽는다
   - 같은 범위를 다시 조회해도 Discord 봇으로 원본을 읽으며, 메시지를 서버에 캐시하지 않는다
5. Discord 오류는 502다
   - Discord 401/403·404·429·5xx·연결 오류·타임아웃이면 502 에러를 반환한다. 여러 페이지 중 일부가 실패해도 502이며, 오류 원문과 인증 정보는 노출하지 않는다
6. 채팅방이 있어야 한다
   - 그룹에 채팅방이 없으면 400 에러를 반환하고 Discord를 호출하지 않는다
7. 그룹 상태와 관계없이 조회할 수 있다
   - 중단·종료 그룹에서도 그룹원이면 200 응답을 반환한다
8. 그룹원만 조회할 수 있다
   - 공개 범위와 관계없이 그룹원이 아니면 403, 인증되지 않으면 401, 그룹이 없으면 404 에러를 반환한다
