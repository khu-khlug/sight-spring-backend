# 카드 기록 작성

카드에 새 활동 기록을 작성합니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
POST /groups/:groupId/cards/:cardId/records
```

## 권한

USER and 그룹원

## 조건

- 그룹이 종료(`SUCCESS`·`FAIL`) 상태가 아니어야 함
- 카드가 삭제되지 않은 활성 상태여야 함. [카드 활성 상태별 동작](../card-window/group-card-disabled-update.md#비활성-상태의-동작)을 따름
- 본문(`content`)이 빈 문자열이 아니어야 함. 서버는 본문을 파싱하지 않으므로 본문 안의 내용 유무는 확인하지 않음
- 본문 크기는 UTF-8 바이트 기준 최대 1 MiB(1,048,576바이트)여야 함. 첨부 파일 크기는 포함하지 않음
- 첨부 파일 배열(`files`)은 [기록 첨부 파일](../global.md#기록-첨부-파일)의 비교 규칙을 따름. 새 기록이므로 비교 대상 연결 목록은 비어 있음

## 생성 기본값

| 항목 | 기본값 |
| :-- | :-- |
| 작성자 | 요청자 |
| `type` | `TIPTAP` |
| `isDeleted` | false |
| `isInPortfolio` | true |

## 저장 처리

- 카드·그룹의 기록 수를 증가시킨다.
- `files` 배열로 새 기록의 연결 목록을 만든다. 새 파일은 업로드 링크를 발급하고, 기존 파일은 참조를 추가한다.
- 기록 저장이 성공하면 요청자의 임시저장을 지운다. 임시저장에 연결돼 있던 파일 중 요청 배열에 같은 `fileId`로 들어온 파일은 새 기록에 연결되므로 유지되고, 연결이 하나도 남지 않은 파일은 삭제한다. [기록 첨부 파일의 임시저장과 기록 저장 사이의 처리](../global.md#임시저장과-기록-저장-사이의-처리)를 따른다.

## 부수 효과

### 그룹 상태

실제 변경이 발생하면 중단 상태를 진행 중으로 자동 전환한다. [그룹 공통 사항](../global.md#활동에-따른-중단-상태-해제)을 따른다.

### 경험치 변동

| 대상 | 변동 |
| :-- | :--: |
| 기록을 작성한 요청자 | +2 |

### 알림

그룹원 전체에게 기록 작성 알림

### 그룹 활동 로그

그룹 활동 로그에 기록 작성을 기록하고 최근 활동 일시를 갱신함

## 쿼리스트링

(해당 없음)

## 요청 바디

| 이름 | 타입 | 설명 |
| :-- | :--: | :-- |
| `content` | 문자열 | 필수. TIPTAP 문서 JSON을 직렬화한 문자열 |
| `files` | 객체 배열 | 필수. 본문이 참조하는 파일 전체. 형식은 [요청의 파일 식별자 배열](../global.md#요청의-파일-식별자-배열)을 따름 |

## 성공 응답

```
201 Created
```

생성된 기록을 [기록 필드](group-record-get.md#기록-필드) 형식으로 반환하고, 아래 필드를 함께 반환한다.

| 이름 | 타입 | 설명 |
| :-- | :--: | :-- |
| `uploads` | 객체 배열 | 새 파일의 업로드 정보. 형식은 [기록 첨부 파일의 비교 규칙](../global.md#비교-규칙)을 따름 |

## 실패 응답

[그룹 공통 실패 응답](../global.md#공통-실패-응답)을 함께 적용한다.

| 상황 | 응답 코드 |
| :-- | :--: |
| 종료된 그룹임 | 400 |
| 비활성 카드임 | 400 |
| 본문이 빈 문자열이거나 1 MiB를 초과함 | 400 |
| `files` 형식이 잘못됨 (필수 값 누락, 식별자 중복, 최대 크기 초과) | 400 |
| `files`가 다른 그룹의 파일이나 존재하지 않거나 삭제된 파일을 참조함 | 400 |
| 삭제된 카드임 | 404 |
