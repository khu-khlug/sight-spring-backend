# 기록 임시저장 삭제

요청자의 기록 임시저장을 삭제합니다. 임시저장은 회원당 하나뿐이며, 그 임시저장이 경로의 그룹 것일 때만 삭제합니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
DELETE /groups/:groupId/records/draft
```

## 권한

USER and 그룹원

## 조건

- 그룹이 종료(`SUCCESS`·`FAIL`) 상태가 아니어야 함
- 중단 상태에서는 실행할 수 없음. [그룹 공통 사항의 중단 상태 동작 제한](../global.md#중단-상태에서의-동작-제한)을 따름
- 임시저장이 없거나 다른 그룹 것이면 변경 없이 성공함

## 저장 처리

임시저장의 연결을 모두 해제하고, 연결이 하나도 남지 않은 파일은 삭제 표시한 뒤 커밋 후 [삭제 흐름](../global.md#삭제-흐름)을 적용한다.

## 테스트 케이스

1. 그룹원은 이 그룹의 본인 임시저장을 삭제할 수 있다
   - 204 응답과 함께 임시저장과 그 파일 연결을 지운다. 다른 회원의 임시저장은 그대로다
2. 연결이 하나도 남지 않은 파일은 삭제한다
   - 삭제 표시 후 커밋하고 R2에서 지운다. 다른 기록·임시저장에 연결이 남은 파일은 유지한다
   - R2 삭제에 실패해도 204 응답을 유지하고 삭제 표시를 남겨 청소에서 다시 지운다. `NoSuchKey`는 삭제 성공으로 본다
3. 임시저장이 없거나 다른 그룹 것이면 아무것도 바뀌지 않는다
   - 204 응답을 반환하고 다른 그룹의 임시저장과 파일 연결은 그대로 둔다
4. 중단·종료된 그룹에서는 임시저장을 삭제할 수 없다
   - 그룹이 `STOP`·`SUCCESS`·`FAIL` 상태면 임시저장이 없거나 다른 그룹 것이어도 400 에러를 반환한다
5. 그룹원만 삭제할 수 있다
   - 그룹원이 아니면 403, 인증되지 않으면 401, 그룹이 없으면 404 에러를 반환한다
6. DB 처리가 실패하면 모두 되돌린다
   - 트랜잭션 도중 실패하면 임시저장·파일 연결을 그대로 두고, R2 객체는 지우지 않는다
7. 거부된 요청은 아무것도 바꾸지 않는다
   - 400·401·403·404 응답에서는 데이터와 경험치·알림·로그·최근 활동 일시·그룹 상태를 바꾸지 않는다
