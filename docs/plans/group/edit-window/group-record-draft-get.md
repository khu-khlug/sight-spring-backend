# 기록 임시저장 본문 조회

요청자의 기록 임시저장을 본문과 함께 조회합니다. 임시저장은 회원당 하나뿐이며, 그 임시저장이 경로의 그룹 것일 때만 반환합니다. 메타데이터 조회 API는 그대로 유지합니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
GET /groups/:groupId/records/draft
```

## 권한

USER and 그룹원

## 조건

- `groupId`는 조회할 그룹의 아이디이며 숫자(Long)이다.
- 요청자 본인의 임시저장만 조회한다. 다른 회원의 임시저장은 조회하지 않는다.
- 임시저장이 존재하고 해당 임시저장이 속한 그룹이 `groupId`와 일치해야 한다.
- 임시저장이 없거나 다른 그룹 것이면 메타데이터 조회와 달리 `404 Not Found`를 반환한다.

## 부수 효과

(해당 없음)

조회로 임시저장을 삭제하거나 마지막 저장 일시를 변경하지 않는다. 반복 조회에도 같은 기준을 적용한다.

## 쿼리스트링

(해당 없음)

## 요청 바디

(해당 없음)

## 성공 응답

```
200 OK
```

| 이름 | 타입 | 설명 |
| :-- | :--: | :-- |
| `draft` | 객체 | 요청자의 해당 그룹 기록 임시저장. null을 반환하지 않음 |
| `draft.isNewRecord` | 불리언 | 새 기록 작성 중이면 true, 기존 기록 수정 중이면 false |
| `draft.cardId` | 문자열 | 작성 중인 기록이 속한 카드 아이디 |
| `draft.cardTitle` | 문자열 | 카드명 |
| `draft.recordId` | 숫자(Long) \| null | 수정 중인 기록 아이디. `isNewRecord`가 true이면 null |
| `draft.content` | 문자열 | 서버에 저장된 임시저장 본문. TIPTAP 문서 JSON을 직렬화한 문자열 |
| `draft.updatedAt` | 문자열 | 마지막 저장 일시. ISO 8601 UTC 문자열이며 `Z` 접미사를 사용 |
| `draft.files` | 객체 배열 | 임시저장에 연결된 첨부 파일과 읽기 링크. 형식은 [기록 첨부 파일의 조회 응답 파일 매핑](../global.md#조회-응답의-파일-매핑)을 따름. 첨부 파일이 없으면 빈 배열 |

`content`는 서버에 저장된 임시저장 본문을 반환하며, 최종 저장된 기록 본문으로 대체하지 않는다.

## 실패 응답

[그룹 공통 실패 응답](../global.md#공통-실패-응답)을 함께 적용한다.

| 상황 | 응답 코드 |
| :-- | :--: |
| 요청자의 임시저장이 없음 | 404 |
| 요청자의 임시저장이 다른 그룹에 속함 | 404 |

## 테스트 케이스

1. 그룹원은 이 그룹의 본인 임시저장을 조회할 수 있다
   - 200 응답과 함께 `draft`를 반환한다. 대상 카드 아이디·카드명·`recordId`·본문·마지막 저장 일시·첨부 파일을 포함한다
   - 기록 아이디는 숫자(Long), 카드·파일 아이디는 문자열, `updatedAt`은 UTC ISO 8601 `Z` 형식이다
2. 새 기록과 기존 기록 수정을 구분해 반환한다
   - 새 기록 작성 중이면 `isNewRecord: true`·`recordId: null`, 기존 기록 수정 중이면 false와 그 기록 아이디를 반환한다
3. 본문은 임시저장 본문 그대로 반환한다
   - 최종 저장된 기록 본문으로 바꾸거나 서버에서 파싱·정제하지 않는다
4. 첨부 파일은 읽기 링크와 함께 반환한다
   - 첨부가 없으면 `files: []`다. 업로드가 끝난 파일은 7일 유효 읽기 링크를 주고, 업로드되지 않은 파일의 `url`은 null이다
5. 임시저장이 없거나 다른 그룹 것이면 찾을 수 없다
   - 404 에러를 반환한다. 다른 회원의 임시저장은 반환하지 않는다
6. 조회해도 임시저장은 바뀌지 않는다
   - 반복 조회해도 임시저장을 지우거나 `updatedAt`을 바꾸지 않는다
7. 그룹 상태와 관계없이 조회할 수 있다
   - 중단·종료 그룹에서도 200 응답을 반환한다
8. 그룹원만 조회할 수 있다
   - 그룹원이 아니면 403, 인증되지 않으면 401, 그룹이 없으면 404 에러를 반환한다
