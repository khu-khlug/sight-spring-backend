# 그룹 기록 단건 조회

기록 아이디로 본문과 현재 소속 카드 정보를 조회합니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
GET /groups/:groupId/records/:recordId
```

## 권한

USER and 열람권한

## 조건

- 기록이 현재 속한 카드의 그룹이 `groupId`와 일치해야 함
- 해당 기록과 그 기록이 현재 속한 카드가 모두 삭제 상태가 아니어야 함

## 부수 효과

(해당 없음)

## 쿼리스트링

(해당 없음)

## 요청 바디

(해당 없음)

## 성공 응답

```
200 OK
```

[기록 필드](#기록-필드)에 아래 소속 정보를 추가한 객체를 반환한다.

| 이름 | 타입 | 설명 |
| :-- | :--: | :-- |
| `cardId` | 문자열 | 현재 소속 카드 아이디 |
| `cardTitle` | 문자열 | 현재 소속 카드 이름 |
| `listId` | 문자열 | 소속 카드의 리스트 아이디 |
| `listTitle` | 문자열 | 소속 카드의 리스트 이름 |

### 기록 필드

| 이름 | 타입 | 설명 |
| :-- | :--: | :-- |
| `id` | 숫자(Long) | 기록 아이디 |
| `type` | 문자열 | 본문 형식. `TIPTAP` 또는 `LEGACY` |
| `authorName` | 문자열 | 기록 작성자 실명 |
| `content` | 문자열 | 본문. 아래 [본문 형식](#본문-형식)을 따름 |
| `createdAt` | 문자열 | 작성 일시. [그룹 공통 시각 표기](../global.md#그룹-api-시각-표기-utc)를 따름 |
| `updatedAt` | 문자열 | 본문 수정 일시. [그룹 공통 시각 표기](../global.md#그룹-api-시각-표기-utc)를 따름 |
| `isDeleted` | 불리언 | 소프트 삭제 여부 |
| `isInPortfolio` | 불리언 | 해당 기록의 포트폴리오 포함 여부 |
| `files` | 객체 배열 | 기록에 연결된 첨부 파일과 읽기 링크. 형식은 [기록 첨부 파일의 조회 응답 파일 매핑](../global.md#조회-응답의-파일-매핑)을 따름. 첨부 파일이 없으면 빈 배열 |

### 본문 형식

- `content`는 `type`에 해당하는 형식의 문자열이며 JSON 문자열과 HTML을 혼동하지 않는다.
- `TIPTAP`은 저장된 문서 JSON 직렬화 문자열을, `LEGACY`는 저장된 HTML을 그대로 반환한다. 서버는 본문을 파싱하거나 정제하지 않는다.

## 실패 응답

[그룹 공통 실패 응답](../global.md#공통-실패-응답)을 함께 적용한다.

| 상황 | 응답 코드 |
| :-- | :--: |
| 삭제된 카드·기록임 | 400 |

## 테스트 케이스

1. 열람 권한이 있는 회원은 기록을 조회할 수 있다
   - 200 응답과 함께 기록 필드와 현재 `cardId`·`cardTitle`·`listId`·`listTitle`을 반환한다
   - 기록 아이디는 숫자(Long), 카드·리스트·파일 아이디는 문자열, 시각은 UTC ISO 8601 `Z` 형식이다
2. 이동한 기록은 현재 소속 카드 정보로 반환한다
   - 다른 카드로 옮긴 기록을 조회하면 옮긴 카드·리스트 정보를 반환한다
3. 본문은 저장한 형식 그대로 반환한다
   - `TIPTAP`은 문서 JSON 직렬화 문자열, `LEGACY`는 HTML을 그대로 반환한다. 서버는 본문을 파싱·정제하지 않는다
4. 첨부 파일은 읽기 링크와 함께 반환한다
   - 첨부가 없으면 `files: []`, 있으면 `id`·`fileId`·이름·크기·MIME 타입을 반환한다
   - 업로드가 끝난 파일은 7일 유효 읽기 링크를 주고, 업로드되지 않은 파일의 `url`은 null이다. 위험 형식은 다운로드 전용 링크다
5. 그룹 상태와 관계없이 조회할 수 있다
   - 중단·종료 그룹에서도 열람 권한이 있으면 200 응답을 반환한다
6. 공개 범위에 따라 열람할 수 있는 회원이 정해진다
   - 비공개는 그룹원, 운영진 공개는 운영진, 회원 공개는 교류 회원을 제외한 회원, 완전 공개는 모든 로그인 회원이 조회할 수 있다
   - 범위 밖 회원이면 403, 인증되지 않으면 401 에러를 반환한다
7. 삭제된 기록과 삭제된 카드의 기록은 조회할 수 없다
   - 기록이 삭제됐거나 현재 소속 카드가 삭제됐으면 400 에러를 반환한다
8. 경로의 그룹·기록이 있어야 한다
   - 그룹이 없거나, 기록이 없거나 현재 소속 카드의 그룹이 경로 그룹과 다르면 404 에러를 반환한다
