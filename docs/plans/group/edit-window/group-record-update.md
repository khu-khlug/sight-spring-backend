# 카드 기록 수정

작성한 기록의 본문을 수정합니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
PATCH /groups/:groupId/records/:recordId
```

## 권한

USER and 그룹원 and 기록 작성자

## 조건

- 기록의 현재 소속 카드는 `recordId`로 조회하며, 해당 카드의 그룹이 `groupId`와 일치해야 함
- 그룹이 종료(`SUCCESS`·`FAIL`) 상태가 아니어야 함
- 카드가 삭제되지 않은 활성 상태여야 함. [카드 활성 상태별 동작](../card-window/group-card-disabled-update.md#비활성-상태의-동작)을 따름
- 삭제된 기록이 아니어야 함
- `TIPTAP` 기록이어야 함. `LEGACY` 기록은 읽기만 가능하며 수정할 수 없음
- 본문(`content`)이 빈 문자열이 아니고, UTF-8 바이트 기준 최대 1 MiB(1,048,576바이트)여야 함
- 첨부 파일 배열(`files`)은 [기록 첨부 파일](../global.md#기록-첨부-파일)의 비교 규칙을 따름. 비교 대상은 이 기록의 연결 목록임

## 저장 처리

- 작성 일시와 작성자는 유지하고, 본문이나 연결 목록이 실제로 변경되면 `updatedAt`을 갱신한다.
- `files` 배열로 이 기록의 연결 목록을 갱신한다. 새 파일은 업로드 링크를 발급하고, 배열에서 빠진 연결은 해제하며, 연결이 하나도 남지 않은 파일은 삭제한다.
- 수정이 성공하면 요청자 본인의 임시저장 중 그룹이 경로의 `groupId`, 카드가 수정 기록의 현재 소속 카드, `recordId`가 경로의 `recordId`와 모두 일치하는 수정용 임시저장만 지운다.
- 임시저장이 다른 그룹·다른 카드·다른 기록의 것이거나 새 기록 작성용(`recordId: null`)이면 본문·대상·마지막 저장 일시·파일 연결을 모두 유지한다. 다른 회원의 임시저장도 변경하지 않는다. 일치하는 임시저장이 없어도 수정은 성공한다.
- 삭제 대상이 일치하는 경우에만 기록의 파일 연결을 먼저 갱신한 뒤 해당 임시저장과 연결을 지운다. 다른 기록이나 유지되는 임시저장에 연결이 남은 파일은 삭제하지 않는다. [공통 처리](../global.md#임시저장과-기록-저장-사이의-처리)를 따른다.

## 요청 바디

| 이름 | 타입 | 설명 |
| :-- | :--: | :-- |
| `content` | 문자열 | 필수. TIPTAP 문서 JSON을 직렬화한 문자열 |
| `files` | 객체 배열 | 필수. 본문이 참조하는 파일 전체. 형식은 [요청의 파일 식별자 배열](../global.md#요청의-파일-식별자-배열)을 따름 |

## 성공 응답

```
200 OK
```

| 이름 | 타입 | 설명 |
| :-- | :--: | :-- |
| `uploads` | 객체 배열 | 새 파일의 업로드 정보. 새 파일이 없으면 빈 배열. 형식은 [기록 첨부 파일의 비교 규칙](../global.md#비교-규칙)을 따름 |

## 실패 응답

[그룹 공통 실패 응답](../global.md#공통-실패-응답)을 함께 적용한다.

| 상황 | 응답 코드 |
| :-- | :--: |
| 종료된 그룹임 | 400 |
| 비활성 카드임 | 400 |
| 본문이 빈 문자열이거나 1 MiB를 초과함 | 400 |
| `LEGACY` 기록을 수정하려 함 | 400 |
| `files` 형식이 잘못됨 (필수 값 누락, 식별자 중복, 최대 크기 초과) | 400 |
| 이미 연결된 식별자에 다른 `fileId`를 보냄 | 400 |
| `files`가 다른 그룹의 파일이나 존재하지 않거나 삭제된 파일을 참조함 | 400 |
| 삭제된 카드·기록임 | 400 |

## 테스트 케이스

1. 작성자는 자신의 기록을 수정할 수 있다
   - 본문과 `files`를 보내면 200 응답과 함께 `uploads`를 반환한다
   - 작성자·작성 일시는 그대로이고 `updatedAt`을 갱신한다
   - 기록 수정 로그를 남기고 최근 활동 일시를 갱신한다
2. 첨부 연결만 바꿔도 수정으로 처리한다
   - 본문이 같아도 연결 목록이 바뀌면 `updatedAt`과 로그를 갱신한다
3. 현재와 같은 본문·연결로 요청하면 기록 정보는 바뀌지 않는다
   - 200 응답을 반환하고 기록의 `updatedAt`·로그를 바꾸지 않는다. 같은 대상의 임시저장은 저장 성공 시 삭제 규칙을 적용하고, 다른 대상의 임시저장은 유지한다
4. 본문은 비어 있지 않은 UTF-8 1 MiB 이하 문자열이다
   - 빈 문자열이면 400, 1,048,576바이트를 넘으면 400 에러를 반환한다
5. `files` 배열로 이 기록의 연결 목록을 맞춘다
   - 새 파일에는 업로드 기록·연결·확인 예약을 만들고 `uploads`에 10분 유효 PUT URL을 반환한다
   - 같은 `id`·`fileId`는 유지하고, 배열에서 빠진 연결은 해제한다. `files: []`면 모든 연결을 해제한다
   - 연결이 하나도 남지 않은 파일은 삭제 표시한 뒤 커밋 후 R2에서 지운다
6. 연결된 식별자의 파일은 바꿀 수 없다
   - 이미 연결된 `id`에 다른 `fileId`를 보내면 400 에러를 반환한다. 파일을 바꾸려면 기존 식별자를 빼고 새 식별자로 넣는다
7. 참조하는 파일과 `files` 항목은 올바라야 한다
   - 다른 그룹 파일·없는 파일·삭제 표시된 파일을 참조하면 400 에러를 반환하고, 같은 요청의 다른 항목도 저장하지 않는다
   - `id`가 없거나 중복되거나, 새 파일 메타데이터가 없거나 잘못됐거나, 20 MiB를 넘으면 400 에러를 반환한다
8. 수정이 성공하면 같은 대상의 수정용 임시저장만 지운다
   - 요청자·그룹·현재 소속 카드·기록 아이디가 모두 일치하면 해당 임시저장과 파일 연결만 지운다. 기록에 연결된 파일은 유지하고, 연결이 하나도 남지 않은 파일만 삭제한다
   - A 그룹의 임시저장을 둔 채 다른 탭에서 B 그룹의 기록을 수정해도 A 그룹의 본문·대상·`updatedAt`·파일 연결·임시저장에만 연결된 파일은 그대로다
   - 같은 그룹이라도 다른 카드·다른 기록의 임시저장은 유지한다. 같은 카드의 새 기록 작성용 임시저장(`recordId: null`)도 지우지 않는다
   - 기록 이동으로 현재 소속 카드와 임시저장의 `cardId`가 달라졌으면 기록 아이디가 같아도 임시저장은 유지한다
   - 다른 회원의 같은 대상 임시저장도 유지한다. 요청자의 임시저장이 없거나 대상이 달라도 기록 수정은 200으로 성공한다
9. `LEGACY` 기록은 수정할 수 없다
   - `LEGACY` 기록이면 400 에러를 반환한다
10. 종료된 그룹에서는 기록을 수정할 수 없다
    - 그룹이 `SUCCESS`·`FAIL` 상태면 400 에러를 반환한다
11. 중단된 그룹에서 기록을 수정하면 그룹이 다시 진행 중이 된다
    - 실제로 수정되면 그룹 상태가 `PROGRESS`로 전환된다
12. 삭제된 기록과 비활성·삭제된 카드의 기록은 수정할 수 없다
    - 기록이 삭제됐거나 현재 소속 카드가 비활성이거나 삭제됐으면 400 에러를 반환한다
13. 기록 작성자만 수정할 수 있다
    - 그룹원이 아니거나 작성자가 아니면 403, 인증되지 않으면 401 에러를 반환한다
14. 경로의 그룹·기록이 있어야 한다
    - 그룹이 없거나, 기록이 없거나 현재 소속 카드의 그룹이 경로 그룹과 다르면 404 에러를 반환한다
15. 커밋 후 R2 삭제가 실패해도 요청은 성공한다
    - 성공 응답을 유지하고 삭제 표시를 남겨 청소에서 다시 지운다. `NoSuchKey`는 삭제 성공, `NoSuchBucket`은 다시 처리할 대상이다
16. 서버는 본문과 첨부 목록을 비교하지 않는다
    - 본문의 블록과 `files`가 달라도 본문을 파싱해 비교하지 않고 `files`로 연결 목록을 만든다
17. DB 처리가 실패하면 모두 되돌린다
    - 트랜잭션 도중 실패하면 본문·파일 연결·업로드 기록·임시저장·로그를 함께 되돌리고, R2 객체는 지우지 않는다
18. 거부된 요청은 아무것도 바꾸지 않는다
    - 400·401·403·404 응답에서는 데이터와 경험치·알림·로그·최근 활동 일시·그룹 상태를 바꾸지 않는다
