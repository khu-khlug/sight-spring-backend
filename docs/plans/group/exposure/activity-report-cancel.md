# 접수중인 활동보고 취소

제출한 활동보고를 취소합니다. 제출한 파일도 함께 삭제됩니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
DELETE /groups/:groupId/activity-reports/:reportId
```

## 권한

USER and (그룹장 or 운영진)

## 조건

- 그룹이 종료(`SUCCESS`·`FAIL`) 상태가 아니어야 함
- 해당 활동보고에 연결된 세미나의 `schedule.endAt`이 현재보다 나중이어야 함 (정각부터 접수 종료)

## 부수 효과

### 그룹 상태

실제 변경이 발생하면 중단 상태를 진행 중으로 자동 전환한다. [그룹 공통 사항](../global.md#활동에-따른-중단-상태-해제)을 따른다.


### 경험치 변동

| 행동        | 포인트 | 대상      |
| ----------- | ------ | --------- |
| 세미나 발표 등록 취소 | -150 | 멤버 전체 |
| 보고서 제출 취소·삭제 | -150 | 멤버 전체 |

ExPoint 변동 시 멤버별로 `members.expoint` 직접 UPDATE + `expoint_log` INSERT 처리.

- 세미나 발표와 보고서 모두 제출 취소·삭제 시 멤버 전체에게 -150 exp를 적용한다. 운영진이 세미나 세션을 강제로 제거할 때도 같은 차감 기준을 적용한다.

### 알림

그룹 멤버 전체 + 운영진에게 알림 발송

### 그룹 활동 로그

그룹 활동 로그에 활동보고 취소를 기록하고 최근 활동 일시를 갱신함

(해당 없음)

## 성공 응답

```
204 No Content
```

## 실패 응답

| 상황                                          | 응답 코드 |
| :-------------------------------------------- | :-------: |
| 접수 기간(`schedule.endAt`)이 지난 활동보고임 |    400    |
| 종료된 그룹임 | 400 |
| 보고서가 없거나 경로 그룹에 속하지 않음, 세미나/스케줄 참조 없음 | 404 |

## 리소스 소속·접수 경계

대상 보고서는 경로 그룹에 속해야 하며 다른 그룹의 보고서는 404다. 접수 가능 구간은 `현재 < schedule.endAt`이다. 정각부터 400으로 거부한다. 세미나 또는 스케줄 참조가 없으면 404다.

## 테스트 케이스

1. 그룹장이나 운영진은 접수 중인 활동보고를 취소할 수 있다
   - 204 응답과 함께 활동보고를 지우고 보고 파일을 삭제 표시한 뒤, 커밋 후 R2에서 지운다
   - 그룹원 전체에게 -150 exp를 적용하고, 그룹원 전체와 운영진에게 알림을 보낸다
   - 활동보고 취소 로그를 남기고 최근 활동 일시를 갱신한다
   - 그룹원이 아닌 운영진도 취소할 수 있다
2. R2 삭제에 실패해도 취소는 성공한다
   - 204 응답을 유지하고 삭제 표시를 남겨 청소에서 다시 지운다. `NoSuchKey`는 삭제 성공으로 본다
3. 이미 취소한 활동보고는 다시 취소할 수 없다
   - 404 에러를 반환하며 경험치를 다시 차감하지 않는다. 동시에 요청해도 한 번만 차감한다
4. 접수 기간이 지난 활동보고는 취소할 수 없다
   - `schedule.endAt` 정각부터 400 에러를 반환한다
5. 종료된 그룹에서는 취소할 수 없다
   - 그룹이 `SUCCESS`·`FAIL` 상태면 400 에러를 반환한다
6. 중단된 그룹에서 취소하면 그룹이 다시 진행 중이 된다
   - 그룹 상태가 `PROGRESS`로 전환된다
7. 그룹장이나 운영진만 취소할 수 있다
   - 둘 다 아니면 403, 인증되지 않으면 401 에러를 반환한다
8. 경로의 그룹·활동보고가 있어야 한다
   - 그룹이 없거나, 활동보고가 없거나 다른 그룹의 것이거나, 연결된 세미나·일정이 없으면 404 에러를 반환한다
9. DB 처리가 실패하면 모두 되돌린다
   - 트랜잭션 도중 실패하면 활동보고·파일 사용 상태·경험치와 경험치 이력·알림·로그·그룹 상태를 함께 되돌리고, R2 객체는 지우지 않는다
10. 거부된 요청은 아무것도 바꾸지 않는다
    - 400·401·403·404 응답에서는 데이터와 경험치·알림·로그·최근 활동 일시·그룹 상태를 바꾸지 않는다

## 관련 DB 테이블

| 테이블                  | 역할                                                |
| ----------------------- | --------------------------------------------------- |
| `group`                 | 그룹 존재 확인 + `master` 컬럼으로 그룹장 여부 확인 |
| `group_activity_report` | 활동보고 DELETE                                     |
| `big_seminar`+`schedule`| 접수 기간 내 여부 확인 (`schedule.endAt`)           |
| `file_upload`        | 해당 파일 row DELETE                                |
| `group_member`          | 전체 멤버 목록 조회 (ExPoint 일괄 처리 시 사용)     |
| `members`               | `expoint` 직접 UPDATE                               |
| `expoint_log`           | ExPoint 변동 이력 INSERT                            |
