# 포트폴리오 취소

발행한 그룹 포트폴리오를 내립니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
DELETE /groups/:groupId/portfolio
```

## 권한

USER and 그룹장

## 조건

- 중단 상태에서는 실행할 수 없음. [그룹 공통 사항의 중단 상태 동작 제한](../global.md#중단-상태에서의-동작-제한)을 따름
- 포트폴리오가 발행된 상태여야 함

## 부수 효과

### 경험치 변동

| 행동            | 포인트 | 대상      |
| --------------- | ------ | --------- |
| 포트폴리오 취소 | -10    | 멤버 전체 |

ExPoint 변동 시 멤버별로 `members.expoint` 직접 UPDATE + `expoint_log` INSERT 처리.

### 알림

그룹 멤버 전체에게 알림

### 그룹 활동 로그

그룹 활동 로그에 "포트폴리오 발행이 중단되었습니다."를 기록함 (레거시 `GroupController.php:656`)

- 참고: `origin/main`의 `GroupService.cancelPortfolio`는 그룹 활동 로그를 남기지 않음

204 No Content

## 실패 응답

| 상황                     | 응답 코드 |
| :----------------------- | :-------: |
| 발행되지 않은 그룹임     |    404    |

## 테스트 케이스

1. 그룹장이 발행 중인 그룹에 요청 → `group.portfolio = false`로 변경, 멤버 전체 -10, 204 반환
2. 발행 안 된 그룹에 요청 → 404 반환
3. 그룹원(비그룹장)이 요청 → 403 반환
4. 존재하지 않는 그룹 ID 요청 → 404 반환
5. 취소 성공 시 → 그룹 멤버 전체에게 알림 발송

## 관련 DB 테이블

| 테이블         | 역할                                            |
| -------------- | ----------------------------------------------- |
| `group`        | `portfolio` 컬럼 UPDATE + 그룹장 여부 확인      |
| `group_member` | 전체 멤버 목록 조회 (ExPoint 일괄 처리 시 사용) |
| `members`      | `expoint` 직접 UPDATE                           |
| `expoint_log`  | ExPoint 변동 이력 INSERT                        |
