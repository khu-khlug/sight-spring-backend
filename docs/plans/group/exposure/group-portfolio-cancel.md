# 포트폴리오 취소

발행한 그룹 포트폴리오를 내립니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
DELETE /groups/:groupId/portfolio
```

## 권한

USER and 그룹장

## 조건

- 그룹이 종료(`SUCCESS`·`FAIL`) 상태가 아니어야 함
- 중단 상태에서는 실행할 수 없음. [그룹 공통 사항의 중단 상태 동작 제한](../global.md#중단-상태에서의-동작-제한)을 따름
- 포트폴리오가 발행된 상태여야 함

## 부수 효과

### 경험치 변동

| 행동            | 포인트 | 대상      |
| --------------- | ------ | --------- |
| 포트폴리오 취소 | -10    | 멤버 전체 |

ExPoint 변동 시 멤버별로 `members.expoint` 직접 UPDATE + `expoint_log` INSERT 처리.

### 알림

그룹 멤버 전체에게 알림

### 그룹 활동 로그

그룹 활동 로그에 "포트폴리오 발행이 중단되었습니다."를 기록함 (레거시 `GroupController.php:656`)

- 참고: `origin/main`의 `GroupService.cancelPortfolio`는 그룹 활동 로그를 남기지 않음

## 성공 응답


## 실패 응답

| 상황                     | 응답 코드 |
| :----------------------- | :-------: |
| 중단되거나 종료된 그룹임 |    400    |
| 발행되지 않은 그룹임     |    404    |

## 테스트 케이스

1. 그룹장은 발행한 포트폴리오를 내릴 수 있다
   - 204 응답과 함께 발행 상태를 해제한다
   - 그룹원 전체에게 -10 exp를 적용하고 알림을 보내며, 포트폴리오 발행 중단 로그를 남긴다
2. 발행하지 않은 그룹은 취소할 수 없다
   - 404 에러를 반환하며 경험치·알림·로그를 다시 남기지 않는다. 동시에 요청해도 하나만 성공한다
3. 중단·종료된 그룹에서는 취소할 수 없다
   - 그룹이 `STOP`·`SUCCESS`·`FAIL` 상태면 400 에러를 반환한다
4. 그룹장만 취소할 수 있다
   - 그룹장이 아니면 운영진이어도 403, 인증되지 않으면 401, 그룹이 없으면 404 에러를 반환한다
5. DB 처리가 실패하면 모두 되돌린다
   - 트랜잭션 도중 실패하면 발행 여부·경험치와 경험치 이력·알림·로그를 함께 되돌린다
6. 거부된 요청은 아무것도 바꾸지 않는다
   - 400·401·403·404 응답에서는 데이터와 경험치·알림·로그·최근 활동 일시·그룹 상태를 바꾸지 않는다

## 관련 DB 테이블

| 테이블         | 역할                                            |
| -------------- | ----------------------------------------------- |
| `group`        | `portfolio` 컬럼 UPDATE + 그룹장 여부 확인      |
| `group_member` | 전체 멤버 목록 조회 (ExPoint 일괄 처리 시 사용) |
| `members`      | `expoint` 직접 UPDATE                           |
| `expoint_log`  | ExPoint 변동 이력 INSERT                        |
