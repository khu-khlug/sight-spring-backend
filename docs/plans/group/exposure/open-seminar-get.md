# 접수 중인 세미나 조회

현재 활동보고서 제출 또는 세미나 발표 등록의 대상이 되는 세미나와 접수 마감 시각을 조회합니다. [그룹 정책](../../../../../policy/그룹/POLICY.md)의 접수 기간 기준을 따르며, 그룹별 정보가 아닌 공통 세미나 정보를 반환합니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
GET /seminars/current
```

## 권한

USER

## 조건

- `big_seminar`와 연결된 삭제되지 않은 `schedule` 중 `schedule.endAt > 현재`인 세미나를 대상으로 함
- `schedule.scheduledAt` 오름차순, 동률이면 일정 아이디 오름차순으로 첫 번째 세미나 하나를 선택함. [활동보고 제출](activity-report-submit.md#제출-대상과-중복-방지)과 동일한 기준을 적용함
- 세미나 일정의 시작 시각 전에도 조회 대상에 포함하며 별도의 접수 시작일은 두지 않음
- 세미나가 없는 일반 일정, 일정이 없거나 삭제된 세미나는 제외함
- 접수 중인 세미나가 없으면 오류가 아니라 응답 본문으로 JSON `null`을 반환함

## 성공 응답

```
200 OK
```

응답 본문은 세미나 객체 또는 JSON `null`이다. 별도의 `seminar` 필드로 감싸지 않는다. 대상이 있을 때 객체의 필드는 다음과 같다.

| 이름 | 타입 | 설명 |
| :-- | :--: | :-- |
| `id` | 문자열 | 세미나 아이디 (`big_seminar.id`). 활동보고의 `seminarId`와 같은 식별자 |
| `isSummerSeason` | 불리언 | true는 여름, false는 겨울 |
| `isSpeakAfter` | 불리언 | false는 먼저말하기, true는 나중에말하기 |
| `scheduledAt` | 문자열 | 세미나 일정의 시작 시각. ISO 8601 UTC, `Z` 접미사 |
| `endAt` | 문자열 | 세미나 일정의 종료 시각이자 접수 마감 시각. ISO 8601 UTC, `Z` 접미사. 정각부터 접수 종료 |

```json
{
  "id": "seminar-example",
  "isSummerSeason": false,
  "isSpeakAfter": true,
  "scheduledAt": "2026-12-05T05:00:00Z",
  "endAt": "2026-12-05T09:00:00Z"
}
```

접수 중인 세미나가 없을 때는 아래와 같이 반환한다.

```json
null
```

조회 시점의 접수 대상만 반환하며 특정 그룹의 제출 권한·제출 여부를 뜻하지 않는다. 조회 뒤 마감되거나 일정이 변경될 수 있으므로 제출 시에는 제출 API가 접수 대상과 권한을 다시 판단한다.

## 실패 응답

| 상황 | 응답 코드 |
| :-- | :--: |
| 인증되지 않음 | 401 |
| DB 연결 실패 또는 조회 오류 | 500 |

DB 조회 실패를 접수 대상 없음으로 취급해 JSON `null`로 반환하지 않는다.

## 테스트 케이스

1. 인증된 회원은 접수 대상 세미나를 조회할 수 있다
   - 200 응답과 함께 세미나 아이디·계절·발표 순서·시작 시각·종료 시각을 반환한다
   - 그룹 아이디를 받지 않으며 그룹장·그룹원 여부와 관계없이 동일한 접수 대상을 반환한다
2. 시작 전이나 진행 중인 세미나 모두 접수 대상이다
   - 일정이 등록되어 있고 종료 시각이 현재보다 나중이면 시작 시각 전에도 반환한다
   - 시작 시각이 지났더라도 종료 시각 전이면 반환한다
3. 접수 대상이 여러 개이면 제출 API와 같은 세미나를 선택한다
   - 시작 시각이 가장 이른 세미나를 반환하고, 동률이면 일정 아이디가 가장 작은 것을 반환한다
   - 세미나가 없는 일반 일정, 연결 일정이 없거나 삭제된 세미나는 건너뛴다
4. 종료 시각 정각부터 해당 세미나를 제외한다
   - 종료 시각이 현재와 같거나 과거이면 제외하고 다음 접수 대상을 선택한다
   - 접수 대상이 없으면 200 응답과 JSON `null` 본문을 반환한다. 404·204나 빈 본문으로 대신하지 않는다
5. 조회는 데이터를 바꾸지 않는다
   - 활동보고·일정·경험치·알림·로그·그룹 상태를 변경하지 않는다
6. 인증되지 않은 요청과 조회 장애를 구분한다
   - 인증되지 않으면 401, DB 연결 실패·조회 오류이면 500 에러를 반환한다

## 관련 DB 테이블

| 테이블 | 역할 |
| :-- | :-- |
| `big_seminar` | 세미나 식별자·계절·발표 순서 조회 |
| `schedule` | 연결된 세미나 일정의 삭제 여부·종료 시각 검사, 시작 시각과 일정 아이디 기준 선택 |
