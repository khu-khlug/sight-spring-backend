# 그룹 활동 로그 조회

그룹 활동 로그를 최신 로그부터 조회합니다.

로그타입·로그데이터 변경은 [그룹 로그 변경 Task](../../../tasks/group/group-log-format-backend.md)를 따른다. 이 문서의 페이지네이션·행위자·시각 개편은 별도 변경 범위이며 해당 Task에 함께 포함하지 않는다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
GET /groups/:groupId/logs
```

## 권한

USER and 그룹원

## 조건

(해당 없음)

## 제한

- 한 번에 받는 로그 수는 최대 50개이며, 더 필요하면 `skip`을 늘려 다시 요청해야 함

## 부수 효과

(해당 없음)

## 쿼리스트링

| 이름   |    타입    | 기본값 | 설명                                   |
| :----- | :--------: | :----: | :------------------------------------- |
| `skip` | 숫자(uint) |   0    | 최신 로그부터 n개를 건너뛰고 반환      |

## 요청 바디

(해당 없음)

## 성공 응답

```
200 OK
```

| 이름                |      타입      | 설명                                                    |
| :------------------ | :------------: | :------------------------------------------------------ |
| `skip`              |   숫자(uint)   | 최신 로그부터 건너뛴 개수 (요청의 `skip`과 같음)        |
| `totalCount`        |   숫자(uint)   | 로그 총 개수                                            |
| `receivedCount`     |   숫자(uint)   | 받은 로그 수 (`logs` 길이)                              |
| `logs`              |   객체 배열    | 로그 목록. 최신 로그가 앞                               |
| `logs.id`           | 숫자(Long) | 로그 아이디                                             |
| `logs.actor`        |  객체 \| null  | 행위자. 시스템이 남긴 로그면 null                       |
| `logs.actor.userId` | 숫자(Long) | 행위자 회원 아이디                                      |
| `logs.actor.name`   |     문자열     | 행위자 실명. 탈퇴한 회원이어도 기록된 이름을 반환        |
| `logs.logType`      | enum | 필수 로그타입. `LEGACY` 또는 이벤트별 타입. null 불가 |
| `logs.logData`      | 객체 | 필수 로그데이터. `logType`에 대응하는 JSON 객체. null 불가 |
| `logs.createdAt`    |     문자열     | 발생 일시 (ISO 8601 UTC, `Z` 접미사)                    |

### 로그타입과 로그데이터

- `logType`은 `LEGACY`와 이벤트별 enum 50개로 구분한다. 전체 값과 타입별 필수 필드는 [변경 Task의 비즈니스 동작](../../../tasks/group/group-log-format-backend.md#비즈니스-동작)을 따른다.
- `LEGACY`의 `logData`는 `{ "html": "기존 HTML 원문" }`이다. 기존 로그를 이벤트별 타입으로 역추정하거나 원문을 JSON 데이터로 변환하지 않는다.
- 신규 이벤트의 `logData`는 타입별 필드로 구성한 객체다. 부가 데이터가 없는 이벤트도 `{}`로 반환한다.
- `logData`를 직렬화한 문자열로 반환하지 않는다. 완성된 메시지나 HTML·Markdown 링크도 넣지 않는다.
- 이름·제목·소속 등은 발생 당시의 값이다. 대상 리소스가 변경되거나 삭제되어도 현재 값으로 덮어쓰지 않는다.
- 대상 식별자는 별도 필드로 제공한다. 그룹·회원·기록은 숫자(Long), 아직 도메인이 없는 리스트·카드는 문자열이며 [그룹 공통 기준](../global.md)을 따른다.
- 기존 `message` 응답 필드는 제거한다. `type`·`data` 대신 `logType`·`logData`를 사용한다. 전환 기간의 병행 응답은 변경 Task의 배포 절차를 따른다.

## 설계 결정

- 이벤트별 문장 구조가 정해져 있으므로 완성된 Markdown 대신 구조화된 데이터를 제공해 텍스트·대상 식별자·레이블 등의 의미를 분리한다.
- 당시 이름을 보존해 대상 이름 변경이나 삭제로 과거 활동의 내용이 달라지는 것을 방지한다.
- 기존 HTML을 일괄 변환하면 링크와 레이블 색상 등의 정보가 손실될 수 있으므로 LEGACY 원문을 유지한다.

## 테스트 케이스

1. 그룹원은 그룹 활동 로그를 조회할 수 있다
   - 200 응답과 함께 이 그룹의 로그를 최신순으로 최대 50개 반환한다
   - 로그 아이디는 숫자(Long), `createdAt`은 UTC ISO 8601 `Z` 형식이다. 레거시 시각은 저장 시간대를 해석해 UTC로 바꾼다
2. 행위자는 기록 당시 정보로 반환한다
   - 회원이 남긴 로그는 숫자(Long) `userId`와 기록된 실명을 반환한다. 탈퇴한 회원도 그 이름을 유지하며, 시스템 로그의 `actor`는 null이다
3. 로그 내용은 로그타입과 로그데이터로 반환한다
   - 모든 로그에 null이 아닌 `logType`과 JSON 객체 `logData`를 반환한다. 부가 데이터가 없으면 `{}`이며 직렬화한 문자열로 반환하지 않는다
   - 이벤트별 로그는 로그 형식 명세의 필수 필드를 담고, 완성된 문장이나 HTML·Markdown 링크로 대신하지 않는다
   - 레거시 로그는 `logType: LEGACY`, `logData: { html: 원문 }`이며 이벤트 데이터로 바꾸지 않는다
   - 그룹·회원·기록 식별자는 숫자(Long), 리스트·카드 식별자는 문자열이다
4. 로그는 발생 당시 값을 유지한다
   - 대상 이름·제목·소속이 바뀌거나 대상이 삭제돼도 로그의 값은 바뀌지 않는다
5. `skip`으로 범위를 나눠 조회한다
   - 남은 로그가 50개 미만이면 남은 개수만, `skip`이 전체 개수 이상이면 빈 배열을 반환한다
   - 응답 `skip`은 요청 값, `receivedCount`는 반환한 개수, `totalCount`는 이 그룹의 전체 로그 수다
   - 음수·소수·숫자가 아닌 `skip`은 400 에러를 반환한다
6. 그룹 상태와 관계없이 조회할 수 있다
   - 중단·종료 그룹에서도 그룹원이면 200 응답을 반환한다
7. 그룹원만 조회할 수 있다
   - 공개 범위와 관계없이 그룹원이 아니면 403, 인증되지 않으면 401, 그룹이 없으면 404 에러를 반환한다
8. 전환이 끝나면 옛 응답 필드를 반환하지 않는다
   - 최종 전환 뒤에는 `message`·`type`·`data`를 반환하지 않는다. 옛 필드를 함께 보내는 것은 로그 형식 Task의 배포 절차에서만 한다
