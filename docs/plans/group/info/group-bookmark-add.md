# 그룹 즐겨찾기 추가

요청자의 즐겨찾기에 그룹을 추가합니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
POST /groups/:groupId/bookmark
```

## 권한

USER and 열람권한

## 조건

- 중단 상태에서는 실행할 수 없음. [그룹 공통 사항의 중단 상태 동작 제한](../global.md#중단-상태에서의-동작-제한)을 따름
- 요청자가 이 그룹을 아직 즐겨찾기하지 않았어야 함

(해당 없음)

## 실패 응답

| 상황                         | 응답 코드 |
| :--------------------------- | :-------: |
| 이미 즐겨찾기한 그룹임       |    422    |

## 테스트 케이스

1. 즐겨찾기 안 된 그룹에 요청 → `group_bookmark` row INSERT, 201 반환
2. 이미 즐겨찾기 된 그룹에 요청 → 422 반환
3. 존재하지 않는 그룹 ID 요청 → 404 반환
4. 미인증 요청 → 401 반환
5. 추가 성공 시 → 본인에게 알림 발송

## 관련 DB 테이블

| 테이블           | 역할                     |
| ---------------- | ------------------------ |
| `group`          | 그룹 존재 확인           |
| `group_bookmark` | 즐겨찾기 row INSERT      |
