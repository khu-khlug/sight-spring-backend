# 그룹 즐겨찾기 취소

요청자의 즐겨찾기에서 그룹을 제거합니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
DELETE /groups/:groupId/bookmark
```

## 권한

USER and 열람권한

## 조건

- 중단 상태에서는 실행할 수 없음. [그룹 공통 사항의 중단 상태 동작 제한](../global.md#중단-상태에서의-동작-제한)을 따름
- 요청자가 이 그룹을 즐겨찾기한 상태여야 함

## 실패 응답

| :----------------------------- | :-------: |
| 즐겨찾기하지 않은 그룹임       |    422    |

## 테스트 케이스

1. 열람 권한이 있는 회원은 즐겨찾기를 취소할 수 있다
   - 204 응답과 함께 요청자의 즐겨찾기에서 그룹을 빼고, 요청자에게 즐겨찾기 해제 알림을 보낸다
   - 다른 회원의 즐겨찾기는 바뀌지 않는다
2. 즐겨찾기하지 않은 그룹은 취소할 수 없다
   - 422 에러를 반환하며 알림을 보내지 않는다. 동시에 요청해도 한 번만 취소한다
3. 종료된 그룹도 즐겨찾기를 취소할 수 있다
   - 그룹이 `SUCCESS`·`FAIL` 상태여도 취소한다
4. 중단된 그룹은 즐겨찾기를 취소할 수 없다
   - 그룹이 `STOP` 상태면 400 에러를 반환한다
5. 공개 범위에 따라 취소할 수 있는 회원이 정해진다
   - 비공개는 그룹원, 운영진 공개는 운영진, 회원 공개는 교류 회원을 제외한 회원, 완전 공개는 모든 로그인 회원이 취소할 수 있다
   - 범위 밖 회원이면 403, 인증되지 않으면 401, 그룹이 없으면 404 에러를 반환한다
6. 거부된 요청은 아무것도 바꾸지 않는다
   - 400·401·403·404 응답에서는 데이터와 경험치·알림·로그·최근 활동 일시·그룹 상태를 바꾸지 않는다
