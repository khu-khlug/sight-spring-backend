# 그룹 즐겨찾기 취소

요청자의 즐겨찾기에서 그룹을 제거합니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
DELETE /groups/:groupId/bookmark
```

## 권한

USER and 열람권한

## 조건

- 중단 상태에서는 실행할 수 없음. [그룹 공통 사항의 중단 상태 동작 제한](../global.md#중단-상태에서의-동작-제한)을 따름
- 요청자가 이 그룹을 즐겨찾기한 상태여야 함

## 부수 효과

### 경험치 변동

(해당 없음)

### 알림

요청자에게 즐겨찾기 해제 알림

### 그룹 활동 로그

(해당 없음)

(해당 없음)

## 성공 응답

```
204 No Content
```

(해당 없음)

## 실패 응답

| 상황                           | 응답 코드 |
| :----------------------------- | :-------: |
| 즐겨찾기하지 않은 그룹임       |    422    |

## 테스트 케이스

1. 즐겨찾기 된 그룹에 요청 → `group_bookmark` row DELETE, 204 반환
2. 즐겨찾기 안 된 그룹에 요청 → 422 반환
3. 존재하지 않는 그룹 ID 요청 → 404 반환
4. 미인증 요청 → 401 반환

## 관련 DB 테이블

| 테이블           | 역할                     |
| ---------------- | ------------------------ |
| `group`          | 그룹 존재 확인           |
| `group_bookmark` | 즐겨찾기 row DELETE      |
