# 그룹 채팅방 생성

그룹의 채팅방(디스코드 채널)을 만들고 요청자(그룹장)를 참여시킵니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
POST /groups/:groupId/chat-room
```

## 권한

USER and 그룹장

## 조건

- 그룹이 종료(`SUCCESS`·`FAIL`) 상태가 아니어야 함
- 중단 상태에서는 실행할 수 없음. [그룹 공통 사항의 중단 상태 동작 제한](../global.md#중단-상태에서의-동작-제한)을 따름
- 그룹에 완료된 채팅방이 아직 없어야 함. 미완료 생성 작업은 아래 복구 규칙을 따름
- 요청자가 디스코드 계정을 연동해 두었어야 함

## 실패 응답

| 상황                       | 응답 코드 |
| :------------------------- | :-------: |
| 중단되거나 종료된 그룹임 | 400 |
| 그룹에 이미 채팅방이 있음  |    400    |
| 요청자의 디스코드 연동 정보가 없음 |    422    |

## 외부 실패 처리

Discord의 권한 상실(401/403), 채널 없음(404), 호출 제한(429), 5xx·네트워크 오류·타임아웃은 502로 응답한다. SIGHT의 권한/입력 오류와 구분하며 Discord 오류 본문·토큰을 노출하지 않는다. 동기 요청 안에서 변경 호출을 자동 재시도하지 않는다. Discord 성공 여부가 불명확한 경우 성공으로 응답하지 않고, 재요청 전에 외부 상태를 조회하여 이미 완료된 작업을 중복 실행하지 않는다. 조회도 실패한 경우 변경을 재전송하지 않고 502다. 로컬 DB 저장 실패는 500이다. 실패 요청에는 성공 알림·성공 활동 로그를 남기지 않는다.

## 부분 완료와 중복 생성 방지

그룹별 생성 작업을 직렬화하고 외부 호출 전 지속 가능한 작업 식별자를 기록한다. 생성 채널을 이 식별자로 재식별할 수 있게 하며 사용자 메시지 본문은 보관하지 않는다. 채널 생성 후 요청자 참여가 실패하면 채널과 작업의 연결을 복구 가능하게 유지하고 502다. 재요청은 같은 채널에서 참여 단계만 완료한다. DB 실패·타임아웃으로 완료 여부가 불명확해도 외부 상태를 대조하기 전에는 새 채널을 만들지 않는다. 완료된 채팅방이 이미 있는 일반 재요청의 400과 미완료 작업 복구를 구분한다.

## 테스트 케이스

1. 그룹장은 그룹 채팅방을 만들 수 있다
   - Discord 계정을 연동한 그룹장이 요청하면 204 응답과 함께 채널을 만들고 요청자를 참여시킨다
   - 그룹원 전체에게 채팅방 생성 알림을 보내고 채팅방 생성 로그를 남긴다
2. 채팅방은 그룹에 하나만 만들 수 있다
   - 완료된 채팅방이 이미 있으면 400 에러를 반환한다. 동시에 요청해도 채널은 하나만 만든다
3. 요청자의 Discord 계정 연동이 필요하다
   - 연동 정보가 없으면 422 에러를 반환하고 채널을 만들지 않는다
4. Discord 오류는 502다
   - Discord 401/403·404·429·5xx·연결 오류·타임아웃이면 502 에러를 반환하고 알림·로그를 남기지 않는다. 오류 원문과 인증 정보는 노출하지 않는다
5. 중간에 실패한 생성은 다시 요청해 이어서 완료한다
   - 채널 생성 후 참여에 실패하면 502이며, 다시 요청하면 같은 채널에 참여만 완료하고 204를 반환한다
   - Discord 성공 후 DB 저장에 실패하면 500이며, 다시 요청하면 Discord 상태를 확인해 기존 채널을 쓰고 204를 반환한다
   - 결과가 불분명하면 Discord 상태를 확인하기 전에는 채널을 새로 만들지 않는다. 생성 알림·로그는 한 번만 남긴다
6. 중단·종료된 그룹에서는 채팅방을 만들 수 없다
   - 그룹이 `STOP`·`SUCCESS`·`FAIL` 상태면 400 에러를 반환하고 Discord를 호출하지 않는다
7. 그룹장만 채팅방을 만들 수 있다
   - 그룹장이 아니면 운영진이나 그룹원이어도 403, 인증되지 않으면 401, 그룹이 없으면 404 에러를 반환한다
8. 복구용 작업 식별자는 재시작해도 남는다
   - 서버를 재시작해도 작업 식별자를 유지하며, 메시지 내용 캐시로 쓰지 않는다
9. 거부된 요청은 아무것도 바꾸지 않는다
   - 400·401·403·404 응답에서는 데이터와 경험치·알림·로그·최근 활동 일시·그룹 상태를 바꾸지 않는다. Discord도 호출하지 않는다
