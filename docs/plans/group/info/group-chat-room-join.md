# 그룹 채팅방 참여

요청자를 그룹 채팅방(디스코드 채널)에 참여시킵니다. 참여 대상은 항상 요청자 본인이므로 회원 아이디를 받지 않습니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
POST /groups/:groupId/chat-room/join
```

## 권한

USER and 그룹원

## 조건

- 그룹이 종료(`SUCCESS`·`FAIL`) 상태가 아니어야 함
- 중단 상태에서는 실행할 수 없음. [그룹 공통 사항의 중단 상태 동작 제한](../global.md#중단-상태에서의-동작-제한)을 따름
- 그룹에 채팅방이 있어야 함
- 요청자가 아직 채팅방 참여를 완료하지 않았어야 함. 미완료 참여 작업은 아래 복구 규칙을 따름
- 요청자가 디스코드 계정을 연동해 두었어야 함

## 실패 응답

| 상황                             | 응답 코드 |
| :------------------------------- | :-------: |
| 중단되거나 종료된 그룹임 | 400 |
| 그룹에 채팅방이 없음             |    400    |
| 요청자가 이미 채팅방에 참여함    |    400    |
| 요청자의 디스코드 연동 정보가 없음 |    422    |

## 외부 실패 처리

Discord의 권한 상실(401/403), 채널 없음(404), 호출 제한(429), 5xx·네트워크 오류·타임아웃은 502로 응답한다. SIGHT의 권한/입력 오류와 구분하며 Discord 오류 본문·토큰을 노출하지 않는다. 동기 요청 안에서 변경 호출을 자동 재시도하지 않는다. Discord 성공 여부가 불명확한 경우 성공으로 응답하지 않고, 재요청 전에 외부 상태를 조회하여 이미 완료된 작업을 중복 실행하지 않는다. 조회도 실패한 경우 변경을 재전송하지 않고 502다. 로컬 DB 저장 실패는 500이다. 실패 요청에는 성공 알림·성공 활동 로그를 남기지 않는다.

## 참여 완료 복구

회원·채널별 참여 처리를 직렬화하고 처리 중인 작업을 지속 가능하게 기록한다. Discord 참여 성공 후 로컬 완료 기록에 실패하면 재요청에서 Discord 참여 상태를 확인하여 로컬 기록과 알림·로그를 한 번만 완료한다. 이미 완료된 일반 재요청은 400이며 미완료 작업 복구는 204다.

## 테스트 케이스

1. 그룹원은 그룹 채팅방에 참여할 수 있다
   - Discord 계정을 연동한 그룹원이 요청하면 204 응답과 함께 요청자 본인을 채널에 참여시킨다. 다른 회원을 지정할 수 없다
   - 그룹원 전체에게 채팅방 참여 알림을 보내고 채팅방 참여 로그를 남긴다
2. 이미 참여했으면 다시 참여할 수 없다
   - 참여를 완료한 요청자면 400 에러를 반환한다
3. 채팅방이 있어야 한다
   - 그룹에 채팅방이 없으면 400 에러를 반환한다
4. 요청자의 Discord 계정 연동이 필요하다
   - 연동 정보가 없으면 422 에러를 반환한다
5. Discord 오류는 502다
   - Discord 401/403·404·429·5xx·연결 오류·타임아웃이면 502 에러를 반환하고 알림·로그를 남기지 않는다. 오류 원문과 인증 정보는 노출하지 않는다
6. 중간에 실패한 참여는 다시 요청해 이어서 완료한다
   - Discord 참여 후 DB 저장에 실패하면 500이며, 다시 요청하면 Discord 참여 상태를 확인해 완료하고 204를 반환한다. 알림·로그는 한 번만 남긴다
7. 중단·종료된 그룹에서는 참여할 수 없다
   - 그룹이 `STOP`·`SUCCESS`·`FAIL` 상태면 400 에러를 반환하고 Discord를 호출하지 않는다
8. 그룹원만 참여할 수 있다
   - 그룹원이 아니면 403, 인증되지 않으면 401, 그룹이 없으면 404 에러를 반환한다
9. 타임아웃 뒤 다시 요청하면 실제 상태를 먼저 확인한다
   - Discord에서 참여가 이미 완료됐으면 참여 요청을 다시 보내지 않는다. 상태 확인까지 실패하면 502 에러를 반환하고 다시 보내지 않는다
10. 거부된 요청은 아무것도 바꾸지 않는다
    - 400·401·403·404 응답에서는 데이터와 경험치·알림·로그·최근 활동 일시·그룹 상태를 바꾸지 않는다. Discord도 호출하지 않는다
