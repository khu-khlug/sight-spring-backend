# 그룹 참가

요청자가 그룹에 그룹원으로 참가합니다. 신청·승인 절차 없이 즉시 그룹원이 됩니다.

## 운영 그룹인 경우

- 참가 알림을 그룹장 대신 그룹 멤버 전체에게 보냄

## API 경로

```
POST /groups/{groupId}/members/@me
```

## 권한

USER and 열람권한

## 조건

- 요청자가 그룹원이 아니어야 함
- 그룹의 참여 신청 가능 여부(`allowJoin`)가 켜져 있어야 함
- 그룹 상태가 진행 중 또는 중단이어야 함. 종료된 그룹에는 참가할 수 없음

## 부수 효과

### 그룹 상태

실제 변경이 발생하면 중단 상태를 진행 중으로 자동 전환한다. [그룹 공통 사항](../global.md#활동에-따른-중단-상태-해제)을 따른다.


### 경험치 변동

| 대상      | 변동 |
| :-------- | :--: |
| 참가 회원 | +40  |

### 알림

요청자에게 참가 확인 알림, 그룹장에게 참가 알림. 운영(`MANAGE`) 그룹이면 그룹장 대신 그룹 멤버 전체에게 알림

### 그룹 활동 로그

그룹 활동 로그에 멤버 참가를 기록하고 최근 활동 일시를 갱신함

## 실패 응답

| 상황                                     | 응답 코드 |
| :--------------------------------------- | :-------: |
| 요청자가 이미 그룹원임                   |    400    |
| 참여 신청 가능 여부(`allowJoin`)가 꺼져 있음 |    403    |
| 그룹 열람 권한이 없음 | 403 |
| 종료된 그룹임 | 400 |
| 존재하지 않는 그룹임 | 404 |

## 테스트 케이스

1. 조건을 충족한 회원이 그룹에 참여할 수 있다
   - `group_member`에 레코드가 추가되고 `group.count_member`가 1 증가한다
   - `group.changed_at`이 갱신된다. 중단 상태(`suspend`)인 그룹이면 진행 중(`progress`)으로 자동 전환된다
   - 참여자에게 +40 exp가 부여된다
   - 운영 카테고리(`category=manage`) 그룹이면 전 멤버에게 알림이 발송된다. 그 외엔 참여자 본인과 그룹장에게 알림이 발송된다

2. `allow_join`이 꺼진 그룹에는 참여할 수 없다 — 403

3. 그룹 열람 권한이 없으면 참여할 수 없다 — 403

4. 이미 멤버인 경우 400을 반환한다

5. 종료된 그룹에는 참여할 수 없다 — 400

6. 존재하지 않는 그룹이면 404를 반환한다
