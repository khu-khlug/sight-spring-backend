# 그룹 카드 생성

지정한 리스트의 마지막 표시 위치에 카드를 생성합니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
POST /groups/:groupId/lists/:listId/cards
```

## 권한

USER and 그룹원

## 조건

- 그룹이 종료(`SUCCESS`·`FAIL`) 상태가 아니어야 함

## 생성 기본값

| 항목 | 기본값 |
| :-- | :-- |
| 카드설명 | 빈 문자열 |
| 담당자·커버 이미지 | null |
| 레이블 | 빈 배열 |
| `isInPortfolio`·`isDisabled` | false |
| 표시 위치 | 리스트의 마지막 |
| `recordSort` | `NEWEST` |

## 저장 처리

리스트와 그룹의 카드 수를 함께 증가시킨다.

## 새니타이징

- 이름은 앞뒤 공백을 제거하고, 공백만 있는 값과 255자를 초과한 값은 거부한다.

## 부수 효과

### 그룹 상태

실제 변경이 발생하면 중단 상태를 진행 중으로 자동 전환한다. [그룹 공통 사항](../global.md#활동에-따른-중단-상태-해제)을 따른다.

### 경험치 변동

| 대상 | 변동 |
| :-- | :--: |
| 카드를 생성한 요청자 | +1 |

### 알림

그룹원 전체에게 카드 생성 알림

### 그룹 활동 로그

그룹 활동 로그에 카드 생성을 기록하고 최근 활동 일시를 갱신함

## 쿼리스트링

(해당 없음)

## 요청 바디

| 이름 | 타입 | 설명 |
| :-- | :--: | :-- |
| `title` | 문자열 | 필수. 앞뒤 공백 제거 후 비어 있지 않은 이름 |

## 성공 응답

```
201 Created
```

| 이름 | 타입 | 설명 |
| :-- | :--: | :-- |
| `id` | 문자열 | 생성된 카드 아이디 |

## 실패 응답

[그룹 공통 실패 응답](../global.md#공통-실패-응답)을 함께 적용한다.

| 상황 | 응답 코드 |
| :-- | :--: |
| 종료된 그룹임 | 400 |
| 이름이 없거나 공백뿐이거나 255자를 초과함 | 400 |

## 테스트 케이스

1. 그룹원은 리스트에 카드를 만들 수 있다
   - 이름을 보내면 201 응답과 함께 리스트 맨 끝에 카드를 만들고 카드 `id`를 반환한다
   - 설명은 빈 문자열, 담당자·커버 이미지는 null, 레이블은 빈 배열, `isInPortfolio`·`isDisabled`는 false, `recordSort`는 `NEWEST`다
   - 리스트와 그룹의 카드 수를 1씩 늘리고 요청자에게 +1 exp를 지급한다
   - 그룹원 전체에게 카드 생성 알림을 보내고, 카드 생성 로그를 남기고 최근 활동 일시를 갱신한다
2. 이름은 공백이 아닌 255자 이하여야 한다
   - 앞뒤 공백은 제거해 저장한다. 255자는 저장하고, 없거나 공백뿐이거나 256자면 400 에러를 반환한다
3. 종료된 그룹에서는 카드를 만들 수 없다
   - 그룹이 `SUCCESS`·`FAIL` 상태면 400 에러를 반환한다
4. 중단된 그룹에서 카드를 만들면 그룹이 다시 진행 중이 된다
   - 그룹 상태가 `PROGRESS`로 전환된다
5. 그룹원만 카드를 만들 수 있다
   - 그룹원이 아니면 403, 인증되지 않으면 401 에러를 반환한다
6. 경로의 그룹·리스트가 있어야 한다
   - 그룹이 없거나, 리스트가 없거나 다른 그룹의 리스트면 404 에러를 반환한다
7. 거부된 요청은 아무것도 바꾸지 않는다
   - 400·401·403·404 응답에서는 데이터와 경험치·알림·로그·최근 활동 일시·그룹 상태를 바꾸지 않는다
