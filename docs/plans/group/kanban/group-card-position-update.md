# 그룹 카드 위치 변경

같은 리스트 안에서 카드 순서를 변경하거나 같은 그룹의 다른 리스트로 카드를 이동합니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
PATCH /groups/:groupId/cards/:cardId/position
```

경로의 `cardId`는 위치를 변경할 카드다.

## 권한

USER and 그룹원

## 조건

- 그룹이 종료(`SUCCESS`·`FAIL`) 상태가 아니어야 함
- 경로의 카드(`cardId`)가 해당 그룹의 삭제되지 않은 카드여야 함. 비활성 카드도 옮길 수 있음
- 목적지 리스트(`listId`)는 같은 그룹의 리스트여야 함. 현재 리스트와 같으면 순서만 변경함
- 기준 카드(`insertBeforeCardId`)를 지정하면 목적지 리스트의 삭제되지 않은 카드여야 함
- 같은 리스트에서 자기 자신을 기준으로 지정하거나 결과 위치가 같으면 변경 없이 성공함

## 저장 처리

- 카드의 기록과 담당자·레이블 등 위치 외 속성은 유지한다.
- 원본·목적지 리스트의 순서와 카드 수를 하나의 트랜잭션에서 변경한다. 순서 변경 중 동시 요청으로 카드가 중복 소속되거나 빠지지 않도록 해당 순서 구간을 잠근다.

## 부수 효과

### 그룹 상태

실제 변경이 발생하면 중단 상태를 진행 중으로 자동 전환한다. [그룹 공통 사항](../global.md#활동에-따른-중단-상태-해제)을 따른다.

### 그룹 활동 로그

다른 리스트로 이동한 경우에만 그룹 활동 로그에 카드 이동(`CARD_MOVED`)을 기록함. 같은 리스트 안의 순서 변경은 기록하지 않음. 실제 변경 시 최근 활동 일시를 갱신함

## 요청 바디

| 이름 | 타입 | 설명 |
| :-- | :--: | :-- |
| `listId` | 문자열 | 필수. 목적지 리스트 아이디 |
| `insertBeforeCardId` | 문자열 | 선택. 목적지 리스트에서 이 카드 바로 앞에 삽입. 생략하거나 null이면 맨 끝 |

## 성공 응답

```
204 No Content
```

(해당 없음)

## 실패 응답

[그룹 공통 실패 응답](../global.md#공통-실패-응답)을 함께 적용한다.

| 상황 | 응답 코드 |
| :-- | :--: |
| 종료된 그룹임 | 400 |
| 경로의 카드가 삭제됨 | 400 |
| 경로의 카드가 해당 그룹에 없음 | 404 |
| 삽입될 리스트가 이 그룹에 없음 | 400 |
| 기준 카드가 삽입될 리스트에 없음 | 400 |

## 테스트 케이스

1. 그룹원은 같은 리스트 안에서 카드 순서를 바꿀 수 있다
   - `insertBeforeCardId`를 보내면 204 응답과 함께 그 카드 바로 앞으로 옮긴다
   - 기록·담당자·레이블 등 위치 외 속성은 그대로다
   - 로그는 남기지 않고 최근 활동 일시만 갱신한다
2. 다른 리스트로 카드를 옮길 수 있다
   - `listId`에 다른 리스트를 보내면 204 응답과 함께 그 리스트의 기준 카드 앞에 넣는다
   - 원본 리스트의 카드 수는 1 줄고 목적지 리스트의 카드 수는 1 는다
   - 카드 이동 로그를 남기고 최근 활동 일시를 갱신한다
3. 기준 카드를 생략하면 맨 끝으로 간다
   - `insertBeforeCardId`를 생략하거나 null로 보내면 목적지 리스트의 맨 끝으로 옮긴다
4. 위치가 그대로면 아무것도 바뀌지 않는다
   - 같은 리스트에서 자기 자신을 기준으로 지정하거나 결과 위치가 같으면 204 응답을 반환하고 로그·최근 활동 일시를 바꾸지 않는다
5. 목적지 리스트와 기준 카드는 이 그룹에 있어야 한다
   - 목적지 리스트가 이 그룹에 없으면 400 에러를 반환한다
   - 기준 카드가 목적지 리스트에 없거나 삭제된 카드면 400 에러를 반환한다
6. 동시에 옮겨도 카드가 겹치거나 빠지지 않는다
   - 같은 리스트에 대한 동시 요청에서도 카드가 중복 소속되거나 빠지지 않는다
7. 비활성 카드도 옮길 수 있다
   - 비활성 카드도 같은 리스트 안의 순서 변경과 다른 리스트로의 이동이 된다
8. 종료된 그룹에서는 카드를 옮길 수 없다
   - 그룹이 `SUCCESS`·`FAIL` 상태면 400 에러를 반환한다
9. 중단된 그룹에서 카드를 옮기면 그룹이 다시 진행 중이 된다
   - 실제로 위치가 바뀌면 그룹 상태가 `PROGRESS`로 전환된다
10. 삭제된 카드는 옮길 수 없다
    - 경로의 카드가 삭제됐으면 400 에러를 반환한다
11. 그룹원만 카드를 옮길 수 있다
    - 그룹원이 아니면 403, 인증되지 않으면 401 에러를 반환한다
12. 경로의 그룹·카드가 있어야 한다
    - 그룹이 없거나, 카드가 없거나 다른 그룹의 카드면 404 에러를 반환한다
13. 거부된 요청은 아무것도 바꾸지 않는다
    - 400·401·403·404 응답에서는 데이터와 경험치·알림·로그·최근 활동 일시·그룹 상태를 바꾸지 않는다
