# 리스트 카드 목록 조회

특정 리스트의 카드 목록을 추가로 조회합니다. [그룹 리스트 목록 조회](group-lists-get.md)에서 받은 첫 최대 15개 카드 이후의 카드를 이 API로 이어서 가져오며, 한 번에 최대 15개의 카드 요약을 반환합니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
GET /groups/:groupId/lists/:listId/cards
```

## 권한

USER and 열람권한

## 조건

(해당 없음)

## 정렬·범위

- 저장된 카드 표시 순서 오름차순, 동률이면 카드 아이디 오름차순으로 반환한다.
- 비활성 카드도 포함한다.
- 설명 본문과 기록 본문은 포함하지 않는다.

## 부수 효과

(해당 없음)

## 쿼리스트링

| 이름 | 타입 | 설명 |
| :-- | :--: | :-- |
| `skip` | 숫자(uint) | 기본 0. 해당 리스트에서 건너뛸 카드 개수 |

반환 개수는 최대 15개로 고정하며 개수를 지정하는 옵션은 받지 않는다.

## 요청 바디

(해당 없음)

## 성공 응답

```
200 OK
```

| 이름 | 타입 | 설명 |
| :-- | :--: | :-- |
| `skip` | 숫자(uint) | 건너뛴 카드 개수 (요청의 `skip`과 같음) |
| `totalCount` | 숫자(uint) | 해당 리스트의 조회 가능한 전체 카드 수. 리스트 조회의 `lists.cardCount`와 같은 기준으로 집계 |
| `receivedCount` | 숫자(uint) | 이번에 반환한 카드 수. 최대 15 |
| `cards` | 객체 배열 | 카드 요약 목록. 각 항목은 아래 [카드 요약 필드](#카드-요약-필드)를 따름 |

`skip`이 전체 개수 이상이면 빈 배열을 반환한다. 여러 번 조회하는 사이에 카드가 추가·삭제·이동되면 건너뛰는 경계가 달라질 수 있다.

### 카드 요약 필드

| 이름 | 타입 | 설명 |
| :-- | :--: | :-- |
| `id` | 문자열 | 카드 아이디 |
| `title` | 문자열 | 카드 이름 |
| `authorName` | 문자열 | 카드 작성자 실명 |
| `recordCount` | 숫자(uint) | 해당 카드가 직접 소유한 삭제되지 않은 기록 수 |
| `hasDescription` | 불리언 | 설명이 비어 있지 않은지 여부 |
| `isInPortfolio` | 불리언 | 카드의 포트폴리오 포함 여부. 그룹의 발행 상태와 구분 |
| `assigneeUserId` | 숫자(Long) 또는 null | 담당 회원 아이디. 미지정 시 null |
| `assigneeName` | 문자열 또는 null | 담당 회원 실명. 미지정 시 null |
| `coverImageUrl` | 문자열 또는 null | 커버 이미지 주소. 커버가 없으면 null |
| `labels` | 문자열 배열 | [카드 레이블 변경](../card-window/group-card-labels-update.md)의 레이블 값 |
| `isDisabled` | 불리언 | 비활성 여부. 삭제 여부와 구분 |
| `createdAt` | 문자열 | 생성 일시. [그룹 공통 시각 표기](../global.md#그룹-api-시각-표기-utc)를 따름 |

## 실패 응답

[그룹 공통 실패 응답](../global.md#공통-실패-응답)을 함께 적용한다.

| 상황 | 응답 코드 |
| :-- | :--: |
| `skip` 형식이 잘못됨 | 400 |

## 테스트 케이스

1. 열람 권한이 있는 회원은 리스트의 카드 목록을 조회할 수 있다
   - 200 응답과 함께 카드 요약을 저장된 표시 순서로 최대 15개 반환한다. 설명 본문과 기록 본문은 포함하지 않는다
   - `recordCount`는 그 카드의 삭제되지 않은 기록 수다
2. 비활성 카드는 포함하고 삭제된 카드는 뺀다
   - 비활성 카드는 목록에 포함하고, 삭제된 카드는 목록과 개수에서 뺀다
3. `skip`으로 범위를 나눠 조회한다
   - 카드 16개에서 `skip`을 생략하면 15개, `skip=15`면 마지막 1개를 반환한다. `skip`이 전체 개수 이상이면 빈 배열이다
   - 응답 `skip`은 요청 값, `receivedCount`는 반환한 개수, `totalCount`는 리스트 목록 조회의 `lists.cardCount`와 같다
   - 음수·소수·숫자가 아닌 `skip`은 400 에러를 반환한다
4. 순서가 같은 카드는 아이디 순으로 정렬한다
   - 표시 순서가 같으면 카드 아이디 오름차순이며, 페이지 경계에서도 누락·중복이 없다
5. 그룹 상태와 관계없이 조회할 수 있다
   - 중단·종료 그룹에서도 열람 권한이 있으면 200 응답을 반환한다
6. 공개 범위에 따라 열람할 수 있는 회원이 정해진다
   - 비공개는 그룹원, 운영진 공개는 운영진, 회원 공개는 교류 회원을 제외한 회원, 완전 공개는 모든 로그인 회원이 조회할 수 있다
   - 범위 밖 회원이면 403, 인증되지 않으면 401 에러를 반환한다
7. 경로의 그룹·리스트가 있어야 한다
   - 그룹이 없거나, 리스트가 없거나 다른 그룹의 리스트면 404 에러를 반환한다
