# 그룹 리스트 생성

그룹의 마지막 위치에 빈 리스트를 생성합니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
POST /groups/:groupId/lists
```

## 권한

USER and 그룹원

## 조건

- 그룹이 종료(`SUCCESS`·`FAIL`) 상태가 아니어야 함

## 생성 기본값

| 항목 | 기본값 |
| :-- | :-- |
| 설명 | 빈 문자열 |
| 카드 수 | 0 |
| 표시 위치 | 그룹의 마지막 |

## 새니타이징

- 이름은 앞뒤 공백을 제거하고, 공백만 있는 값과 255자를 초과한 값은 거부한다.

## 부수 효과

실제 변경이 발생하면 중단 상태를 진행 중으로 자동 전환한다. [그룹 공통 사항](../global.md#활동에-따른-중단-상태-해제)을 따른다.

## 요청 바디

| 이름 | 타입 | 설명 |
| :-- | :--: | :-- |
| `title` | 문자열 | 필수. 앞뒤 공백 제거 후 비어 있지 않은 이름 |

## 성공 응답

```
201 Created
```

| 이름 | 타입 | 설명 |
| :-- | :--: | :-- |
| `id` | 문자열 | 생성된 리스트 아이디 |

## 실패 응답

[그룹 공통 실패 응답](../global.md#공통-실패-응답)을 함께 적용한다.

| 상황 | 응답 코드 |
| :-- | :--: |
| 종료된 그룹임 | 400 |
| 이름이 없거나 공백뿐이거나 255자를 초과함 | 400 |

## 테스트 케이스

1. 그룹원은 리스트를 만들 수 있다
   - 이름을 보내면 201 응답과 함께 그룹의 마지막 위치에 리스트를 만들고 리스트 `id`를 반환한다
   - 설명은 빈 문자열, 카드 수는 0이다
   - 리스트 생성 로그를 남기고 최근 활동 일시를 갱신한다
2. 이름은 공백이 아닌 255자 이하여야 한다
   - 앞뒤 공백은 제거해 저장한다. 255자는 저장하고, 없거나 공백뿐이거나 256자면 400 에러를 반환한다
3. 종료된 그룹에서는 리스트를 만들 수 없다
   - 그룹이 `SUCCESS`·`FAIL` 상태면 400 에러를 반환한다
4. 중단된 그룹에서 리스트를 만들면 그룹이 다시 진행 중이 된다
   - 그룹 상태가 `PROGRESS`로 전환된다
5. 그룹원만 리스트를 만들 수 있다
   - 그룹원이 아니면 403, 인증되지 않으면 401, 그룹이 없으면 404 에러를 반환한다
6. 거부된 요청은 아무것도 바꾸지 않는다
   - 400·401·403·404 응답에서는 데이터와 경험치·알림·로그·최근 활동 일시·그룹 상태를 바꾸지 않는다
