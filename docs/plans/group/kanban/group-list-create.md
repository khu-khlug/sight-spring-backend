# 그룹 리스트 생성

그룹의 마지막 위치에 빈 리스트를 생성합니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
POST /groups/:groupId/lists
```

## 권한

USER and 그룹원

## 조건

- 그룹이 종료(`SUCCESS`·`FAIL`) 상태가 아니어야 함

## 생성 기본값

| 항목 | 기본값 |
| :-- | :-- |
| 설명 | 빈 문자열 |
| 카드 수 | 0 |
| 표시 위치 | 그룹의 마지막 |

## 새니타이징

- 이름은 앞뒤 공백을 제거하고, 공백만 있는 값과 255자를 초과한 값은 거부한다.

## 부수 효과

### 그룹 상태

실제 변경이 발생하면 중단 상태를 진행 중으로 자동 전환한다. [그룹 공통 사항](../global.md#활동에-따른-중단-상태-해제)을 따른다.

### 경험치 변동

(해당 없음)

### 알림

(해당 없음)

### 그룹 활동 로그

그룹 활동 로그에 리스트 생성을 기록하고 최근 활동 일시를 갱신함

## 쿼리스트링

(해당 없음)

## 요청 바디

| 이름 | 타입 | 설명 |
| :-- | :--: | :-- |
| `title` | 문자열 | 필수. 앞뒤 공백 제거 후 비어 있지 않은 이름 |

## 성공 응답

```
201 Created
```

| 이름 | 타입 | 설명 |
| :-- | :--: | :-- |
| `id` | 문자열 | 생성된 리스트 아이디 |

## 실패 응답

[그룹 공통 실패 응답](../global.md#공통-실패-응답)을 함께 적용한다.

| 상황 | 응답 코드 |
| :-- | :--: |
| 종료된 그룹임 | 400 |
| 이름이 없거나 공백뿐이거나 255자를 초과함 | 400 |
