# 그룹 리스트 삭제

카드가 없는 리스트를 삭제합니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
DELETE /groups/:groupId/lists/:listId
```

## 권한

USER and 그룹원

## 조건

- 그룹이 종료(`SUCCESS`·`FAIL`) 상태가 아니어야 함
- 비활성 카드를 포함하여 리스트에 카드가 하나도 없어야 함

## 부수 효과

### 그룹 상태

실제 변경이 발생하면 중단 상태를 진행 중으로 자동 전환한다. [그룹 공통 사항](../global.md#활동에-따른-중단-상태-해제)을 따른다.
