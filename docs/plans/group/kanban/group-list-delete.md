# 그룹 리스트 삭제

카드가 없는 리스트를 삭제합니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
DELETE /groups/:groupId/lists/:listId
```

## 권한

USER and 그룹원

## 조건

- 그룹이 종료(`SUCCESS`·`FAIL`) 상태가 아니어야 함
- 비활성 카드를 포함하여 리스트에 카드가 하나도 없어야 함

## 부수 효과

## 테스트 케이스

1. 그룹원은 카드가 없는 리스트를 삭제할 수 있다
   - 204 응답과 함께 리스트를 삭제한다
   - 리스트 삭제 로그를 남기고 최근 활동 일시를 갱신한다
2. 카드가 남은 리스트는 삭제할 수 없다
   - 삭제되지 않은 카드가 있으면 400 에러를 반환한다. 비활성 카드만 있어도 400이다
   - 삭제된 카드는 리스트에서 빠지므로 삭제를 막지 않는다
3. 종료된 그룹에서는 리스트를 삭제할 수 없다
   - 그룹이 `SUCCESS`·`FAIL` 상태면 400 에러를 반환한다
4. 중단된 그룹에서 리스트를 삭제하면 그룹이 다시 진행 중이 된다
   - 그룹 상태가 `PROGRESS`로 전환된다
5. 그룹원만 리스트를 삭제할 수 있다
   - 그룹원이 아니면 403, 인증되지 않으면 401 에러를 반환한다
6. 경로의 그룹·리스트가 있어야 한다
   - 그룹이 없거나, 리스트가 없거나 다른 그룹의 리스트면 404 에러를 반환한다
7. 거부된 요청은 아무것도 바꾸지 않는다
   - 400·401·403·404 응답에서는 데이터와 경험치·알림·로그·최근 활동 일시·그룹 상태를 바꾸지 않는다
