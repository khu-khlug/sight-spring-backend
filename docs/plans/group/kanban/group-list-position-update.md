# 그룹 리스트 순서 변경

같은 그룹 안에서 리스트의 표시 위치를 변경합니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
PATCH /groups/:groupId/lists/:listId/position
```

경로의 `listId`는 위치를 변경할 리스트다.

## 권한

USER and 그룹원

## 조건

- 그룹이 종료(`SUCCESS`·`FAIL`) 상태가 아니어야 함
- 경로의 리스트(`listId`)가 이 그룹의 리스트여야 함
- 기준 리스트(`insertBeforeListId`)를 지정하면 같은 그룹의 리스트여야 함
- 자기 자신을 기준으로 지정하거나 결과 순서가 같으면 변경 없이 성공함

## 부수 효과

### 그룹 상태

실제 변경이 발생하면 중단 상태를 진행 중으로 자동 전환한다. [그룹 공통 사항](../global.md#활동에-따른-중단-상태-해제)을 따른다.
