# 그룹 리스트 수정

리스트의 이름과 설명을 변경합니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
PATCH /groups/:groupId/lists/:listId
```

## 권한

USER and 그룹원

## 조건

- 그룹이 종료(`SUCCESS`·`FAIL`) 상태가 아니어야 함
- 수정할 필드를 하나 이상 포함해야 함. 생략한 필드는 유지하며 null은 허용하지 않음

## 새니타이징

- 이름은 앞뒤 공백을 제거하고, 공백만 있는 값과 255자를 초과한 값은 거부한다.
- 리스트 설명은 일반 텍스트 문자열이며 최대 1000자다. 빈 문자열이면 설명을 제거한다.

## 부수 효과

### 그룹 상태

실제 변경이 발생하면 중단 상태를 진행 중으로 자동 전환한다. [그룹 공통 사항](../global.md#활동에-따른-중단-상태-해제)을 따른다.

| :-- | :--: | :-- |
| `title` | 문자열 | 선택. 앞뒤 공백 제거 후 비어 있지 않은 이름 |
