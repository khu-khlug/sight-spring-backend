# 그룹 리스트 수정

리스트의 이름과 설명을 변경합니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
PATCH /groups/:groupId/lists/:listId
```

## 권한

USER and 그룹원

## 조건

- 그룹이 종료(`SUCCESS`·`FAIL`) 상태가 아니어야 함
- 수정할 필드를 하나 이상 포함해야 함. 생략한 필드는 유지하며 null은 허용하지 않음

## 새니타이징

- 이름은 앞뒤 공백을 제거하고, 공백만 있는 값과 255자를 초과한 값은 거부한다.
- 리스트 설명은 일반 텍스트 문자열이며 최대 1000자다. 빈 문자열이면 설명을 제거한다.

## 테스트 케이스

1. 그룹원은 리스트 이름과 설명을 바꿀 수 있다
   - 바꿀 필드만 보내면 204 응답과 함께 그 필드만 바뀌고, 생략한 필드는 그대로다
   - 리스트 수정 로그를 남기고 최근 활동 일시를 갱신한다
2. 이름은 공백이 아닌 255자 이하여야 한다
   - 앞뒤 공백은 제거해 저장한다. 공백뿐이거나 256자면 400 에러를 반환한다
3. 설명은 1000자 이하 일반 텍스트다
   - 1000자는 저장하고 1001자면 400 에러를 반환한다. 빈 문자열이면 설명을 지운다
4. 바꿀 필드가 하나 이상 있어야 한다
   - 필드가 하나도 없거나 필드에 null을 보내면 400 에러를 반환한다
5. 현재와 같은 값으로 요청하면 아무것도 바뀌지 않는다
   - 204 응답을 반환하고 로그·최근 활동 일시를 바꾸지 않는다
6. 종료된 그룹에서는 리스트를 수정할 수 없다
   - 그룹이 `SUCCESS`·`FAIL` 상태면 400 에러를 반환한다
7. 중단된 그룹에서 리스트를 수정하면 그룹이 다시 진행 중이 된다
   - 실제로 바뀌면 그룹 상태가 `PROGRESS`로 전환된다
8. 그룹원만 리스트를 수정할 수 있다
   - 그룹원이 아니면 403, 인증되지 않으면 401 에러를 반환한다
9. 경로의 그룹·리스트가 있어야 한다
   - 그룹이 없거나, 리스트가 없거나 다른 그룹의 리스트면 404 에러를 반환한다
10. 거부된 요청은 아무것도 바꾸지 않는다
    - 400·401·403·404 응답에서는 데이터와 경험치·알림·로그·최근 활동 일시·그룹 상태를 바꾸지 않는다
