# 그룹 리스트 목록 조회

그룹에 속한 리스트를 최대 10개 조회하고, 각 리스트에 속한 카드의 첫 최대 15개를 함께 반환합니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
GET /groups/:groupId/lists
```

## 권한

USER and 열람권한

## 조건

(해당 없음)

## 정렬·범위

- 리스트는 `list_order` 오름차순, 같은 순서이면 리스트 아이디 오름차순으로 반환한다.
- 각 리스트의 카드는 [리스트 카드 목록 조회](group-cards-get.md)와 동일한 정렬·카드 요약 형식을 사용한다. 설명 본문과 기록 본문은 포함하지 않는다.
- 각 리스트의 카드는 항상 처음부터 최대 15개를 반환한다. 특정 리스트의 다음 카드는 리스트 카드 목록 조회 API로 가져온다.

## 부수 효과

(해당 없음)

## 쿼리스트링

| 이름 | 타입 | 설명 |
| :-- | :--: | :-- |
| `skip` | 숫자(uint) | 기본 0. 건너뛸 리스트 개수. 한 번에 최대 10개 반환 |

리스트 수는 10개, 리스트별 첫 카드 수는 15개로 고정하며 개수를 지정하는 옵션은 받지 않는다.

## 요청 바디

(해당 없음)

## 성공 응답

```
200 OK
```

| 이름 | 타입 | 설명 |
| :-- | :--: | :-- |
| `skip` | 숫자(uint) | 건너뛴 리스트 개수 (요청의 `skip`과 같음) |
| `totalCount` | 숫자(uint) | 조회 가능한 전체 리스트 수 |
| `receivedCount` | 숫자(uint) | 이번에 반환한 리스트 수. 최대 10 |
| `lists` | 객체 배열 | 리스트 목록 |
| `lists.id` | 문자열 | 리스트 아이디 |
| `lists.title` | 문자열 | 리스트 이름 |
| `lists.description` | 문자열 | 리스트 설명. 없으면 빈 문자열 |
| `lists.cardCount` | 숫자(uint) | 해당 리스트의 조회 가능한 전체 카드 수. 포함된 카드 개수와 구분 |
| `lists.cards` | 객체 배열 | 해당 리스트의 첫 최대 15개 카드. 각 항목은 [카드 요약 필드](group-cards-get.md#카드-요약-필드)를 따르며 카드가 없으면 빈 배열 |

다음 리스트의 시작 위치는 `skip + receivedCount`다. 이 값이 `totalCount`보다 작으면 다음 리스트가 남아 있다. `skip`이 전체 개수 이상이면 빈 배열을 반환한다. 조회 사이에 리스트가 추가·삭제·이동되면 건너뛰는 경계가 달라질 수 있다.

`lists.cards`의 길이가 `lists.cardCount`보다 작으면 해당 리스트의 카드가 더 남아 있으며, 카드 목록 조회 API에 현재 받은 카드 개수를 `skip`으로 보내 이어서 조회한다. 리스트 조회의 `skip`은 리스트 안의 카드 시작 위치에 영향을 주지 않는다.

## 실패 응답

[그룹 공통 실패 응답](../global.md#공통-실패-응답)을 함께 적용한다.

| 상황 | 응답 코드 |
| :-- | :--: |
| `skip` 형식이 잘못됨 | 400 |

## 테스트 케이스

1. 열람 권한이 있는 회원은 리스트 목록을 조회할 수 있다
   - 200 응답과 함께 리스트를 최대 10개 반환한다. 각 리스트는 아이디·이름·설명·`cardCount`와 처음부터 최대 15개의 카드 요약을 포함한다
   - 설명이 없는 리스트는 빈 문자열이다
2. 리스트는 정해진 순서로 반환한다
   - 표시 순서 오름차순이며, 같으면 리스트 아이디 오름차순이다. 페이지 경계에서도 누락·중복이 없다
3. 각 리스트의 카드는 카드 목록 조회와 같은 기준이다
   - 같은 순서·요약 형식이며 비활성 카드는 포함하고 삭제된 카드는 뺀다
   - 카드가 15개를 넘으면 `cards`는 15개이고 `cardCount`는 전체 카드 수다. 카드가 없으면 `cards`는 빈 배열이다
4. `skip`으로 리스트 범위를 나눠 조회한다
   - 리스트 11개에서 `skip`을 생략하면 10개, `skip=10`이면 마지막 1개를 반환한다. `skip`이 전체 개수 이상이면 빈 배열이다
   - 각 리스트의 카드는 `skip`과 관계없이 처음부터 반환한다
   - 음수·소수·숫자가 아닌 `skip`은 400 에러를 반환한다
5. 그룹 상태와 관계없이 조회할 수 있다
   - 중단·종료 그룹에서도 열람 권한이 있으면 200 응답을 반환한다
6. 공개 범위에 따라 열람할 수 있는 회원이 정해진다
   - 비공개는 그룹원, 운영진 공개는 운영진, 회원 공개는 교류 회원을 제외한 회원, 완전 공개는 모든 로그인 회원이 조회할 수 있다
   - 범위 밖 회원이면 403, 인증되지 않으면 401, 그룹이 없으면 404 에러를 반환한다
