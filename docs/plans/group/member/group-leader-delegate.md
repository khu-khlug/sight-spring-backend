# 그룹장 위임

그룹장이 다른 멤버에게 그룹장을 위임합니다. 위임 후 요청자는 일반 그룹원이 됩니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
PUT /groups/:groupId/leader
```

## 권한

USER and 그룹장

## 조건

- 대상(`userId`)이 그룹 멤버여야 함
- 대상이 요청자 본인이 아니어야 함

## 부수 효과

### 그룹 상태

실제 변경이 발생하면 중단 상태를 진행 중으로 자동 전환한다. [그룹 공통 사항](../global.md#활동에-따른-중단-상태-해제)을 따른다.


### 경험치 변동

(해당 없음)

### 알림

그룹 멤버 전체에게 그룹장 변경 알림

### 그룹 활동 로그

그룹 활동 로그에 그룹장 위임을 기록하고 최근 활동 일시를 갱신함

## 쿼리스트링

(해당 없음)

## 요청 바디

| 이름     |  타입  | 설명                       |
| :------- | :----: | :------------------------- |
| `userId` | 숫자(Long) | 새 그룹장이 될 회원 아이디 |

## 성공 응답

```
204 No Content
```

(해당 없음)

## 실패 응답

| 상황                     | 응답 코드 |
| :----------------------- | :-------: |
| 대상이 그룹 멤버가 아님  |    400    |
| 대상이 요청자 본인임     |    400    |
| 요청자가 그룹장이 아님   |    403    |
| 존재하지 않는 그룹임    |    404    |
| 존재하지 않는 회원임    |    404    |

## 테스트 케이스

기존 [그룹장 위임 문서](../../group-member-delegate.md)의 6개 케이스를 가져오고, 요청은 이 명세의 `PUT /groups/:groupId/leader`와 `{ userId }`를 사용한다.

1. 그룹장이 다른 멤버에게 그룹장을 위임할 수 있다 — 204, 응답 바디 없음
   - `group.master`가 요청의 `userId`로 업데이트된다
   - `group.changed_at`이 갱신된다
   - 중단 상태인 그룹이면 진행 중으로 자동 전환된다. [그룹 공통 사항](../global.md#활동에-따른-중단-상태-해제)을 따른다
   - 그룹 활동 로그에 그룹장 위임이 기록된다
   - 전 멤버에게 그룹장 변경 알림이 발송된다

2. 그룹장이 아닌 회원이 요청하면 403을 반환한다

3. 위임 대상 회원은 존재하지만 그룹 멤버가 아니면 400을 반환한다

4. 자기 자신에게 위임하면 400을 반환한다

5. 존재하지 않는 그룹이면 404를 반환한다

6. 존재하지 않는 회원이면 404를 반환한다
