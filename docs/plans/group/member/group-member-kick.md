# 그룹 멤버 내보내기

그룹장이 다른 멤버를 그룹에서 내보냅니다.

## 운영 그룹인 경우

- 멤버를 내보낼 수 없음 (400)

## API 경로

```
DELETE /groups/:groupId/members/:userId
```

## 권한

USER and 그룹장

## 조건

- 그룹이 종료(`SUCCESS`·`FAIL`) 상태가 아니어야 함
- 그룹 유형이 운영(`MANAGE`)이 아니어야 함
- 대상(`userId`)이 그룹 멤버여야 함
- 대상이 요청자 본인이 아니어야 함

## 부수 효과

### 그룹 상태

실제 변경이 발생하면 중단 상태를 진행 중으로 자동 전환한다. [그룹 공통 사항](../global.md#활동에-따른-중단-상태-해제)을 따른다.


### 경험치 변동

| 대상          | 변동 |
| :------------ | :--: |
| 내보내진 회원 | -40  |

### 알림

내보내진 회원에게 알림

### 그룹 활동 로그

그룹 활동 로그에 멤버 내보내기를 기록하고 최근 활동 일시를 갱신함

## 쿼리스트링

(해당 없음)

## 요청 바디

(해당 없음)

## 성공 응답

```
204 No Content
```

(해당 없음)

## 실패 응답

| 상황                              | 응답 코드 |
| :-------------------------------- | :-------: |
| 종료된 그룹임                     |    400    |
| 운영(`MANAGE`) 그룹임             |    400    |
| 대상이 그룹 멤버가 아님           |    400    |
| 대상이 요청자 본인임              |    400    |
| 요청자가 그룹장이 아님 | 403 |
| 존재하지 않는 그룹임 | 404 |
| 존재하지 않는 회원임 | 404 |

## 테스트 케이스

1. 그룹장은 그룹원을 내보낼 수 있다
   - 204 응답과 함께 대상의 그룹원 관계를 지우고 그룹원 수를 1 줄인다. 대상에게 -40 exp를 적용한다
   - 내보낸 회원에게 알림을 보내고, 멤버 내보내기 로그를 남기고 최근 활동 일시를 갱신한다
2. 운영 그룹에서는 내보낼 수 없다
   - 운영(`MANAGE`) 그룹이면 400 에러를 반환한다
3. 내보낼 대상은 요청자가 아닌 그룹원이어야 한다
   - 대상이 그룹원이 아니거나 요청자 본인이면 400 에러를 반환한다. 이미 내보낸 회원을 다시 내보내도 400이다
   - 대상 회원이 없으면 404 에러를 반환한다
4. 종료된 그룹에서는 내보낼 수 없다
   - 그룹이 `SUCCESS`·`FAIL` 상태면 400 에러를 반환한다
5. 중단된 그룹에서 내보내면 그룹이 다시 진행 중이 된다
   - 그룹 상태가 `PROGRESS`로 전환된다
6. 그룹장만 내보낼 수 있다
   - 그룹장이 아니면 403, 인증되지 않으면 401, 그룹이 없으면 404 에러를 반환한다
7. DB 처리가 실패하면 모두 되돌린다
   - 트랜잭션 도중 실패하면 회원 관계·그룹장·그룹원 수·경험치와 경험치 이력·알림·로그·중단 해제를 함께 되돌린다
8. 동시에 요청해도 한 번만 반영한다
   - 같은 회원에 대한 동시 요청도 그룹원 관계 변경과 경험치 차감은 한 번만 반영한다
9. 거부된 요청은 아무것도 바꾸지 않는다
   - 400·401·403·404 응답에서는 데이터와 경험치·알림·로그·최근 활동 일시·그룹 상태를 바꾸지 않는다
