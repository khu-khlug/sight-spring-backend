# 그룹 멤버 내보내기

그룹장이 다른 멤버를 그룹에서 내보냅니다.

## 운영 그룹인 경우

- 멤버를 내보낼 수 없음 (400)

## API 경로

```
DELETE /groups/{groupId}/members/{memberId}
```

## 권한

USER and 그룹장

## 조건

- 그룹 유형이 운영(`MANAGE`)이 아니어야 함
- 대상(`memberId`)이 그룹 멤버여야 함
- 대상이 요청자 본인이 아니어야 함

## 부수 효과

### 그룹 상태

실제 변경이 발생하면 중단 상태를 진행 중으로 자동 전환한다. [그룹 공통 사항](../global.md#활동에-따른-중단-상태-해제)을 따른다.


### 경험치 변동

| 대상          | 변동 |
| :------------ | :--: |
| 내보내진 회원 | -40  |

### 알림

내보내진 회원에게 알림

### 그룹 활동 로그

그룹 활동 로그에 멤버 내보내기를 기록하고 최근 활동 일시를 갱신함

## 쿼리스트링

(해당 없음)

(해당 없음)

```

```

(해당 없음)

## 실패 응답

| 상황                              | 응답 코드 |
| :-------------------------------- | :-------: |
| 운영(`MANAGE`) 그룹임             |    400    |
| 대상이 그룹 멤버가 아님           |    400    |
| 대상이 요청자 본인임              |    400    |
| 요청자가 그룹장이 아님 | 403 |
| 존재하지 않는 그룹임 | 404 |
| 존재하지 않는 회원임 | 404 |

## 테스트 케이스

1. 그룹장이 멤버를 정상적으로 내보낼 수 있다
   - `group_member` 레코드가 삭제되고 `group.count_member`가 1 감소한다
   - `group.changed_at`이 갱신된다. 중단 상태(`suspend`)인 그룹이면 진행 중(`progress`)으로 자동 전환된다
   - 내보내진 멤버에게 -40 exp가 차감된다
   - 내보내진 멤버에게 알림이 발송된다

2. 그룹장이 아닌 회원이 요청하면 403을 반환한다

3. 운영 카테고리(`category=manage`) 그룹에서는 내보내기를 할 수 없다 — 400

4. 자기 자신을 내보낼 수 없다 — 400

5. 대상이 그룹 멤버가 아니면 400을 반환한다

6. 존재하지 않는 그룹이면 404를 반환한다

7. 존재하지 않는 회원이면 404를 반환한다
