# 그룹 멤버 목록 조회

그룹 멤버 목록을 조회합니다. 서버가 그룹장을 맨 앞에 두고, 나머지는 회원 실명(`members[].name`) 오름차순으로 정렬해서 반환합니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
GET /groups/:groupId/members
```

## 권한

USER and 열람권한

## 조건

(해당 없음)

## 부수 효과

(해당 없음)

## 쿼리스트링

(해당 없음)

## 요청 바디

(해당 없음)

## 성공 응답

```
200 OK
```

| 이름                  |    타입    | 설명                                                                 |
| :-------------------- | :--------: | :------------------------------------------------------------------- |
| `leaderUserId`        | 숫자(Long) | 그룹장의 회원 아이디                                                 |
| `members`             | 객체 배열  | 서버에서 정렬한 전체 멤버 목록. 그룹장이 맨 앞, 나머지는 회원 실명(`name`) 오름차순 |
| `members.userId`      | 숫자(Long) | 회원 아이디                                                          |
| `members.name`        |   문자열   | 회원 실명                                                            |
| `members.college`     |   문자열   | 소속 단과대학명                                                      |
| `members.cardCount`   | 숫자(uint) | 이 그룹에서 해당 회원이 만든 카드 중 삭제되지 않은 카드 수           |
| `members.recordCount` | 숫자(uint) | 이 그룹에서 해당 회원이 작성한 기록 중 삭제되지 않은 기록 수         |

## 실패 응답

| 상황 | 응답 코드 |
| :-- | :--: |
| 인증되지 않음 | 401 |
| 그룹 열람 권한이 없음 | 403 |
| 존재하지 않는 그룹임 | 404 |

## 테스트 케이스

기존 [그룹 멤버 목록 조회 문서](../../group-member-list.md)의 3개 케이스를 새 응답·정렬 기준에 맞춰 반영하고, 추가 필드의 검증 항목을 보완한다.

1. 열람 권한이 있는 회원이 멤버 목록을 조회하면 200을 반환한다
   - 최상위 `leaderUserId`는 `group.master`와 같은 Long 숫자다
   - `members`에는 이 그룹에 참여 중인 멤버가 반환된다
   - 각 멤버는 `userId`, `name`, `college`, `cardCount`, `recordCount`를 포함한다
   - `userId`는 Long 숫자이며 `name`은 로그인 아이디가 아닌 실명이다
   - 기존 `members[].realname`과 `members[].isLeader`는 반환하지 않는다

2. 공개 범위(`grade`)에 따라 열람 가능 여부가 결정된다
   - 비공개(`grade=0`): 그룹원 또는 그룹 생성자는 조회할 수 있다. 둘 다 아닌 회원은 403을 반환한다
   - 운영진 공개(`grade=2`): 운영진은 조회할 수 있고 일반 회원은 403을 반환한다
   - 회원 공개(`grade=3`): 재학·휴학·졸업 회원은 조회할 수 있고 교류 회원은 403을 반환한다
   - 완전 공개(`grade=4`): 교류 회원을 포함한 모든 로그인 회원이 조회할 수 있다

3. 존재하지 않는 그룹을 조회하면 404를 반환한다

4. 서버가 그룹장 우선, 나머지는 회원 실명 오름차순으로 정렬하여 반환한다
   - 그룹장의 실명이 이름순으로 가장 뒤에 오더라도 그룹장은 목록 맨 앞에 반환된다
   - 나머지 멤버는 `members[].name` 오름차순으로 반환된다
   - 회원 아이디순·그룹 참여순과 실명순이 다른 데이터에서도 실명순으로 반환된다

5. 멤버별 소속을 정확히 반환한다
   - `members[].college`는 해당 회원의 소속 단과대학명이다

6. 멤버별 카드·기록 수는 이 그룹에서 본인이 작성한 삭제되지 않은 항목만 집계한다
   - `cardCount`는 해당 회원이 작성한 카드 수이며, 담당자로 지정됐다는 이유만으로 집계하지 않는다
   - `recordCount`는 해당 회원이 작성한 기록 수다
   - 다른 그룹의 항목, 다른 회원이 작성한 항목, 삭제된 항목은 각 집계에서 제외한다
   - 해당하는 카드·기록이 없는 멤버는 각각 숫자 0을 반환한다

7. 인증되지 않은 요청은 401을 반환한다
