# 그룹 멤버 목록 조회

그룹 멤버 목록을 조회합니다. 서버가 그룹장을 맨 앞에 두고, 나머지는 회원 실명(`members[].name`) 오름차순으로 정렬해서 반환합니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
GET /groups/:groupId/members
```

## 권한

USER and 열람권한

## 조건

(해당 없음)

## 부수 효과

(해당 없음)

## 쿼리스트링

(해당 없음)

## 요청 바디

(해당 없음)

## 성공 응답

```
200 OK
```

| 이름                  |    타입    | 설명                                                                 |
| :-------------------- | :--------: | :------------------------------------------------------------------- |
| `leaderUserId`        | 숫자(Long) | 그룹장의 회원 아이디                                                 |
| `members`             | 객체 배열  | 서버에서 정렬한 전체 멤버 목록. 그룹장이 맨 앞, 나머지는 회원 실명(`name`) 오름차순 |
| `members.userId`      | 숫자(Long) | 회원 아이디                                                          |
| `members.name`        |   문자열   | 회원 실명                                                            |
| `members.college`     |   문자열   | 소속 단과대학명                                                      |
| `members.cardCount`   | 숫자(uint) | 이 그룹에서 해당 회원이 만든 카드 중 삭제되지 않은 카드 수           |
| `members.recordCount` | 숫자(uint) | 이 그룹에서 해당 회원이 작성한 기록 중 삭제되지 않은 기록 수         |

## 실패 응답

| 상황 | 응답 코드 |
| :-- | :--: |
| 인증되지 않음 | 401 |
| 그룹 열람 권한이 없음 | 403 |
| 존재하지 않는 그룹임 | 404 |

## 테스트 케이스

1. 열람 권한이 있는 회원은 그룹원 목록을 조회할 수 있다
   - 200 응답과 함께 `leaderUserId`와 그룹원 목록을 반환한다. 아이디는 숫자(Long)다
   - 각 그룹원은 `userId`, 실명 `name`, 소속 단과대학 `college`, `cardCount`, `recordCount`를 포함한다
2. 그룹장이 맨 앞이고 나머지는 실명 순이다
   - 그룹장은 이름순과 관계없이 맨 앞이고, 나머지는 실명 오름차순이다
3. 카드·기록 수는 이 그룹에서 본인이 작성한 삭제되지 않은 항목만 센다
   - 담당자로 지정된 카드는 세지 않고, 다른 그룹·다른 회원의 항목과 삭제된 항목은 뺀다. 없으면 0이다
4. 그룹 상태와 관계없이 조회할 수 있다
   - 중단·종료 그룹에서도 열람 권한이 있으면 200 응답을 반환한다
5. 공개 범위에 따라 열람할 수 있는 회원이 정해진다
   - 비공개(`PRIVATE`)는 그룹원만 조회할 수 있다. 그룹을 만든 회원이라도 그룹원이 아니면 403 에러를 반환한다
   - 운영진 공개(`MANAGER_ONLY`)는 운영진, 회원 공개(`MEMBER_ONLY`)는 교류 회원을 제외한 회원, 완전 공개(`PUBLIC`)는 모든 로그인 회원이 조회할 수 있다
   - 범위 밖 회원이면 403, 인증되지 않으면 401, 그룹이 없으면 404 에러를 반환한다
