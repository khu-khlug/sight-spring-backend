# 그룹 저장소 파일 트리 조회

요청한 커밋 시점의 파일·디렉터리 경로 목록을 조회합니다. 커밋 대신 브랜치를 지정하면 그 브랜치의 끝(HEAD) 커밋을 대상으로 조회합니다.

공용 GitHub 토큰의 사용자별 호출량은 [저장소 API 공통 사항](global.md)을 따릅니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
GET /groups/:groupId/repository/file-tree
```

## 권한

USER and 열람권한

## 조건

- `url`이 그룹에 등록된 저장소 URL(`repositoryUrls`) 중 하나여야 함
- `branch`와 `commitSha` 중 정확히 하나만 보내야 함
- `commitSha`를 보내면 해당 저장소에 있는 커밋이어야 함
- `branch`를 보내면 해당 저장소에 있는 브랜치여야 함

## 대상 커밋 결정

- `commitSha`를 보내면 그 커밋을 대상으로 한다.
- `branch`를 보내면 그 브랜치의 끝 커밋을 대상으로 한다. 끝 커밋은 [브랜치 커밋 캐시](global.md#브랜치-커밋-캐시)의 0페이지 첫 커밋으로 정하며, 캐시가 없거나 유효기간이 지났으면 공통 규칙대로 조회·재검증한다.
- 대상 커밋이 정해진 뒤의 파일 트리 조회와 캐시는 `commitSha`를 보낸 경우와 같다.

## 제한

- 저장소 서비스가 한 번에 돌려줄 수 있는 항목 수를 넘으면 일부만 반환하고 `truncated`를 true로 표시함
  - GitHub 트리 API는 재귀 조회 시 최대 100,000개 항목, 7MB까지만 반환함

## 새니타이징

- `commitSha`는 16진수 문자(7~40자)만 허용한다.
- `branch`는 원문 값으로 받으며, 인코딩은 [공통 사항의 쿼리 값 인코딩](global.md#쿼리-값-인코딩)을 따른다.

## 부수 효과

공용 토큰의 GitHub 기본 호출 한도를 실제로 소모한 경우에만 원인 사용자의 시간당 할당량을 차감함. 인증된 조건부 GET의 `304`는 차감하지 않음. 캐시 재검증과 공통 fetcher의 호출 제어는 [공통 사항](global.md)을 따름.

## 쿼리스트링

| 이름        |  타입  | 설명          |
| :---------- | :----: | :------------ |
| `url`       | 문자열 | 저장소 URL    |
| `commitSha` | 문자열 | 대상 커밋 SHA. `branch`와 둘 중 하나만 보냄 |
| `branch` | 문자열 | 대상 브랜치 이름. 그 브랜치의 끝 커밋을 대상으로 함. `commitSha`와 둘 중 하나만 보냄 |
| `refresh` | 불리언 | 생략 가능, 기본값 `false`. 파일 트리 캐시는 영구라 재검증하지 않음. `branch`로 요청하면 `true`일 때 끝 커밋을 결정하는 브랜치 커밋 캐시를 재검증함. [공통 사항](global.md) 참고 |

## 요청 바디

(해당 없음)

## 성공 응답

```
200 OK
```

| 이름              |      타입      | 설명                                                                        |
| :---------------- | :------------: | :-------------------------------------------------------------------------- |
| `commitSha`       |     문자열     | 조회한 커밋 SHA. `branch`로 요청했으면 결정된 끝 커밋 SHA                   |
| `truncated`       |     불리언     | 항목이 너무 많아 일부만 반환했는지                                          |
| `entries`         |   객체 배열    | 경로 목록                                                                   |
| `entries.path`    |     문자열     | 저장소 루트 기준 경로                                                       |
| `entries.type`    |      enum      | `file`(파일) \| `dir`(디렉터리)                                            |
| `entries.rawUrl`  | 문자열 \| null | 파일 원문을 바로 받을 수 있는 주소. `file`일 때만 있고 `dir`이면 null      |

### 파일 원문 주소

`entries.rawUrl`은 저장소 서비스의 원문 주소(GitHub이면 `https://raw.githubusercontent.com/...`)로만 만든다.

## 실패 응답

| 상황                                           | 응답 코드 |
| :--------------------------------------------- | :-------: |
| `url`이 그룹에 등록된 저장소가 아님            |    400    |
| `branch`와 `commitSha`를 둘 다 보냈거나 둘 다 보내지 않음 |    400    |
| `commitSha`가 저장소에 없음                    |    404    |
| `branch`가 저장소에 없음                       |    404    |
| 저장소 서비스 요청 한도를 넘었거나 응답이 실패함 |    502    |
| 실제 GitHub 호출이 필요하지만 원인 사용자의 시간당 100회 할당량이 소진됨 | 429 |
| `refresh`가 `true`·`false`가 아님 | 400 |
| 같은 저장소에 1분 안에 `refresh=true`를 10번 넘게 요청함 | 429 |
