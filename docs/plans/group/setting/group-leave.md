# 그룹 나가기

요청자가 그룹에서 탈퇴합니다.

## 운영 그룹인 경우

- 탈퇴 알림을 그룹장 대신 그룹 멤버 전체에게 보냄
- 그룹장도 위임 없이 탈퇴할 수 있음. 운영 그룹에서는 그룹장이 특별한 권한을 갖지 않으므로, 그룹장이 탈퇴하면 남은 그룹원 중 한 명을 그룹장으로 지정함. 누구를 지정할지에 대한 기준은 두지 않음
- 그룹장이 마지막 그룹원이라 남은 그룹원이 없으면 그룹장을 지정하지 않음

## API 경로

```
DELETE /groups/:groupId/members/@me
```

## 권한

USER and 그룹원

## 조건

- 그룹이 종료(`SUCCESS`·`FAIL`) 상태가 아니어야 함
- 운영(`MANAGE`) 그룹이 아닌 경우, 그룹장은 먼저 다른 멤버에게 그룹장을 위임해야 함

## 부수 효과

### 그룹 상태

실제 변경이 발생하면 중단 상태를 진행 중으로 자동 전환한다. [그룹 공통 사항](../global.md#활동에-따른-중단-상태-해제)을 따른다.


### 경험치 변동

| 대상        | 변동 |
| :---------- | :--: |
| 탈퇴한 회원 | -40  |

### 알림

요청자와 그룹장에게 탈퇴 알림. 운영(`MANAGE`) 그룹이면 그룹장 대신 그룹 멤버 전체에게 알림

### 그룹 활동 로그

그룹 활동 로그에 멤버 탈퇴를 기록하고 최근 활동 일시를 갱신함


## 실패 응답

| 상황                                     | 응답 코드 |
| :--------------------------------------- | :-------: |
| 종료된 그룹임 | 400 |
| 운영 그룹이 아닌데 그룹장이 위임하지 않고 나가려 함 | 400 |
| 요청자가 그룹원이 아님 | 400 |
| 존재하지 않는 그룹임 | 404 |

## 테스트 케이스

1. 그룹원은 그룹에서 나갈 수 있다
   - 204 응답과 함께 그룹원 관계를 지우고 그룹원 수를 1 줄인다. 나간 회원에게 -40 exp를 적용한다
   - 나간 회원과 그룹장에게 알림을 보낸다. 운영(`MANAGE`) 그룹이면 그룹장 대신 그룹원 전체에게 보낸다
   - 멤버 탈퇴 로그를 남기고 최근 활동 일시를 갱신한다
2. 일반 그룹의 그룹장은 위임한 뒤에 나갈 수 있다
   - 운영(`MANAGE`) 그룹이 아닌데 그룹장이 나가려 하면 400 에러를 반환한다
3. 운영 그룹의 그룹장은 바로 나갈 수 있다
   - 남은 그룹원 중 한 명이 그룹장이 된다. 남은 그룹원이 없으면 그룹장을 지정하지 않는다
4. 그룹원이 아니면 나갈 수 없다
   - 그룹원이 아니면 400 에러를 반환한다. 이미 나간 뒤 다시 요청해도 400이며 경험치를 다시 차감하지 않는다
5. 종료된 그룹에서는 나갈 수 없다
   - 그룹이 `SUCCESS`·`FAIL` 상태면 400 에러를 반환한다
6. 중단된 그룹에서 나가면 그룹이 다시 진행 중이 된다
   - 그룹 상태가 `PROGRESS`로 전환된다
7. 인증된 회원만 요청할 수 있다
   - 인증되지 않으면 401, 그룹이 없으면 404 에러를 반환한다
8. DB 처리가 실패하면 모두 되돌린다
   - 트랜잭션 도중 실패하면 회원 관계·그룹장·그룹원 수·경험치와 경험치 이력·알림·로그·중단 해제를 함께 되돌린다
9. 동시에 요청해도 한 번만 반영한다
   - 같은 회원에 대한 동시 요청도 그룹원 관계 변경과 경험치 차감은 한 번만 반영한다
10. 거부된 요청은 아무것도 바꾸지 않는다
    - 400·401·403·404 응답에서는 데이터와 경험치·알림·로그·최근 활동 일시·그룹 상태를 바꾸지 않는다
