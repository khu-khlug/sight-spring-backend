# 그룹 나가기

요청자가 그룹에서 탈퇴합니다.

## 운영 그룹인 경우

- 탈퇴 알림을 그룹장 대신 그룹 멤버 전체에게 보냄
- 그룹장도 위임 없이 탈퇴할 수 있음. 운영 그룹에서는 그룹장이 특별한 권한을 갖지 않으므로, 그룹장이 탈퇴하면 남은 그룹원 중 한 명을 그룹장으로 지정함. 누구를 지정할지에 대한 기준은 두지 않음
- 그룹장이 마지막 그룹원이라 남은 그룹원이 없으면 그룹장을 지정하지 않음

## API 경로

```
DELETE /groups/{groupId}/members/@me
```

## 권한

USER and 그룹원

## 조건

- 운영(`MANAGE`) 그룹이 아닌 경우, 그룹장은 먼저 다른 멤버에게 그룹장을 위임해야 함

## 부수 효과

### 그룹 상태

실제 변경이 발생하면 중단 상태를 진행 중으로 자동 전환한다. [그룹 공통 사항](../global.md#활동에-따른-중단-상태-해제)을 따른다.


### 경험치 변동

| 대상        | 변동 |
| :---------- | :--: |
| 탈퇴한 회원 | -40  |

### 알림

요청자와 그룹장에게 탈퇴 알림. 운영(`MANAGE`) 그룹이면 그룹장 대신 그룹 멤버 전체에게 알림

### 그룹 활동 로그

그룹 활동 로그에 멤버 탈퇴를 기록하고 최근 활동 일시를 갱신함

## 실패 응답

| 상황                                     | 응답 코드 |
| :--------------------------------------- | :-------: |
| 운영 그룹이 아닌데 그룹장이 위임하지 않고 나가려 함 | 400 |
| 요청자가 그룹원이 아님 | 400 |
| 존재하지 않는 그룹임 | 404 |

## 테스트 케이스

1. 그룹 멤버가 정상적으로 탈퇴할 수 있다
   - `group_member` 레코드가 삭제되고 `group.count_member`가 1 감소한다
   - `group.changed_at`이 갱신된다. 중단 상태(`suspend`)인 그룹이면 진행 중(`progress`)으로 자동 전환된다
   - 탈퇴자에게 -40 exp가 차감된다
   - 운영 카테고리(`category=manage`) 그룹이면 전 멤버에게 알림이 발송된다. 그 외엔 탈퇴자 본인과 그룹장에게 알림이 발송된다

2. 운영 카테고리가 아닌 그룹에서 그룹장은 탈퇴할 수 없다 — 400
   - 먼저 다른 멤버에게 그룹장을 위임해야 한다
   - 운영 카테고리 그룹에서는 그룹장도 탈퇴할 수 있으며, 남은 그룹원 중 한 명이 그룹장으로 지정된다. 남은 그룹원이 없으면 그룹장을 지정하지 않는다

3. 그룹 멤버가 아니면 400을 반환한다

4. 존재하지 않는 그룹이면 404를 반환한다
