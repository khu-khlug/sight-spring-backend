# 그룹 활동 종료

그룹의 활동을 성공 또는 실패로 종료합니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
PUT /groups/:groupId/status/end
```

## 권한

USER and (그룹장 or 운영진)

## 조건

- 중단 상태에서는 실행할 수 없음. [그룹 공통 사항의 중단 상태 동작 제한](../global.md#중단-상태에서의-동작-제한)을 따름
- 현재 상태가 진행중(`PROGRESS`)이어야 함
- `status`는 `SUCCESS` 또는 `FAIL`이어야 함

## 부수 효과

### 경험치 변동

| 바꾼 상태 | 대상 | 변동 |
| :-- | :-- | :--: |
| `SUCCESS` | 현재 멤버 전체 | +90 |
| `FAIL` | 현재 멤버 전체 | +70 |

### 알림

그룹 멤버 전체에게 그룹 종료(성공·실패) 알림

### 그룹 활동 로그

그룹 활동 로그에 활동 종료를 기록함

## 쿼리스트링

(해당 없음)

## 요청 바디

| 이름 | 타입 | 설명 |
| :-- | :--: | :-- |
| `status` | enum | 필수. `SUCCESS`(종료(성공)) 또는 `FAIL`(종료(실패)) |

## 성공 응답

```
204 No Content
```

(해당 없음)

## 실패 응답

| 상황 | 응답 코드 |
| :-- | :--: |
| 그룹장도 운영진도 아님 | 403 |
| 현재 상태가 진행중(`PROGRESS`)이 아님 | 400 |
| `status`가 없거나 `SUCCESS`·`FAIL`이 아님 | 400 |

이미 종료된 그룹에는 경험치를 다시 지급하거나 종료 로그·알림을 중복 생성하지 않음
