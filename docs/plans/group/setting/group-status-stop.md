# 그룹 활동 중단

진행 중인 그룹을 중단 상태로 변경합니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
PUT /groups/:groupId/status/stop
```

## 권한

USER and 운영진

## 조건

- 중단 상태에서는 실행할 수 없음. [그룹 공통 사항의 중단 상태 동작 제한](../global.md#중단-상태에서의-동작-제한)을 따름
- 현재 상태가 진행중(`PROGRESS`)이어야 함
- 그룹장이라도 운영진이 아니면 직접 중단시킬 수 없음

## 부수 효과

### 경험치 변동

(해당 없음)

### 알림

그룹 멤버 전체에게 그룹 중단 알림

### 그룹 활동 로그

그룹 활동 로그에 활동 중단을 기록함

## 실패 응답

| 상황 | 응답 코드 |
| :-- | :--: |
| 운영진이 아님 | 403 |
| 현재 상태가 진행중(`PROGRESS`)이 아님 | 400 |

이미 중단된 그룹에는 중단 로그·알림을 중복 생성하지 않음
