# 그룹 활동 중단

진행 중인 그룹을 중단 상태로 변경합니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
PUT /groups/:groupId/status/stop
```

## 권한

USER and 운영진

## 조건

- 중단 상태에서는 실행할 수 없음. [그룹 공통 사항의 중단 상태 동작 제한](../global.md#중단-상태에서의-동작-제한)을 따름
- 현재 상태가 진행중(`PROGRESS`)이어야 함
- 그룹장이라도 운영진이 아니면 직접 중단시킬 수 없음

## 부수 효과

### 경험치 변동

(해당 없음)

### 알림

그룹 멤버 전체에게 그룹 중단 알림

### 그룹 활동 로그

그룹 활동 로그에 활동 중단을 기록함

(해당 없음)

## 요청 바디

(해당 없음)

## 성공 응답

```
204 No Content
```

(해당 없음)

## 실패 응답

| 상황 | 응답 코드 |
| :-- | :--: |
| 운영진이 아님 | 403 |
| 현재 상태가 진행중(`PROGRESS`)이 아님 | 400 |

이미 중단된 그룹에는 중단 로그·알림을 중복 생성하지 않음

## 테스트 케이스

1. 운영진은 진행 중인 그룹을 중단할 수 있다
   - 204 응답과 함께 `STOP`으로 바꾼다
   - 그룹원 전체에게 중단 알림을 보내고 활동 중단 로그를 남긴다
2. 진행 중인 그룹만 중단할 수 있다
   - 이미 중단됐거나 종료된 그룹이면 400 에러를 반환하며 알림·로그를 다시 남기지 않는다
3. 운영진만 중단할 수 있다
   - 그룹장이라도 운영진이 아니면 403 에러를 반환한다
   - 인증되지 않으면 401, 그룹이 없으면 404 에러를 반환한다
4. 거부된 요청은 아무것도 바꾸지 않는다
   - 400·401·403·404 응답에서는 데이터와 경험치·알림·로그·최근 활동 일시·그룹 상태를 바꾸지 않는다
