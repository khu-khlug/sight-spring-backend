# 그룹 정보 변경

그룹의 이름·설명·유형·관심 분야·사용 기술·저장소·참여 신청 가능 여부·공개 범위를 모두 덮어씁니다.

## 운영 그룹인 경우

- 그룹장뿐 아니라 운영진도 그룹 정보를 변경할 수 있음
- 운영 그룹이고 운영진이 요청하면 공개 범위를 운영진만(`MANAGER_ONLY`)으로 지정할 수 있음

## API 경로

```
PUT /groups/:groupId
```

## 권한

USER and (그룹장 or (운영진 and 그룹 유형이 운영(`MANAGE`)))

## 조건

- 중단 상태에서는 실행할 수 없음. [그룹 공통 사항의 중단 상태 동작 제한](../global.md#중단-상태에서의-동작-제한)을 따름
- 그룹 진행 상태가 진행중(`PROGRESS`)이어야 함 — 중단·종료된 그룹은 변경 불가
- `title`이 공백이 아니어야 함
- 운영진이 아니면 `category`는 `STUDY` \| `PROJECT` \| `DOCUMENTATION` 중 하나여야 함
- `visibility`가 `MANAGER_ONLY`이면 요청자가 운영진이고 `category`가 `MANAGE`여야 함
- `interests` 안에 중복 값이 없어야 함
- `repositoryUrls`는 LF 줄바꿈(`\n`, U+000A)으로 구분한 문자열이며 분리한 URL에 중복 값이나 빈 값이 없어야 함. URL 자체의 쉼표와 퍼센트 인코딩은 보존함. 개별 URL 안에 실제 CR·LF 줄바꿈은 포함할 수 없음. 빈 문자열 또는 null은 저장소 없음으로 처리함
- `techStack`은 쉼표(`,`)로 구분한 문자열이며 분리한 기술 이름에 중복 값이나 빈 이름이 없어야 함. 기술 이름 자체에 쉼표를 포함할 수 없음. 빈 문자열 또는 null은 사용 기술 없음으로 처리함

## 제한

- `title` 길이는 최대 255자 — 현재 `group.title` 컬럼 길이
- `techStack`은 현재 `group.technology` 컬럼(255자) 하나에 저장되므로, 쉼표를 포함한 문자열 길이가 255자를 넘을 수 없음
- `repositoryUrls`는 최대 5개. 개별 URL 길이의 별도 제한 없이 프로토콜과 LF 구분자를 포함해 합친 문자열의 전체 길이가 255자를 넘을 수 없음. 기존 `group.repository` 컬럼(255자)에 저장함
- 사용 기술과 저장소 URL 각각의 합친 문자열에 255자 한도를 적용함. 255자는 허용하고 256자부터 거부함
- LF는 1자로 계산하고 유니코드 코드 포인트 기준으로 글자 수를 셈. 사용 기술은 개별 길이·개수의 별도 제한 없음

## 저장 형식

- `title`, `description`, 사용 기술 이름은 HTML로 해석하지 않는 일반 텍스트로 저장한다.
- 저장소는 LF 줄바꿈으로 합쳐 전송·저장함. JSON에서는 `\n`으로 이스케이프되지만 값에는 실제 LF 한 문자가 들어감
- 전체 저장소 문자열은 URL 디코딩하지 않고 LF로 먼저 분리함. URL 안의 `%0A`, `%2C` 등은 원문 그대로 유지함
- 저장소가 하나뿐인 기존 데이터는 별도 구분자 변환 없이 유지함

## 설계 결정

### 글자 수와 개수 제한

- 사용 기술과 저장소 문자열의 255자 한도는 레거시 컬럼의 저장 범위를 그대로 유지하기 위한 것이다.
- 저장소는 일반적으로 3개 이내를 사용한다는 요구를 바탕으로 여유를 두어 최대 5개를 허용했다.

### 저장소 URL 구분자

- 쉼표는 URL 경로나 쿼리에 원문으로 포함될 수 있어 구분자로 사용하면 정상 URL을 제한하거나 잘못 분리할 수 있다. 실제 줄바꿈은 정상 URL에 포함되지 않으므로 LF를 사용한다. [URL 표준](https://url.spec.whatwg.org/#url-writing), [RFC 3986](https://www.rfc-editor.org/rfc/rfc3986#section-2.2).
- 사용 기술은 기존 데이터가 쉼표로 구분되어 있고 사용에 불편이 없으므로 데이터 변환이 필요한 구분자 변경을 하지 않는다.

## 새니타이징

- 분리한 저장소 URL은 `http`·`https` 스킴만 허용한다. `javascript:`, `data:` 등은 거부한다.
- `title`, 사용 기술 이름에서 줄바꿈 등 제어 문자를 거부한다. `description`은 줄바꿈만 허용한다.

## 부수 효과

### 경험치 변동

(해당 없음)

### 알림

변경된 항목을 그룹 멤버 전체에게 알림

### 그룹 활동 로그

그룹 활동 로그에 정보 변경을 기록함. 그룹 정보 변경은 활동으로 인정하지 않으므로 최근 활동 일시는 갱신하지 않음

## 요청 바디

| 이름             |          타입          | 설명   |
| :--------------- | :--------------------: | :------------------------------------------ |
| `title`          |         문자열         | 그룹 이름                                         |
| `description`    |     문자열 \| null     | 그룹 설명                                        |
| `category`       |          enum          | 그룹 유형. `PROJECT` \| `STUDY` \| `DOCUMENTATION` \| `MANAGE` \| `EDUCATION` \| `PROGRAM`       |
| `interests`      |   enum 배열 \| null    | 관심 분야 배열. 값은 그룹 정보 조회의 `interests`와 같음      |
| `techStack`      |  문자열 \| null   | 쉼표로 구분한 사용 기술. 예: `react,typescript,springboot`. 빈 문자열 또는 null은 사용 기술 없음 |
| `repositoryUrls` |  문자열 \| null   | LF 줄바꿈(`\n`)으로 구분한 저장소 URL. 빈 문자열 또는 null은 저장소 없음 |
| `allowJoin`      |         불리언         | 참여 신청 가능 여부                         |
| `visibility`     |          enum          | 공개 범위. `PRIVATE` \| `MEMBER_ONLY` \| `PUBLIC` \| `MANAGER_ONLY`  |
