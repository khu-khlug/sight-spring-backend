# GitHub API 개인 사용량 설정 조회

저장소 조회에 요청자 개인의 GitHub API 사용량을 사용할지 설정한 값을 조회합니다. [개인 사용량 사용 설정](user-github-preference-update.md)으로 저장한 회원 전역 설정이며, 모든 그룹에 동일하게 적용됩니다. 설정한 적이 없으면 `false`를 반환합니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
GET /groups/user-preference
```

## 권한

USER

## 조건

(해당 없음)

## 부수 효과

(해당 없음)

설정값만 조회하며 GitHub API를 호출하지 않습니다. 설정을 생성·변경하거나 비활성화 후 7일 대기 기준을 갱신하지 않습니다.

## 쿼리스트링

(해당 없음)

## 요청 바디

(해당 없음)

## 성공 응답

```
200 OK
```

| 이름 | 타입 | 설명 |
| :-- | :--: | :-- |
| `usePersonalGithubUsage` | 불리언 | 요청자의 개인 GitHub API 사용량 사용 여부. 설정한 적이 없으면 `false` |

```json
{
  "usePersonalGithubUsage": false
}
```

## 실패 응답

| 상황 | 응답 코드 |
| :-- | :--: |
| 인증되지 않음 | 401 |

## 테스트 케이스

1. 회원은 본인의 개인 GitHub 사용량 설정을 조회할 수 있다
   - 200 응답과 함께 저장된 `usePersonalGithubUsage` 값을 불리언으로 반환한다
   - 다른 회원의 설정은 반환하지 않는다
2. 설정한 적이 없으면 기본값을 반환한다
   - 404나 null이 아니라 200 응답과 `usePersonalGithubUsage: false`를 반환한다
3. 변경한 설정을 조회할 수 있다
   - 설정 변경이 성공한 뒤 조회하면 마지막으로 저장된 값을 반환한다
4. 그룹과 관계없는 회원 전역 설정이다
   - 그룹 아이디를 받지 않으며 그룹장·그룹원 여부나 그룹의 중단·종료 상태와 관계없이 조회할 수 있다
5. 설정 조회에 GitHub 호출은 필요하지 않다
   - GitHub API 장애나 호출 한도 소진과 관계없이 저장된 설정을 반환한다
   - GitHub 토큰이나 실제 호출량·잔여량은 응답에 포함하지 않는다
6. 조회는 설정을 바꾸지 않는다
   - 설정이 없어도 새로 저장하지 않으며, 비활성화 후 7일 대기 기준과 경험치·알림·로그·그룹 상태를 바꾸지 않는다
7. 인증된 회원만 조회할 수 있다
   - 인증되지 않으면 401 에러를 반환한다
