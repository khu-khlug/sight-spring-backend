# GitHub API 개인 사용량 사용 설정

저장소 조회에 요청자 개인의 GitHub API 사용량을 쓸지 설정합니다. 그룹 단위가 아니라 회원 전역 설정이며, 모든 그룹의 저장소 조회에 동일하게 적용됩니다.
회원 개인 설정(`user-preference`) 중 요청 바디에 담은 항목만 바꿉니다. 설정한 적 없는 회원의 `usePersonalGithubUsage` 값은 `false`(사용 안 함)입니다.

## 운영 그룹인 경우

(해당 없음)

## API 경로

```
PATCH /groups/user-preference
```

## 권한

USER

## 조건

- 요청 바디에 바꿀 설정이 하나 이상 있어야 함
- `usePersonalGithubUsage`를 true로 바꾸는 경우, 마지막으로 비활성화한 뒤 7일이 지났어야 함

(해당 없음)

## 쿼리스트링

(해당 없음)

## 요청 바디

| 이름                     |  타입  | 기본값      | 설명                                                                 |
| :----------------------- | :----: | :---------: | :------------------------------------------------------------------- |
| `usePersonalGithubUsage` | 불리언 | 변경 안 함  | 개인 GitHub API 사용량 사용 여부. 설정한 적 없는 회원의 값은 `false` |

## 성공 응답

```
204 No Content
```

(해당 없음)

## 실패 응답

| 상황                                             | 응답 코드 |
| :----------------------------------------------- | :-------: |
| 요청 바디에 바꿀 설정이 없음                     |    400    |
| 비활성화한 지 7일이 지나지 않았는데 다시 켜려 함 |    400    |

## 테스트 케이스

1. 회원은 개인 GitHub 사용량 사용을 켤 수 있다
   - `usePersonalGithubUsage: true`를 보내면 204 응답과 함께 저장한다. 설정한 적이 없으면 기본값은 false다
2. 사용을 끌 수 있다
   - true에서 false로 바꾸면 204 응답을 반환한다
3. 끈 뒤 7일이 지나야 다시 켤 수 있다
   - 7일이 안 됐으면 400 에러를 반환하고 false를 유지한다. 정확히 7일부터는 켤 수 있다
4. 현재와 같은 값으로 요청하면 아무것도 바뀌지 않는다
   - 204 응답을 반환한다. false를 다시 보내도 7일 대기 기준을 새로 시작하지 않는다
5. 요청에 담은 설정만 바꾼다
   - 바꿀 설정이 없거나, null이거나 불리언이 아니면 400 에러를 반환한다
   - 다른 설정과 다른 회원의 설정은 그대로다
6. 그룹과 관계없는 회원 전역 설정이다
   - 모든 그룹의 저장소 조회에 같은 값을 쓰고, 그룹장·그룹원 여부나 그룹의 중단·종료 상태와 관계없이 바꿀 수 있다
7. 인증된 회원만 바꿀 수 있다
   - 인증되지 않으면 401 에러를 반환한다
8. 거부된 요청은 아무것도 바꾸지 않는다
   - 400·401·403·404 응답에서는 데이터와 경험치·알림·로그·최근 활동 일시·그룹 상태를 바꾸지 않는다
